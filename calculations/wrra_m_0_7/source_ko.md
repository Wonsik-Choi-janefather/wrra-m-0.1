## 판정 순서와 연구 결과

검증 입력은 WRRA Core 1.0과 MCC 2.3.2를 이어받은 0.6-r2의 공개 코드와 보정 장부다. 광속은 SI 정의값으로 고정하고, 후기 우주 구성비와 국소 시험원의 조건은 갱신 가능한 입력으로 유지한다. WRRA 고유 변환은 양의 상태 부하를 세 부문으로 합산하고, 그 전체를 Actual의 에너지 가중 정보부하로 정규화하여 표현형과 비표현형 비율을 계산하는 것이다. 같은 부하를 기존 에너지 함수와 압력 및 중력·팽창 계산에 전달한다.

산출값은 기준 상태의 표현형 4.93%와 비표현형 95.07%, 상태·공간 크기 변경에 따른 비율, 그리고 기존 회전·렌즈·팽창 산출값의 재현이다. 반증조건은 허용 상태에서 음의 부하가 생기는 경우, 분해 합계가 맞지 않는 경우, 같은 입력의 0.6 에너지·압력과 어긋나는 경우, 또는 실행되지 않은 전환을 완료했다고 주장하는 경우다.

0.7은 Actual·양자화·표현형을 잇는 공통 정의와 측도를 확정하고 장부를 실제 계산한다. 이 판에서 닫힌 것은 가중 측도와 기존 부하 계산의 연결이다. 물리적 양자화 사건과 입자 필터 선택은 다음 판에서 실행한다. 알려진 값의 보정을 정당한 모형 구성으로 인정하며, 독립예측을 완료 조건으로 요구하지 않는다.

## Actual과 양자화 및 표현형의 정의

Actual은 현재 모형이 보유하는 상태·공간 크기·구성 입력·기록의 전체다. 100%는 이 전체의 채택한 가중 부하를 분모로 정규화한 값이다. 무한한 비트 목록이나 우주의 모든 미시 상태를 이미 관측했다는 뜻으로 사용하지 않는다. Θ는 상수·보정·연산자·시험원 조건의 공통 입력 장부이며, R은 물리적 결과 기록이다. 0.7에서 물리적 결과 기록은 빈 목록으로 유지한다.


$$\mathscr A=(a,\rho,\Theta,\mathcal R),\qquad \rho\succeq0,\quad\mathrm{Tr}\rho=1.\tag{1}$$


양자화는 Actual 상태가 이산적인 표현형 결과와 관측 뒤 상태 및 물리적 기록으로 전환되는 연산 과정으로 정의한다. 0.7은 그 연산의 입출력과 부하 장부를 준비한다. 0/1 경계 선택, 발생확률, 관측 뒤 상태갱신을 아직 실행하지 않았으므로 결과 파일에 quantization_status를 미실행으로 명시한다.

표현형은 채택한 우리 우주 가지에서 현재 확정되어 표현된 부문의 부하다. 비표현형은 그 밖에 남아 있는 모이는 부하와 배경 부하다. 비표현형도 Actual에 포함되고 중력·팽창 장부에 기여한다. 비표현형의 존재를 관측 여부에 따라 0으로 처리하지 않는다. 잔여는 표현되지 않은 상태 내용의 보존을 가리키며, 이를 별도의 네 번째 에너지 성분으로 더하지 않는다.

물리적 기록은 전환 결과를 보유한 계의 상태다. 입력 출처와 코드 실행 로그는 재현 기록이며 물리적 관측 기록과 구분한다. 이후 기록계의 에너지는 기존 부문 안의 하위 배정으로 계산한다. 같은 에너지를 기록 비용이라는 이름으로 다시 더하지 않는다.

## 공통운반자와 양의 부하 연산자

0.6의 16개 시험 채널과 N개 내부 격자를 유지한다. N=128은 공간 부하를 계산하는 격자 크기이고, 입자 채널의 수가 아니다. 채널 공통 상태 I16/16과 내부 상태 ρ의 곱 구조를 이어받는다. 0.7은 이 구조에서 내부 부하를 계산하며 채널별 입자 배치나 필터 선택을 새로 확정하지 않는다.


$$K_c=2I-T-T^\dagger,\qquad K_b=\frac{K_c+\epsilon|0\rangle\langle0|}{1+\epsilon/(2N)}.\tag{2}$$


균등 상태에서는 Jc=Tr(ρKc)=2이고 Jb=Tr(ρKb)=2다. ε=0은 기준 운반자, ε=8은 0.6에서 사용한 비가환 시험 입력이다. 이는 실제 우주의 ε를 측정한 값이 아니다. 부문별 가중 연산자를 다음처럼 둔다. 배경 비율 fb는 1−fφ−fc로 계산하며 세 비율을 서로 독립적으로 다시 입력하지 않는다.


$$A_\phi=f_\phi I,\quad A_c=\frac{f_c}{2}a^{n_c}K_c,\quad A_b=\frac{f_b}{2}a^{n_b}K_b.\tag{3}$$


fφ=0.0493, fc=0.265, fb=0.6857, nc=0, nb=3을 기준으로 채택한다. Aφ=fφI는 0.6의 압력 없는 표현형 공변 에너지를 유지하는 구성이다. 이 항 자체가 미시적 관측 사건을 생성하지는 않는다. 세 부문은 가중 부하의 장부 항목이며 직교하는 측정 결과 투영자라고 해석하지 않는다.

## 약 5퍼센트를 계산하는 측도

가중 정보부하 측도는 부문 집합 S에 대해 상태와 양의 연산자의 trace를 합산하여 정의한다. 허용된 상태와 연산자에서는 각 가중치가 음수가 아니며, 서로 겹치지 않는 부문 라벨 집합의 합에 대해 가법성이 성립한다.


$$\mu_a(S)=\sum_{s\in S}\mathrm{Tr}(\rho A_s),\qquad W=\mu_a(\{\phi,c,b\}).\tag{4}$$


여기서 정보의 무게는 에너지 응답을 만드는 상태별 기대 부하다. Shannon 정보량, von Neumann 엔트로피, 정보 비트 수 또는 채널 수와 동일한 측도가 아니다. 상태의 trace가 모두 1이어도 부하가 다를 수 있다. 상태 엔트로피는 별도의 진단값으로 결과 장부에 함께 기록한다.


$$F_\phi=\frac{\mathrm{Tr}(\rho A_\phi)}{W},\quad F_h=\frac{\mathrm{Tr}(\rho(A_c+A_b))}{W},\quad F_\phi+F_h=1.\tag{5}$$


Fφ와 Fh는 현재 상태의 전체 가중 부하에서 각 부문이 차지하는 몫이다. 개별 측정의 0 또는 1 발생확률이 아니다. W=0이면 정규화된 몫을 정의할 수 없으므로 JSON null을 기록한다. trace가 1인 상태라도 가중 연산자의 영 공간에 놓이면 이 경우가 생길 수 있다.


$$a=1,\quad\rho=I/N:\quad(F_\phi,F_c,F_b)=(0.0493,0.265,0.6857).\tag{6}$$


후기 우주의 약 5%를 표현형 부하에 대응시키는 것은 공개한 WRRA 구성 선택이다. 기존의 에너지 가중 보정과 정보부하 측도를 같은 장부에 대응시켜 현재 기준에서 4.93%를 재현한다. 이 대응을 정보 비트 수의 직접 측정 결과로 바꾸어 부르지 않는다. 상수·관측값의 반영을 통해 우리 우주 가지를 정하는 방법을 유지한다.

## 같은 에너지 장부에서 압력과 중력 및 팽창 계산

V0는 대표 공변 부피이며 기본값 1 m³는 회계 단위다. 실제 우주의 크기로 해석하지 않는다. 기준 에너지 밀도는 ucrit,0=3H0²c²/(8πG)다. 가중 부하를 물리 에너지로 대응시키면 0.6의 세 부문 에너지와 정확히 같은 값을 얻는다. 표현형의 지수는 nφ=0이다.


$$E_s=u_{\mathrm{crit},0}V_0\mathrm{Tr}(\rho A_s),\quad u_s=\frac{E_s}{V_0a^3},\quad p_s=-\frac{n_s}{3}u_s.\tag{8}$$



$$H^2=\frac{8\pi G}{3c^2}u_{\mathrm{tot}},\qquad q=\frac{u_{\mathrm{tot}}+3p_{\mathrm{tot}}}{2u_{\mathrm{tot}}}.\tag{9}$$


현재 균등 기준에서 H/H0=1과 q=−0.52855를 재현한다. 같은 모이는 부하를 기존 국소 응답에 넣으면 시험 회전속도 207.510905 km/s와 조건부 렌즈 편향 0.535586511각초를 유지한다. 국소 시험원과 Φ=Ψ 조건을 유지한 재현이며, 실제 은하 관측자료를 새로 적합한 결과는 아니다.

뒤틀림 기록의 크기는 현재 부하와 공간 크기에서 계산하는 집계값으로 유지한다. 이 판에서도 별도의 시간 누적 법칙을 도입하지 않는다. 같은 부하에서 뒤틀림과 팽창이 계산된다는 연결과 뒤틀림이 팽창을 일으킨다는 인과 주장도 구분한다. 압력·팽창 방정식은 0.6에서 실행한 외부 수학을 사용하며, WRRA의 구성 성과는 상태 부하와 표현형 장부를 그 계산에 실제 연결한 데 있다.

## 다음 단계에 전달하는 장부

parameters.json이 상수·구성비·격자·지수·시험원·회계 부피의 유일한 실행 입력이다. 결과는 이 파일의 정규 JSON 표현에 대한 SHA256을 포함한다. 입력을 변경하면 결과와 해시가 함께 바뀌며, 실행 중 입력이 변형되면 실패한다. results.json은 각 부문의 가중치·에너지·밀도·압력과 0.6 연결 출력, 상태 생성법, 측정 미실행 상태를 보유한다.

0.8은 이 장부에 입자와 필터 선택 결과를 연결한다. 0.9는 실제 양자화 결과·발생확률·관측 뒤 상태·물리적 기록을 생성한다. 0.10은 반복 전환의 분기와 불확실성을 계산한다. 0.11은 그 전환과 기록계의 부하 교환을 물리 계산에 연결한다. 다음 식은 그때 사용할 회계 조건이며 0.7에서 실행한 측정 법칙이 아니다.


$$E_{\mathrm{before}}+E_{\mathrm{environment,before}}=E_{\mathrm{after}}+E_{\mathrm{environment,after}}.\tag{11}$$


0.12는 전체 실행·문서·주장 장부를 대조한 뒤 1.0으로 확정한다. 0.7의 완료 판정은 공통 정의와 에너지 가중 측도 및 기존 부하 계산의 연결에 한정한다. 입자 선택·관측 법칙·전체 이론의 통합을 완료했다고 선행 판정하지 않는다. 같은 기준으로 기존 이론의 검증 입력과 WRRA 내부 실행을 구분한다.

## 재현 방법과 참고 자료

압축파일의 루트에서 python calculations/wrra_m_0_7/run_release.py를 실행하면 대표 결과표와 verification.json을 생성한다. 필요한 계산 라이브러리는 numpy와 scipy다. 원고 작성에는 pandoc와 python-docx, PDF 변환에는 LibreOffice가 별도로 필요하다. 고정 입력과 상태 생성법을 공개하므로 재현 과정에서 무작위로 보정값을 선택하지 않는다. 추가 혼합 상태 시험은 seed 707을 사용한다.
