# WRRA-M 0.6 착수: 정보부하, 뒤틀림 중력과 팽창의 연결

Wonsik Choi · 2026-10-01 · 범위 설정 및 실행한 첫 계산

## 이번 판의 중심

0.6은 **공통전달자의 정보 상태 → 물리적 정보부하 → 뒤틀림 → 중력 응답**을 하나의 실행 가능한 계산으로 연결한다. 동일한 표현형 이전 부하의 전역 배경과 국소 모이는 응력을 구분하고, 팽창과 뒤틀림이 함께 존재하는 배경 구성도 계산한다. WRRA Core 1.0과 MCC 2.3.2를 유지한다.

표현형 질량의 양자화 가능성과 표현형 이전의 근본 중력에 대한 비양자 전제는 모형의 출발점으로 유지한다. 이번 계산은 이 전제의 증명이나 일반적인 양자중력 불가능 정리가 아니다. 계산에 쓰는 전달자의 행렬 표현 역시 근본 중력을 양자화했다는 뜻이 아니다.

## 범위와 완료 기준

| 계산 대상 | 0.6에서 할 일 | 착수 상태 |
|---|---|---|
| 상태별 정보부하 | 같은 정규화 정보 상태라도 가중치에 따라 부하가 달라지는 계산 | 선언한 양의 연산자로 실행 |
| 부하에서 국소 중력까지 | 부하를 뒤틀림률과 추가 가속도, 회전, 조건부 렌즈 계산에 전달 | 고정 시험 소스에서 실행 |
| 전체와 부분의 회계 | 전체 숨은 부하와 국소 모이는 응력을 분리 | 비율을 명시해 실행 |
| 팽창과 뒤틀림의 공존 | 보존식 아래에서 뒤틀림 기록·밀도·팽창을 함께 진화 | 세 압력 가정을 비교 실행 |
| 유한 무경계 구성 | T³ 대표 길이와 뒤틀림 기록의 정합성 | 정규화된 배경 계산, 실제 위상은 미확정 |
| 물리적 연결의 검증 | 상태 진화, 압력, 국소 응답의 공동 구성 및 안정성 조건 | 다음 단계의 핵심 미완료 |

0.6 본문을 완성했다고 판정하려면 정보 상태의 변화 규칙과 압력·응력의 관계를 명시하고, 같은 부하 회계가 보존식과 국소 응답을 함께 만족하는지 확인해야 한다. 이 문서와 코드는 그 작업의 착수 결과다. 공변 작용, 소리속도, 비등방 응력, 렌즈 미끄러짐과 섭동 안정성은 현재 구현한 것으로 표시하지 않는다.

## 구현한 부하 사상

128개 내부 격자를 주기적으로 접합하고 양의 준정부호 순환 라플라시안 K=L_C를 사용한다. 16개 시험 전달자 채널에 같은 연산자를 적용한다.

\[
R=(I_{16}/16)\otimes\rho,\qquad
\operatorname{Tr}\rho=1,\qquad J=\operatorname{Tr}(R(I_{16}\otimes L_C))
=\operatorname{Tr}(\rho L_C).
\]

균등 상태에서는 J₀=2다. 물리적 에너지 밀도는 u_pre=ηJ로 둔다. η는 기준 상태에서 u_pre,0=0.9507·ρ_crit,0·c²가 되도록 **한 번 보정하는 에너지 밀도 계수**다. 순환 라플라시안과 이 보정은 명시한 구성 선택이다. 비트마다 보편적인 에너지가 정해졌거나 실제 우주의 미시 법칙을 유일하게 찾았다는 주장은 하지 않는다.

현재 입력은 표현형 4.93%, 전체 숨은 부문 95.07%, 국소 모이는 부문 26.5%, 나머지 배경 68.57%다. 26.5%는 우주 전체에 대한 비율이며, 숨은 95.07% 안의 부분이다. 상태 비교에서는 χ=0.265/0.9507을 고정하고 u_c=χu_pre를 사용한다. 이 분배는 도출값이 아니라 갱신 가능한 입력이다.

\[
\zeta\kappa_{\rm tot}^2=\frac{16\pi G}{c^4}u_{\rm pre},\qquad
a_T^2=\frac{\pi G}{3}u_c
=\frac{\zeta c^4}{48}\kappa_c^2.
\]

두 번째 관계는 0.5의 a_T=cH√(f_c/8)에 평탄 배경의 임계 밀도 정의를 넣어 정리한 동일한 보정 관계다. 새로운 독립적인 가속도 보정값을 넣지 않는다. 국소 계산은 0.5의 응답 함수와 Plummer 시험 소스, 200 kpc 렌즈 패치를 사용한다. 렌즈는 Φ=Ψ라는 조건 아래에서만 계산한다.

정보 상태를 바꾼 순간 비교에서는 표현형 밀도를 고정하고 총밀도에 맞춰 H를 다시 계산한다. 다른 부하를 넣으면서 동일한 H₀와 평탄 임계밀도를 동시에 고정하지 않는다. 이 비교는 같은 은하의 시간 진화나 실제 은하에 대한 새 적합이 아니다.

## 실행한 상태별 결과

모든 상태의 trace는 1이다. 따라서 이 차이는 정규화된 정보의 개수보다 **상태에 부여한 물리적 부하**에서 나온다.

| 정보 상태 | J | a_T (m/s²) | 시험 반경 8.2 kpc의 총 회전속도 (km/s) |
|---|---:|---:|---:|
| 균등 기준 상태 | 2.000000 | 1.191813×10⁻¹⁰ | 207.510905 |
| 낮은 모드 | 0.152241 | 3.288204×10⁻¹¹ | 177.250177 |
| 세 모드의 일관된 중첩 | 0.657554 | 6.833742×10⁻¹¹ | 192.003913 |
| 높은 모드 | 4.000000 | 1.685478×10⁻¹⁰ | 219.215978 |
| 영 모드 | 0 | 0 | 161.450511 |

기준 상태는 0.5의 a_T를 재현한다. 영 모드는 선언한 연산자의 영공간에 있으므로 부하가 0이 된다. 이는 실제 우주의 모든 정보가 어떤 상태에서 무중량이 된다는 일반 명제가 아니다. 영 부하의 렌즈 결과는 계산하지 않아 null로 기록한다. 양의 부하 상태에서는 렌즈 적분값도 results.json에 기록한다.

대칭 전달자의 선택 격차는 여전히 0이다. 이 구현으로 채널 선택 문제가 해결됐다고 주장하지 않는다.

## 팽창과 뒤틀림의 첫 연결

유한 무경계 논문의 T³ 구성에서 L=L₀a, Q=ΣΘᵢ², W=ζQ로 두면

\[
u_{\rm pre}=\frac{\zeta c^4 Q}{16\pi G L^2}
\propto\frac{W}{a^2}.
\]

고정된 양의 ζ를 가정하고, 각 부문에 교환항이 없는 배경 보존식 du/dln a=−3(u+p), p=wu를 적용하면

\[
\frac{d\ln W}{d\ln a}=-1-3w.
\]

이 단계는 등방적인 평탄 Friedmann 평균을 선택한 배경 시험이다. 실제 뒤틀린 계량과 광자 전달을 유도한 계산은 아니다. T³의 주기 접합은 경계를 없애지만, 주기 접합 그 자체가 국소 추가 중력을 만들어 주지는 않는다.

| 선언한 숨은 부문의 압력 | 필요한 뒤틀림 기록의 진화 | 현재 감속계수 q |
|---|---|---:|
| 전체 숨은 W 고정: w=−1/3 | 전체 W 일정 | +0.024650 |
| 모이는 부문 w=0, 배경 w=−1/3 | W_c∝a⁻¹, W_bg 일정 | +0.157150 |
| 모이는 부문 w=0, 배경 w=−1 | W_c∝a⁻¹, W_bg∝a² | −0.528550 |

첫째·둘째 시험은 이 입력에서 가속 팽창을 만들지 못한다. 셋째는 가속 팽창을 만들지만 w_bg=−1을 **선언한 압력 구성**으로 넣은 결과다. 배경 팽창식은 이 조건에서 ΛCDM과 같은 형태이며, 뒤틀림이 그 압력을 미시적으로 발생시켰다는 증명은 아직 없다. 같은 숨은 부하의 배경 응답에 별도의 암흑 성분이나 Λ를 추가해 두 번 세지 않는다.

셋째 시험에서는

\[
\frac{W(a)}{W(1)}=\frac{0.265/a+0.6857a^2}{0.9507},\qquad
\frac{u_{\rm pre}(a)}{u_{\rm pre}(1)}=
\frac{0.265a^{-3}+0.6857}{0.9507}.
\]

그러므로 팽창 중에 누적 뒤틀림 기록의 크기와 물리적 뒤틀림률이 서로 다른 방향으로 변할 수 있다. 둘을 모두 '꼬임'이라는 한 숫자로 쓰지 않는다. 모이는 부문의 a_T(a)/a_T(1)=a⁻³ᐟ²도 같은 밀도 관계로 계산된다.

## 검증과 남은 반증 조건

고정된 K의 고윳값 범위는 0≤J≤4다. 같은 η와 trace=1 상태로 배경 밀도를 표현하려면 J_required=2·u_pre(a)/u_pre(1)도 이 범위에 들어가야 한다. 이 조건도 실제 계산했다.

| 배경 시험 | 고정된 부하 연산자로 표현 가능한 시험 구간 |
|---|---|
| 전체 기록 고정 | a≥0.707107 |
| 차가운 모이는 부문 + 고정 기록 배경 | a≥0.740789 |
| 차가운 모이는 부문 + 일정 에너지 배경 | a≥0.601829 |

따라서 세 배경의 a=0.5 밀도는 현재의 고정된 K와 η, 정규화된 한 상태로 표현할 수 없다. 그림의 해당 부분은 점선으로 구분했다. 허용 구간에서는 영 모드와 높은 모드의 혼합으로 필요한 부하를 대수적으로 구현할 수 있고, 그 혼합 가중치도 기록한다. 그러나 이것은 지정한 배경 부하를 맞추는 상태의 구성 예이지, 압력이나 상태의 시간 변화 법칙을 유도한 결과는 아니다. 전체 진화 구간을 연결하려면 연산자의 기하 의존성 또는 정보 상태의 밀도·범위 변화까지 명시해야 한다.

- 행렬 trace 계산을 독립적인 모드 고윳값 평균과 비교했다. 오차는 2×10⁻¹³ 미만이다.
- 부하 연산자의 준정부호성, 각 상태의 Hermitian·양의 준정부호·trace=1 조건을 확인했다.
- 부하 연산자와 교환하는 격자 이동 아래 부하가 보존되는지 확인했다.
- 배경 밀도에 필요한 부하가 같은 연산자의 상태 허용 범위에 있는지 검사하고, 범위 밖의 구간을 표시했다.
- 배경 ODE 해를 해석적 W(a)와 비교하고, 독립적인 유한차분으로 연속 방정식 잔차를 확인했다. 허용치는 각각 10⁻⁸과 2×10⁻⁸이다.
- 이 검증은 배경의 수치 정합성이다. 음의 압력 부문에 대한 섭동 안정성이나 실제 관측 적합을 검증한 것으로 확대하지 않는다.

다음 단계에서는 정보 상태의 시간 변화에서 위의 압력 구성이 나오는지, 국소 모이는 응력이 차가운 성분으로 작용하는지, 운동과 렌즈가 같은 응력 회계에 맞는지를 검사한다. 맞지 않으면 해당 구성 선택을 기각하거나 수정한다. 광자 뒤틀림 적색편이 커널을 도출하기 전에는 a를 관측 적색편이로 자동 치환하지 않는다. 절대 우주 길이와 실제 위상은 이 계산의 산출값이 아니다.

## 0.5에 반영한 검토

한글·영문 제목과 주장 장부에서 정보부하·뒤틀림 연결 및 조건부 유한 무경계 구성을 앞세웠다. 전체 95.07%와 국소 26.5%의 구분, 상태별 가중치 계산이 0.5에서는 미구현이라는 경계도 명시했다. 표현형 비율이 0일 때 실행되도록 고쳤고, 정의할 수 없는 비율은 JSON null로 기록한다. 반경 r과 2r의 가속도 응답비는 실제 두 값을 계산해 기록한다. 기존의 회전·렌즈·전달자 수치는 그대로 재현됐다.

## 재실행

```bash
python -m pip install -r requirements.txt
python compute_start.py
```

parameters.json과 baseline_0_5/parameters.json에 입력과 보정값을 명시했다. results/results.json은 상태별 중력·조건부 렌즈와 세 배경의 계산 결과다. results/background_start.png는 압력 가정별 팽창과 뒤틀림 기록·뒤틀림률을 함께 보여 준다.
