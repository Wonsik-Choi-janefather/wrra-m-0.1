Executed initial prototype: information-state load → twist → local gravity, with declared expansion-pressure comparisons and explicit state-domain limits. This is not a completed 0.6 paper.

정보 상태의 부하에서 뒤틀림·국소 중력으로 연결한 첫 실행 모형이며, 팽창 압력 구성과 상태 허용 범위를 함께 검사한다. 완성된 0.6 논문은 아니다.

Run `python compute_start.py` after installing `requirements.txt`. Full precomputed results are in [the reproducibility archive](WRRA_M_0_6_Start_Reproducibility.zip); `results/summary.json` gives current values and verification.
