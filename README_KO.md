# WRRA-M 0.3 한국어 개요

## 연구 결정

WRRA-M 0.3은 0.2가 남긴 단 하나의 가정을 유한한 선택 문제로 바꾼다. 교차 차원필터를 독립된 장치로 추가하지 않는다. 소스가 제공한 적합도 값과 고정된 법칙 아래에서 안정적으로 남는 승자를 필터로 정의한다.

## 검증 입력

0.3은 0.2의 16채널 공간과 목표 대응을 그대로 유지한다.

\[
\mathcal C_{16}=\mathbf1_0\oplus\mathbf7_A\oplus\mathbf7_B\oplus\mathbf1_N,
\]

\[
F_{\times}:\mathcal C_{16}\rightarrow
(\mathbf4,\mathbf2,\mathbf1)\oplus(\bar{\mathbf4},\mathbf1,\mathbf2).
\]

왼쪽과 오른쪽 단일항 배정을 각각 교환하면 다음의 완전한 최소 후보집합을 얻는다.

\[
\mathcal F_4=\{F_{DX},F_{XX},F_{DD},F_{XD}\}.
\]

모든 후보는 채널 전체와 공통 색 작용을 보존한다.

## WRRA 고유 변환

소스는 왼쪽과 오른쪽의 스칼라 적합도 표를 제공한다. 법칙은 두 짝지음이 선택한 네 항을 합산해 각 필터의 점수를 정한다.

왼쪽 직접배정의 우위와 오른쪽 교차배정의 우위를 다음처럼 정의한다.

\[
\Delta_L=(\ell_{AA}+\ell_{BB})-(\ell_{AB}+\ell_{BA}),
\]

\[
\Delta_R=(r_{AN}+r_{B0})-(r_{A0}+r_{BN}).
\]

이 값들은 목표 필터를 판정하기 전에 고정한 규칙으로 계산하거나 측정해야 한다.

## 산출값

0.2의 목표 \(F_{DX}\)는 다음 조건에서 그리고 그때에만 유일한 최대점수 필터다.

\[
\Delta_L>0
\quad\text{그리고}\quad
\Delta_R>0.
\]

필터의 양의 가중치는 상수점수 복제자 흐름을 따른다.

\[
\dot p_F=\eta p_F(C(F)-\bar C).
\]

두 간극이 양수이고 목표의 초기 가중치가 0이 아니면 목표 가중치는 1로 수렴한다. 최소 간극

\[
\delta=\min(\Delta_L,\Delta_R)
\]

이 지수 수렴속도를 정한다. 또한 \(\delta>4\rho\)이면 각 적합도 항에 \(\rho\) 이하의 섭동이 생겨도 같은 필터가 선택된다.

## 반증조건

다음 중 하나라도 성립하면 명시한 범위 안에서 0.3은 실패한다.

- 독립적으로 정의한 소스와 법칙이 두 간극 중 하나에 0 이하의 값을 준다.
- 목표와 같거나 더 높은 점수를 가진 다섯 번째 허용 필터가 발견된다.
- 고정점수 필터 가중치가 공개한 비율법칙을 따르지 않는다.
- 불확실성이 주장한 안정성 여유를 넘는다.
- 목표를 확인한 뒤 점수나 후보집합을 바꾼다.

## 정확한 경계

0.3은 정의된 네 필터 집합 안의 정리를 증명한다. 적합도 표를 근본 물리학에서 계산하지 않으며, 더 깊은 이론에서 이 집합이 완전하다고 증명하지도, 자연이 양의 간극을 준다고 보이지도 않는다. 상류 값을 독립적으로 고정하기 전까지 결과는 경험적 확인이 아니라 조건부 정리이자 측정 절차다.
