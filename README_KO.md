# WRRA-M 0.2 한국어 개요

## 연구 결정

WRRA-M 0.2는 0.1이 남겨둔 질문 하나를 마무리한다. 하나의 조건부 교차 차원필터가 16개 입력 채널을 재배열할 때 약한 짝지음·하이퍼전하·전기전하·이상 소거가 함께 따라오는지 검증한다.

## 검증 입력

외부 수학 기준선은 다음과 같다.

- 파티-살람 표현 \((4,2,1)\oplus(\bar 4,1,2)\)
- SO(10) 한 세대와 결부된 16성분 구성
- 확립된 분기 \(7\downarrow_{SU(3)}=3\oplus\bar 3\oplus1\)
- 표준적인 국소·전역 이상 판정조건

이 항목들은 WRRA의 발견으로 주장하지 않는다.

## WRRA 고유 변환

입력공간은 다음과 같다.

\[
\mathcal C_{16}=\mathbf1_0\oplus\mathbf7_A\oplus\mathbf7_B\oplus\mathbf1_N.
\]

WRRA-M은 조건부 교차 차원필터가 수행해야 할 작용을 다음과 같이 정의한다.

\[
DF_{\times}:\mathcal C_{16}\rightarrow
(\mathbf4,\mathbf2,\mathbf1)\oplus(\bar{\mathbf4},\mathbf1,\mathbf2).
\]

A와 B 부문의 삼중항과 단일항은 왼쪽 블록을 이룬다. A 부문의 반삼중항은 널 단일항과, B 부문의 반삼중항은 불변 단일항과 짝을 이루어 오른쪽 블록을 만든다. 채널은 하나도 새로 생기거나 사라지지 않는다.

## 산출값

색 대칭성과 무대각합 조건은 \(B-L\) 생성자의 상대형태를 고정한다. 다음 일반식에서 출발하면

\[
Y=\alpha T_{3R}+\beta(B-L),
\]

\(Y(\nu^c)=0\), \(Y(e^c)=1\)의 두 조건으로

\[
Y=T_{3R}+\frac{B-L}{2}
\]

를 얻는다. \(Q=T_{3L}+Y\)를 함께 적용하면 \(Q_L,L_L,u^c,d^c,\nu^c,e^c\)의 표준 전하가 복구된다. \(SU(3)^3\), \(SU(3)^2U(1)\), \(SU(2)_L^2U(1)\), \(U(1)^3\), 혼합 중력–\(U(1)\), 전역 SU(2) 정합성 검사가 모두 닫힌다.

## 반증조건

공통 \(SU(3)\) 작용을 보존하면서 교차 짝지음을 구현할 수 없거나, 채널의 복제·삭제가 필요하거나, 두 정규화 조건으로 모든 채널에 유효한 하나의 연산자를 만들 수 없거나, 열거한 이상 조건 가운데 하나라도 실패하면 0.2 대응은 기각된다.

## 정확한 경계

WRRA-M 0.2는 소스와 법칙으로부터 교차 차원필터의 존재·유일성·안정성·동역학적 선택을 도출하지 않는다. 필터가 해야 할 작용을 정의하고 그 작용의 결과를 증명한다. 0.2는 여기에서 멈춘다.
