# WRRA-M 0.1 — 한국어 개요

## 연구 결정

WRRA-M을 WRRA Core 1.0과 분리된 연구 분기로 연다. 첫 과제는 다음 대응을 검증하는 것이다.

- 4차원 M이론 콤팩트화에 사용되는 7개의 내부 차원
- WRRA의 7개 선차원 자유도
- 유한한 3+1차원 표현형과 입자 채널을 렌더링하는 차원필터

## 아키텍처

- **소스와 법칙:** 불변의 바탕과 전이법칙
- **선차원 상태 \(P_7\):** 공간으로 가정하지 않은 7개의 독립 자유도
- **잔여:** 이전 전이의 현재 기록. 잔여의 순서화가 물리적 시간의 후보 기원이다.
- **차원필터:** 선차원 상태를 유한한 표현형으로 바꾸는 변환
- **중력:** 12번째 좌표가 아니라 상류의 운동학적 구조와 응력 전체가 표현형에 상속된 결과
- **암흑물질 후보:** 물질 표현형으로 드러나지 않은 상류 구조가 만드는 중력 출력인 뒤틀림 응력

## 정확한 결과와 경계

방향을 가진 \(G_2\) 7 부문 두 개와 불변 채널 하나는 15개 채널을 만든다. 색 부분군 \(SU(3)\)로 제한하면 표준모형 한 세대의 색 내용과 표현 다중도가 정확히 일치한다.

\[
\mathbf{1}\oplus\mathbf{7}_A\oplus\mathbf{7}_B
\downarrow_{SU(3)}
=2\cdot\mathbf{3}\oplus2\cdot\bar{\mathbf{3}}\oplus3\cdot\mathbf{1}.
\]

이 결과는 색 부문에서만 정확하다. 다음 결정적 과제는 약한 짝지음, 하나의 하이퍼전하 연산자, 손지기성, 3세대, 질량, 로런츠형 3+1 계량, 이전 가능한 수치적 뒤틀림 응력법칙을 도출하는 것이다.
