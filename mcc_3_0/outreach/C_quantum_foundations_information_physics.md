## Abstract

Minimal Computing Cosmology 3.0 asks whether physical reality can be modeled as an execution over finite states rather than as a completed infinite catalogue.

The model separates five roles:

1. SOURCE: executable state supply,
2. FILTER/RELATION: admissibility and transport,
3. RESIDUE: present-state memory of prior execution,
4. RESOURCE/LEDGER: owned conserved or transferred quantities,
5. ACTION/PHENOTYPE: rendered output.

The key information-physics claim is not that information is metaphorically important. It is that every downstream physical quantity must have an explicit owner in a finite ledger, and that alternative internal descriptions are not allowed to be counted twice.

In MCC 3.0, the candidate finite address space contains 1,015,000 labels. The address state is propagated through a phase-aware filter into phenotype, resident nonphenotype, and return sectors. These sectors then own the additive energy budget used later in gravity and cosmology.

The finite-carrier proper-time update preserves trace and total energy to numerical precision while internal noncommuting loads evolve. The inherited proper-time step is:

**Delta tau = 1.4813019664158691e-21 s**

but MCC 3.0 does **not** identify this with Planck time or claim it as an absolute minimum physical time.

The unresolved question is equally important: a unitary state update and a conserved ledger do not yet constitute a full autonomous theory of irreversible measurement and persistent record formation. That layer remains OPEN.

## 3. Typed ledgers and information ownership

The additive physical ledger contains only three cosmic sectors:

**phenotype phi + resident nonphenotype D + return R**

Internal particle, component, prime, or channel descriptions are nested views of the phenotype budget. They are not extra additive energy.

Residue is not treated as a hidden historical narrative stored outside the current state.

In MCC 3.0, residue plays the analogous role in the physical ledger.

## 8. Falsification conditions

The information-physics branch must be revised if:

1. the finite state cannot carry all required present information;
2. conservation fails under the declared proper-time evolution;
3. residue is insufficient to distinguish histories that later evolve differently;
4. alternative internal descriptions must be double-counted to recover physical energy;
5. a claimed record requires information not owned by any current state variable;
6. a measurement mechanism can only be recovered by adding an untracked external sink;
7. the finite-source execution requires hidden infinite precision.

The model is fail-closed: an undefined ownership path remains OPEN rather than being declared solved.
