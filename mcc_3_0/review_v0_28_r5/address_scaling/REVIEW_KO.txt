2. WRRA 고유 변환
기존 SOURCE 생성과 주소 직렬화를 보존했다. 새 38.B절은 주소 수 N_U, 활성 주소 영역, 운반자 차원, 공간 격자 수를 구분한다. 새 139.3.1절은 x=ell_ref*xi와 Poisson 단위 복원, 부피 가중 평균, 모드별 해상도 경계를 연결한다.
추가 K 전달식은 기존 가산 장부를 보존하도록 요구하는 구현 인터페이스이다. 물리적 원천 배정 법칙의 도출이나 전 우주 실행 코드 통합이 아니다. 예비 장부는 공간 밀도를 억지로 부여하지 않고 총 에너지 합에 별도 포함한다.

새 검사는 합성 예제이며 실제 우주 에너지를 원천별로 배정한 결과가 아니다.

4. 반증조건
격자 세분화만으로 자원 증가, 예비 장부 누락, 단위 길이 입력 없는 물리 크기 확정, 주소 수와 모든 상태 수의 동일시는 이 계약에 어긋난다. 새 검사의 예비 누락 대조는 총량 등식이 깨짐을 확인한다. 범용 훼손 파일 검증기를 추가했다는 뜻은 아니다.

5. 결론
N_U는 조건부 유한 SOURCE 주소 용량이다. 거시 우주 반경, 최소 공간 셀, 모든 가능한 상태의 총개수는 N_U만으로 정해지지 않는다. 물리 길이와 밀도 기준을 해당 수신 문제에서 지정·보정해야 한다. 한영 전체 본문에 반영했으며, 전체 3.0 실행 검증 완료를 주장하지 않는다.
