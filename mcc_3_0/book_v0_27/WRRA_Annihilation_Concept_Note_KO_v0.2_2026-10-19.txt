WRRA 쌍소멸 구조 모형 — 켤레 구조의 상호 해제
개념 연구 메모 v0.2 | 2026년 10월 19일
최원식의 제안과 대화에서 정리한 모형 명세

상태와 범위
이 개념 메모의 초기 출력 선택·쌍소멸 가설은 v0.24 기준 3.0 개정 원고 v0.25의 제135장에 명시적으로 편입한다. 가설의 편입이며 미시 검증 완료라는 뜻은 아니다. 종전 v0.25의 비대칭 보정 초안은 폐기하고 새 v0.25에는 포함하지 않는다. 이 메모는 쌍소멸만 다루며 최초 우주의 비대칭, 구성비, 핵융합·핵분열로 확장하지 않는다. 신규 미시 동역학 계산·반응률 검증은 수행하지 않았다.

1. 검증 입력

전자와 양전자는 질량과 스핀 크기가 같으며 전기전하·렙톤수 등 내부 양자수가 켤레 관계다. 입자·반입자 대응은 공간의 단순 좌우 반사와 다르다. 전자·양성자도 전하는 반대이지만 서로 반입자는 아니므로 반대 전하만으로 쌍소멸을 판정할 수 없다. 전기적으로 중성인 입자·반입자도 있으므로 전하 부호를 유일한 판정값으로 삼지 않는다.

대표적 확인 반응은 e− + e+ → γ + γ 이다. 실제 허용 채널은 초기 상태와 에너지·운동량·각운동량 등 보존조건에 따라 정해진다. 물질과 반물질의 양의 에너지는 합산되어 출력에 전달된다. 쌍소멸하는 두 입자가 최초에 함께 생성된 짝일 필요는 없다.

2. WRRA 고유 변환 — 제안하는 구조

추가한 초기 출력 규칙:
표현형 출력기는 선언한 원천·시점·영역에서 물질 또는 반물질 중 한쪽만 신규 출력하도록 설정할 수 있다. 우리 우주의 초기 원천 실행은 물질 출력 조건으로 준비되었다는 가설이다. 이 설정은 이미 존재하는 점유를 삭제하지 않으며, 이후 확인된 입자 상호작용의 쌍생성·쌍소멸을 금지하지 않는다. 한쪽 물질 출력은 전기전하 한 부호만 만든다는 뜻도 아니다. 설정을 기존 SOURCE에 연결하거나 독립 입력으로 채택한 소유권과 실제 에너지·양자수 전달을 명시해야 한다. 설정의 형식적 명세와 미시 생성 기작의 도출은 구별한다.

중심 문장:
“서로 켤레인 두 입자 표현형이 만나면, 각자의 안정된 구현 구조를 상대가 해제하는 상호작용 경로가 열리고, 입자 표현형의 에너지가 운반자의 다른 표현형으로 재배치된다.”

‘매듭’과 ‘열쇠’는 이 상호 적합성과 해제 경로를 가리키는 구조 개념이다. 실제 기하학적·위상적 매듭인지 여부는 미정이다. 실제 구조로 주장하려면 해당 자유도, 불변량, 에너지 함수와 상호작용식을 정의해야 한다.

‘동일한 정보량의 다른 표현’은 이 모형의 해석 후보다. 같은 질량이라는 관측 사실만으로 비트 수나 모든 정보량의 동일성이 자동으로 따라오지는 않는다. 질량은 구현 부하, 정보는 구별 가능한 상태·상관관계로 각각 정의한 뒤 대응을 명시한다.

3. 홀수 합성수와 결합 코드

이미 표현형 편입이 허가된 홀수 합성수 주소 n,m을 사용한다. 주소는 입자의 종류나 에너지 자체가 아니며 내부 구조와 물리적 판독값을 함께 가진다.

입력 상태: (n,a,χ,E,p,...)와 (m,a,χ̄,E′,p′,...)
  n,m: 홀수 합성수 주소
  a: 대응하는 입자종의 기준 구조
  χ,χ̄: 서로 켤레인 내부 구조·양자수
  E,p: 실제 에너지·운동량 장부

후보 전환:
  켤레 상태 확인 + 상호작용 가능 + 허용 채널 확인
  → r=n+m이라는 짝수 결합 코드
  → 원래 입자 점유 감소와 운반자 출력의 갱신

홀수+홀수=짝수는 모든 홀수 쌍에서 성립한다. 따라서 켤레 관계는 ‘짝수가 되는 조건’이 아니라 ‘해당 결합을 쌍소멸 전환으로 실행하는 조건’이다. 같은 방향 구조도 산술합은 짝수지만 쌍소멸로 강제하지 않는다. 산술적 짝수화만으로 반응이 유도됐다고 주장하지 않는다.

r은 결합을 표시하는 코드이며 기존 SOURCE의 짝수 합성수 거주 부문과 타입을 구별한다. 짝수라는 이유만으로 광자나 암흑물질로 지정하지 않는다. r이 기존 주소 상한을 넘더라도 우주 용량이 자동으로 증가했다는 뜻은 아니다. 유한 출력 표현과 그 비용은 별도 명세가 필요하다.

4. 산출값과 보존 장부

현재 산출물은 계산된 반응률이 아니라 다음 전환 명세다.

  안정된 두 켤레 표현형
  → 조건부 상호작용 경로 개방
  → 입자 표현형 해제
  → 에너지·운동량·허용 양자수의 운반자 출력으로 전달

  E_out = E_in,   p_out = p_in
  각 보존되는 내부 양자수의 총합도 반응 전후 일치

사라지는 것은 원래 입자의 정지질량을 가진 점유 형태다. 방출 광자 각각의 정지질량이 0이어도, 광자들을 포함한 전체 계의 불변질량이 반드시 0인 것은 아니다. 전체 에너지는 유지된다.

상관관계와 위상 등 상태 정보도 추적해야 한다. r=n+m만으로는 입력 전체를 보존하지 못한다. 예를 들어 9+45와 27+27은 모두 54이므로 주소 합 하나는 여러 입력에 대응한다. 가역적인 전체 양자 동역학을 요구한다면 구별은 출력의 다른 자유도·상관관계 또는 포함한 환경 상태에 남아야 한다. 우주의 과거 전체를 별도 파일로 저장한다는 뜻은 아니다.

5. 반증조건과 다음 계산

다음이면 해당 구현을 기각하거나 수정한다.
  • 반대 전하만으로 전자·양성자까지 쌍소멸 처리한다.
  • 같은 물질 두 개를 홀수합이라는 이유만으로 소멸시킨다.
  • 에너지·운동량·전하 등 보존량이 누락되거나 중복 생성된다.
  • 결합 코드만 남기면서 보존한다고 선언한 상태 정보를 잃는다.
  • 실제 반응의 허용·금지 채널과 출력 상태를 재현하지 못한다.

다음 과제는 χ와 χ̄, 구조 에너지, 상호작용 연산자, 운반자 출력 채널을 정의하고 전자·양전자 사례부터 계산하는 것이다. ‘짝이 맞으면 해제한다’는 규칙을 놓는 것과 그 규칙이 실제 미시 상호작용에서 나오는 것을 보이는 것은 구분한다.

6. 결론

제안의 핵심은 ‘정보가 없어짐’이 아니라 ‘켤레 구조의 상호 해제와 재표현’이다. 홀수 합성수의 짝수 결합은 이 전환을 표시할 산술 후보이며, 전환을 결정하는 물리 조건은 켤레 관계와 허용된 상호작용이다. 최초 출력에 쌍생성을 필수로 두는 것과, 이후 대응하는 두 표현형이 쌍소멸할 수 있는 것은 별개다.

최신 보충: 쌍생성 금지 주장은 철회한다. 매 딸깍 출력 모드는 교대하되 생성은 허가된 때만 발생한다. 초기 큰 물질 출력과 후기 평균 대칭의 조건은 제135장에 명시한다. 짝수 결합 상태가 두 홀수 합성수의 켤레 상태로 분할되는 후속 쌍생성 후보를 별도 장부로 허용한다.

나머지 배치 보충: 홀수 n의 두 위치 점유 T(n,b)=((n+b)/2,(n-b)/2), b=+1 또는 -1. 출력기가 나머지 1의 위·아래 위치를 정한다. 두 상태의 배치 잔여는 b1+b2이며 반대 배치는 0, 같은 배치는 +2 또는 -2다. 이 균형 닫힘 규칙은 켤레 관계의 구조 후보이며 전하·입자종·실제 반응률의 도출을 대체하지 않는다. 그림 두 개와 상세식은 제135장과 별도 논문에 포함한다.
