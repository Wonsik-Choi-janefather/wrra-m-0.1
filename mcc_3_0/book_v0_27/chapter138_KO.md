## 138장 살아 있는 은하 분포함수와 Gaia 비교

### 138.1 검증 입력과 실제 실행한 WRRA 연결

WRRA–AGAMA 연결 v0.3은 은하 분기를 지정된 공간 밀도에서 실제 살아 있는 항성 분포함수·포아송 반복으로 확장한다. 입력은 기존 바리온 질량·방사 척도와 구성 응답 법칙, $a_T=1.191812669\times10^{-10}\ {\rm m\,s^{-2}}$, 명시한 유한 두께 분포, 두 시험 QuasiIsothermal 항성 DF 및 공개 Gaia 표본이다. 가스·벌지는 고정이고 두 항성 DF는 갱신된다. 채택한 항성 높이는 0.3/0.9 kpc, 가스 sech 제곱 척도는 0.085/0.045 kpc, 8.2 kpc에서 시험 방사 속도분산 진폭은 35/55 km/s다. 이는 공개한 물리 선택이며 새로운 미시 유도가 아니다.

실제 실행 순서는 바리온 상태 → 지정 WRRA 잔여 가속도 → 구대칭 유효 밀도·퍼텐셜 → 살아 있는 항성 $f(\mathbf J)$ → 갱신 바리온 상태다. 항성 퍼텐셜·밀도·잔여 응답을 반복한다. 응답 법칙과 DF 매개변수는 고정하지만 장 자체는 변한다. 구대칭 잔여 닫힘과 전역 경계 정칙화는 추가 가정이다. 이 은하 분기는 136장의 전체 CAMB 상태 접합이 아니며 책의 우주론 부문 비율을 재보정하지 않는다.

인터페이스 패치는 물리식을 바꾸지 않고 AGAMA 내부의 기존 적분 제어를 Python에 노출한다. 밀도 적분의 상대 허용오차는 $10^{-4}$, 최대 평가는 $10^6$회이고 항성 격자는 $z=0.08$ kpc에서 시작한다. 두 해상도 모두 보존한 v0.2 밀도에서 다섯 번 추가 반복하여 0.2% 국소 기준을 연속 두 번 만족한다. 이는 warm-start 수렴 검사이며 임의 초기 상태에서 다섯 번 만의 수렴이나 전역 수렴 정리가 아니다.

### 138.2 수치 닫힘과 서로 다른 밀도 관측량

| $R=8.2$ kpc에서 | 기준 격자 | 강화 격자 |
|---|---:|---:|
| 추가 반복; 기록된 검사 | 5; 16/16 | 5; 16/16 |
| 원운동 속도 (km/s) | 215.56532 | 215.62089 |
| $K_z(1.1\ {\rm kpc})/(2\pi G)$ ($M_\odot/{\rm pc}^2$) | 71.82974 | 71.83659 |
| $|z|\le1.1$ kpc 내 실제 적분 기둥밀도 ($M_\odot/{\rm pc}^2$) | 79.31428 | 79.31056 |
| 총 중간면 포아송 밀도 ($M_\odot/{\rm pc}^3$) | 0.0790443 | 0.0790715 |

힘 환산 표면밀도 $K_z/(2\pi G)$와 실제 적분 기둥밀도는 다르다. 원통 좌표 포아송 방정식의 방사 항을 유지해야 하며 둘을 같게 두면 모형을 잘못 읽는다. 표시 자릿수는 재현을 위한 것이고 관측 정확도가 아니다.

20개 검사점에서 최대 힘 차이는 0.0515%, 5–25 kpc에서 최대 원운동 속도 차이는 0.0268%다. 총 중간면 밀도 차이는 0.0344%로, 앞서 검사한 격자 민감도를 해소했다. 네 시험 궤도는 명목 주기 열 번 동안 에너지·축방향 각운동량 검사를 통과한다. 표본 직접 모멘트 Jeans 잔차의 최대값은 2.19%이고 근사 작용은 정확한 불변량이 아니다. 살아 있는 DF가 초기 공간 밀도를 바꾸므로 초기 유한 두께 원운동 속도 222.16 km/s는 약 215.62 km/s로 바뀐다. 기존 선형 회전 기준과의 8.25–25 kpc RMS 차이 약 5.18 km/s는 개별 관측자료 우도가 아니다.

책 통합에서는 공개 JSON·CSV 기록과 위 수치의 일치를 검산했다. 이번 갱신에서 AGAMA를 다시 빌드하거나 전체 DF 적분을 재실행하지 않았다. v0.3 원전의 실제 실행과 책의 기록 수준 검산은 별도 출처 수준이다.

### 138.3 실제 Gaia 표본과 비교 결과

명시적 DR3 선택은 반경 0.25 kpc 원통, $G=7$–17, BP–RP=1.0–1.4, 미보정 절대 $G=5$–6, 시차 S/N 10 초과, RUWE 1.4 미만이다. 받은 표본은 90,113개 별이며 72,603개에 시선속도가 있고, RV 오차 3 km/s 미만 절단 뒤에는 48,794개다. 개수 비교는 $|z|=0.15$–1.0 kpc의 17개 남북 대응 높이 빈에 속한 79,716개를 사용한다. 전역 추적자 가중치 두 개를 맞추며 빈별 조정이나 중력 매개변수 재맞춤은 없다.

기하만 연결한 고정 DF 개수 틀은 선택된 별 개수 분포를 **재현하지 못한다**. 포아송 deviance는 1747.2021이다. 질량 밀도는 자동으로 별 개수가 되지 않는다. 소광·광도와 색상 인구집단·RUWE 선택·Gaia/RVS 완전성을 모두 순방향 모형화하지 않았으며 인구집단 대응과 선택 함수가 미검증이다. 현재 불일치를 중력에만 귀속할 수 없다. 이 차이를 보고하는 것 역시 모형 검증의 일부이며 실제 수치 구현 성과를 지우는 이유가 아니다.

반사 대칭 평형 배경은 남북 비대칭과 수직 유동이 0이라고 예측한다. 별도의 Bennett–Bovy Gaia DR2 표에는 최대 9.92%의 별 개수 비대칭이 있다. 대각 잔차 제곱합은 비대칭 31빈에서 1692.2282, 전역 속도 편이 하나를 맞춘 속도 50빈에서 436.9542다. 전체 공분산이 없어 공식 결합 유의도를 주장하지 않는다. 이 DR2 선택과 직접 DR3 선택은 다르며 하나의 우도로 합치지 않았다. 통상적인 반사 대칭 평형 대조 모형에도 같은 한계가 적용된다. 이는 빠진 섭동 부문을 가리키며 중력 이론 간의 고유한 판별은 아니다.

### 138.4 반증조건과 후속 연구 순서

양이 아닌 원천 밀도, 힘·밀도 수렴 실패, 과도한 격자 민감도, 불변량 위반 또는 인구집단·선택을 일치시킨 관측 검증에서의 불일치는 해당 모형 주장에 도전한다. 현재 수치 닫힘은 선언한 검사를 통과하지만 별 개수·속도의 전체 결합 검증은 열려 있다. 선택된 개수 틀은 이미 그 좁은 표본 비교에 실패했으므로 해당 범위에서 보완하거나 기각해야 한다.

먼저 추적자 인구집단과 선택 함수를 명세하고 밀도·속도분산 자료에 추적자 DF를 보정한다. 이어 고정한 보정 모형을 보류 관측량에 적절한 오차·공분산으로 검증한다. 수직 파동까지 목표로 삼는다면 원천·진화·관측 사영을 정한 비평형 섭동을 추가하고 같은 선택 아래 비교한다. 검증된 관측으로 보정하는 것은 정당한 구성이고, 재현 가능한 연결을 인정하는 데 무관한 독립 예측을 요구하지 않는다.

성과는 살아 있는 WRRA 응답·DF·포아송 구현, 제어된 두 해상도 수치 닫힘, 현행 경계를 드러내는 실제 관측 비교다. 완전히 검증된 은하 모형이 되었다는 뜻은 아니다. 기존 방사·RAR 결과를 원래 범위에서 보존하면서 은하 구현을 확장한다.
