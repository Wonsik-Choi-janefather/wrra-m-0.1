# WRRA 3.0 이론 보완 — 1단계 검토 정리

**검토일: 2026년 10월 8일 · 검토본 r1**

## 검증 입력 → WRRA 고유 변환 → 산출값 → 반증조건

| 판정 순서 | 내용 |
|---|---|
| 검증 입력 | 보정·고정된 주소 구성비 0.05/0.268/0.682, 기존 H=29와 C=70, 공개 3.0의 필터 계수, 기존 SI·국소 중력 계수 |
| WRRA 고유 변환 | 최소 정수 해상도 → 유한 SOURCE → 소수·합성수 위상 필터 → 주소 부하 → SI 에너지 → 동일 에너지의 체적 미분 압력 → 중력·회전·조건부 렌즈·균일 팽창 |
| 산출값 | 세 용량에서 기준 출력 재현과 무재보정 전달 성립 |
| 반증조건 | 정규화·보존·단계 전달 실패, 숨은 보정, 서로 다른 회전·렌즈 중력 응답, 자원 중복 계상 |

**결론: 명시된 균일계와 조건부 국소 중력 범위에서 1단계 완료를 유지한다.** 이번 검토는 새로운 관측 실험이 아니라, 공개된 이론 구성의 재현·정합성 검토다.

## 1. 무엇을 보완했는가

SOURCE의 용량은 입력이 달라도 불변이어야 하는 양으로 전제하지 않는다. 보정 구성비를 수정하면 생성 용량이 달라질 수 있다. 필요한 조건은 어떤 입력과 규칙이 용량을 결정하는지 명시하고 그 변화가 같은 계산 규칙으로 하류까지 전달되는 것이다.

현재 분기는 다음과 같이 정의한다.

\[
L=\operatorname{lcm}\{\text{고정 구성비의 기약분모}\},\qquad N=LHC.
\]

기준 입력에서는 L=500, N=1,015,000이다. 0.05와 0.0500은 같은 유리수이므로 동일한 결과를 낸다. 구성비 값 자체를 수정하는 경우는 표기 변경이 아니라 모형 입력 변경으로 기록한다. 새 관측은 고정 모형의 검사 자료이며, 명시적인 재보정 때 SOURCE를 다시 생성한다.

## 2. 용량·운반자·장부의 구분

N은 총 SOURCE 주소 코드 수다. 기준 주소 1을 제외한 실행 주소는 N−1개다. 이 수를 입자 수, 공간 부피, 정보 비트 수 또는 공통운반자 채널 수와 동일시하지 않는다.

기존 주소→origin 연결은 주소별 기여를 조건부 커널로 합산한다. 기본 설정의 커널은 모든 주소에 같은 벡터를 적용하므로 집계 판독의 rank는 1이다. 이는 공통운반자의 내부 채널 rank를 1로 만든다는 뜻이 아니다. 모든 주소 정체성이 하류 채널에 개별 보존돼야 한다는 추가 조건은 요구하지 않는다.

구성비를 위상 증가량으로 읽는 중간 후보는 이번 완료에 필요하지 않으며 채택하지 않았다. 새로운 500차원 운반자를 도입하지 않았다.

## 3. 고정 입력과 변경 입력

SOURCE 크기 시험 입력은 다음 세 가지다.

| SOURCE 선택 구성비 | L | N |
|---|---:|---:|
| 0.05 / 0.268 / 0.682 | 500 | 1,015,000 |
| 0.0505 / 0.2680 / 0.6815 | 2,000 | 4,060,000 |
| 0.0501 / 0.2680 / 0.6819 | 10,000 | 20,300,000 |

모든 분기에서 alpha=1.8996877935161325, h=1.4476744689338703, 제타 위상 구동, 주소 응답 lambda, SI eta, 에너지 지수, 국소 질량과 렌즈 기하를 고정했다. 이 계수들은 기존 3.0 기준 분기의 보정값이며 새 시험 결과에 맞춰 다시 보정하지 않았다.

변형 구성비는 N을 선택하는 입력이다. 고정 필터를 그 구성비의 새로운 출력 목표로 재보정하지 않았다. 따라서 입력 구성비와 필터 산출값의 차이는 JSON에 잔차로 보존한다. 구성비를 새로 맞췄다고 판정하지 않는다.

## 4. 실제 계산 결과

| N | q(a=1) | 회전속도 km/s | 조건부 렌즈 각초 |
|---:|---:|---:|---:|
| 1,015,000 | −0.5285585894376318 | 207.5102418659153 | 0.5355822400088303 |
| 4,060,000 | −0.5292825795228291 | 207.4541349970819 | 0.5352210185078975 |
| 20,300,000 | −0.529977941992902 | 207.40039181157826 | 0.5348750792521283 |

각 분기에서 a=0.5, 1, 2를 계산했다. SOURCE 변화는 주소 부하 모멘트·에너지·중력·팽창에 실제로 전달됐다. 직접 보통물질 기준 회전속도는 161.45051053125528 km/s로 고정됐다.

물리적 팽창에서 총 에너지가 항상 일정해야 한다는 조건을 쓰지 않았다. 동일한 E(V)에서 압력을 계산하고 각 부문의 연속방정식을 검사했다.

\[
P_s=-\partial E_s/\partial V,\qquad
\frac{d\rho_s}{d\ln a}+3(\rho_s+P_s)=0.
\]

## 5. 재검토와 검증 보강

원본 함수는 특정 저장소 커밋에 고정했으며 바이트 단위 원본과 해시를 기록했다. 함수 추출에 필요한 항목이 모두 있는지도 검사한다. 전체 고정 입력을 분기마다 해시로 비교해 무재보정을 확인한다.

기존의 대수적 연속방정식 검사에 독립적인 중심 수치 미분 검사를 추가했다. 회전·렌즈의 실제 전달 가속도, 직접 보통물질 기준, 유한 출력과 양의 밀도도 확인한다. 작은 분기와 큰 분기의 분할 계산은 기준 분기에서 원본 전체 배열 계산과 대조했다.

13개 등록 검사가 통과했다. 이는 13개의 독립 물리 실험을 뜻하지 않는다. 수치 오차와 분할 적합성 등 세부 결과는 `capacity_transport_results.json`에 기록한다.

## 6. 완료 범위와 남은 가정

완료한 것은 조건부 유한 SOURCE 생성 규칙과 용량 변경의 상류→하류 전달 정합성이다. 균일 운반자, 균일 에너지·압력·팽창, 조건부 Plummer 약한 장 렌즈 패치가 적용 범위다.

H=29, T=2πH에 따른 C=70, LHC 전곱 허용, 산술 분류, 균일 부하, 조건부 렌즈의 Phi=Psi는 명시된 구성 가정으로 유지한다. 이 가정들의 물리적 필연성이나 실제 우주 용량의 직접 관측을 이번 단계의 산출로 바꾸어 말하지 않는다. 독립적 숫자 예측을 추가 필수조건으로 삼지도 않는다.

다음 단계는 직렬화된 주소와 소수·합성수 분류의 구조적 연결을 검토하는 것이다. 이번 완료 판정은 그 다음 문제까지 해결했다는 뜻이 아니다.
