WRRA 3.0 이론 보완 4단계 v0.4 — 내부 질량·혼합과 기록 연결

검증 입력: 공개 내부 혼합 v0.3, 질량 눈금0.11 코드와 고정 입력.
WRRA 고유 변환: 실제 유한 상태/전류를 재실행하고 질량 Hamiltonian을
대각화한다. 실제 혼합 기저로 상태·기록 유니터리·에너지 연산자를 함께
옮겨, 기존 표현형 예산으로 점유와 기록 공급 비용을 계산한다.
산출값: 내부 원본38검사와 신규 연결12검사 통과. 이번4단계 연결 검사는
누적43개이며 원본38개는 별도로 센다. 전자 mode23 보정도 코드로 재현.
반증조건: 고정 입력 재현 실패, 기저변환에 따른 에너지 차이,
질량/준비 에너지 중복, 관측량 불일치 은폐, 공급원 부족을 무시하는 경우.

실제 구분과 발견
기존 기록 사례 gap431.08124431500175 MeV는 이번 내부 혼합 Hamiltonian과
다른 명세다. 자기모멘트 주보정 gap366.9359404920706 MeV,
축 결합 포함 공동보정 gap757.8954317996527 MeV다.
이를 하나의 동일 내부 gap이라고 취급하면 기록 비용을 잘못 연결한다.
주보정은 자기모멘트를 재현하나 gA1.5686240821617012로 관측 축 결합
1.2753과 일치하지 않는다. 기존 공동보정은 질량·두 자기모멘트·축 결합과
상속한 수명 정규화를 함께 재현한다. 알려진 값을 반영한 공동보정은
정당한 구성이다. 구성 명세 Delta와 질량 offset/전류 계수는 공개 입력이다.

공급원 연결
주보정의 기록 비용6.015266344305666e-12 J는 기존20% 공급원으로 가능하다.
공동보정 비용1.2033019830228727e-11 J는 기존20% 공급원으로 불가능하다.
모든 조건부 기록 결과를 감당할 공동보정 최소 공급량은
1.2033440156388269e-11 J, 표현형 예산의31.82783539785394%다.
계산 코드가 이 최소 조건을 산출하지만 기존20% 입력을 몰래 변경하지 않는다.
대안 분기는 최소 공급량 이상의 별도 공개된 공급원을 요구한다.
종별 상태를 바꿀 때 gap/점유/기록 비용/공급원을 함께 갱신해야 한다는
연결 규칙을 얻었다. 입자 질량은 채널 예산의 단순 균등 배분이 아니다.

현재 SOURCE 전달
현재 N1015000, alpha1.8996877935161325를 기존 유한 Euler 가족 응답에 넣고
C를 재보정하지 않으면 주보정 q=.07353192154110458,
gap366.9359260048723 MeV, gA1.5686241046118607다.
미측정 내부 간격의 값은 선언된 Delta/C 안에서의 조건부 WRRA 예측이다.
이 혼합은 핵자 내부 구성 혼합이며 CKM/PMNS 또는 모든 종의 질량 혼합이 아니다.
복합 양성자를 하나의 Weyl 채널과 동일시하지 않는다.

판정: 기존 내부 질량·혼합 연산자를 실제 기록 계산에 연결하고,
숨겨질 수 있던 gap/공급원 불일치를 드러냈다. 전체4단계의 최종 검토는
기존 기록 분기를 유지하는 기준과 대안 내부 분기의 입력 계약을 정리해
같은 입력 장부에서 완료 판정하는 작업으로 남는다. 새 과제를 늘리지 않는다.
