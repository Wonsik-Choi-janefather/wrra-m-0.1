1. 공정한 축약 모형 비교
주파수 gamma는 기존 후보에서 선택하고, 총 계수 합2를 유지한다.
J개 선택에서는 기존 계수에4/J배를 적용한다. 이는 명시적 정규화 규칙이며
추가로 최적화한 자유 계수가 아니다. 기존 offset·xi·8프레임을 유지한다.
각 대안의 h는 같은 P목표5%로 맞춘다. D판독과 alpha가 같아26.8%는
그대로 유지되고 R은 보존으로68.2%다. SI계수는 다시 맞추지 않았다.
1개4조합,2개6조합,3개4조합,4개1조합을 모두 검사했다.
이것은 정한 유한 후보군의 전체 비교이며 모든 주파수·구조의 전체 탐색은 아니다.

2. 가장 가까운 축약안
기존 판독과의 거리 L1_w=sum_n w(n)|P_alt(n)-P_ref(n)|를 사용했다.
이 값은 두 내부 계산의 차이지 관측 적합도나 실측 우열 점수가 아니다.
가장 가까운 축약안은 주파수1·2를 사용하는2모드다.
그 h는1.5934345200906517이며, 같은 구성비를 재현한다.

다른 모형의 관측 실패나 현재 모형의 관측 우위를 입증한 것은 아니다.

3. 구조 변경과 실행 변경을 구분한다
모드를 줄인 구조는 보정 이후에도 주소 판독을 바꾼다.
회전 재귀/직접식/청크 변경은 같은 주소 판독·프레임·부하를 유지한다.
따라서 선택할 수 있는 것은 두 종류다.
- 축약 설명 모형: 같은 알려진 구성비를 설명하고 다른 조건부 출력을 내는 대안.
- 같은 설명의 실행 개선: 현재 모형의 결과를 유지하며 계산·저장 비용을 바꾸는 구현.
기존 모형의 주소/위상 설명을 유지하려는 이번 실행 보완에서는 후자를 채택한다.
모든 축약 대안을 배제하거나 우주의 유일한 구조를 정했다고 말하지 않는다.

4. 이론적 최소성의 정확한 위치
현재 네 모드 생성열은 비영인8개 독립 지수항으로 표현되므로, 그 생성열을
같게 유지하는 시간 불변 실수 선형 구현은8상태 이상이어야 한다.
회전 구현은8상태로 하한을 달성한다. 이는 현재 위상 생성 규칙에서
불필요한 선형 상태가 없음을 뜻한다.
두 모드 생성열은 다른4상태 규칙으로 표현할 수 있다. 그것이 더 작다는
것과 현재 생성열을 같은 상태4개로 줄일 수 있다는 것은 다른 주장이다.
이 하한은4모드의 발생 원인,8프레임 경계의 물리적 필연성, 공통운반자
채널 수 또는 모든 비선형 부호화의 최소성을 도출하지 않는다.

5. 현재 선택 판정
기존 구성비·주소/위상·내부 준비·기록·부하 설명을 유지하는 보완안:
4모드 생성 규칙 유지,8실수 회전 상태,청크 스트리밍 구현.
구성비만 설명하는 축약 층: 상수 허용 모형도 정당한 대안으로 기록.
더 적은 위상 모드도 동일 구성비를 설명하는 별도 조건부 모형으로 보존.
최소계산을 '무조건 가장 적은 숫자/모드'가 아니라, 명시한 같은 설명을
수행하는 비용과 최소 상태 수로 판정한다. 서로 다른 설명 범위의
모형은 그 차이를 기록한 뒤 비교한다.
이번 비교·선택 근거는 마련됐다. 기존 입력이 우주에서 선택되는 전
과정까지 해결하거나 전체3.0 이론이 완료됐다고 확대하지 않는다.
발생 원인의 전역 도출이나 독립예측을 새 완료 조건으로 요구하지 않는다.
