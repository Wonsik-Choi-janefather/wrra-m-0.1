1. 이론적 보완
주소를 표시 번호만으로 정의하지 않고, 유한 곱셈 관계와 비용을 가진 객체로 정의한다.
A_N은 단위 1, 소인수 조립 관계, 허용 경계, 비용 및 판독 규칙을 포함한다.
표시 번호는 이 구조를 나타내는 하나의 좌표다.
표시 번호를 바꿀 때 관계·비용·상태 가중치·필터도 같은 객체에 따라 옮긴다.
따라서 새 표시 번호가 짝수인지 또는 소수인지를 새로 계산하는 것이 아니다.

소인수 좌표를 v_p(n)으로 쓰면 다음이 성립한다.
n = product_p p^(v_p(n)).
Omega(n) = sum_p v_p(n).
kappa(n) = sum_p v_p(n)*log(p) = log(n).

unit: n=1, Omega=0, kappa=0. 기존 비활성 기준이다.
prime atom: Omega=1.
composite with the minimum-cost prime: Omega>=2 and v_2>=1.
composite without the minimum-cost prime: Omega>=2 and v_2=0.

이는 기존 소수/짝수 합성수/홀수 합성수 분류를 재현한다.
소수 2는 원자이므로 합성수 D부문에 포함되지 않는다.
이 세 유형에 복귀/잔존/표현형 가능 판독을 부여하는 것은 기존 필터 규칙으로 유지한다.
소수 분류만으로 입자 종류나 실제 질량을 도출했다고 주장하지 않는다.

2. 최소계산과 기존 위상식의 연결
기존 주소 비용 log(n)을 소인수별 비용의 합으로 계산할 수 있다.
고정된 원자 비용 kappa(p)=log(p) 아래 최소 비용 원자는 2다.
기존 짝수 판독은 '최소 비용 원자를 포함하는 합성 구조'를 읽는 규칙으로 표현할 수 있다.
그 원자를 D부문에 대응시키는 물리적 판독은 구성 규칙이며 이번 시험에서 근원 법칙으로 증명하지 않았다.

위상 신호는 U_j(n)=exp(i*gamma_j*kappa(n))이다.
허용된 곱셈에서 U_j(ab)=U_j(a)*U_j(b)가 성립한다.
따라서 기존 제타 위상 필터는 소인수별 위상의 조립으로 정확히 계산된다.
프레임 위상과 스펙트럼 오프셋은 조립 후 한 번 적용한다.
소인수마다 프레임 오프셋을 반복해서 더하지 않는다.

원시 가중치 b(n)=exp(-alpha*kappa(n))도 b(ab)=b(a)*b(b)이다.
정규화된 w(n)=b(n)/Z는 w(ab)=Z*w(a)*w(b)이며 Z를 생략하지 않는다.
이 연결은 이미 알려진 로그 항등식을 WRRA의 기존 위상·필터·장부 안에서
실제 재계산한 설명 성과다. 새 숫자를 만들어야만 성과가 된다는 기준은 쓰지 않는다.

3. 유한 영역의 조립
a*b<=N일 때만 해당 곱셈 주소를 허용한다.
a*b>N이면 이번 SOURCE 밖의 연산으로 거절한다.
거절이 실제 물리적 복귀 에너지를 발생시킨다는 추가 해석은 하지 않는다.
정체성 좌표의 소인수 합성은 교환적이지만 부품 활성화·발생 순서는 별도 장부다.
주소105의 인수3·5·7을 유지하는 것이 조립 순서별 활성 부품 수까지 같게 만든다는 뜻은 아니다.

4. 전 주소 검사와 재현
1,014,999개 실행 주소 전체에서 소인수 좌표 분류가 기존 분류와 일치했다.
가산 비용·위상 필터·가중치를 구조적 좌표로 재구현해 기존 출력과 대조했다.
가산 비용과 log(n)의 최대 오차는 3.552713678800501e-15였다.
허용 곱셈 1,000쌍에서 인수 개수의 가산과 원시 위상·가중치 합성을 검사했다.
위상 합성 최대 오차는 1.7055009632808765e-13이었다.

구성비: 0.050000000000000176 / 0.26800000000000074 / 0.6820000000000006.
기준 q=-0.5285585894376319.
회전 약207.5102418659153 km/s, 조건부 렌즈 약0.5355822400088303 arcsec.
상류 및 SI 계수를 보정하지 않았다.

5. 번호 변경과 구조 변경의 구분
3개의 전체 무작위 번호 순열에서 관계·가중치·비용·효과를 함께 이동했다.
구성비 최대 오차는 3.34e-15 미만, 부하 최대 오차는 2.00e-14 미만이었다.
SOURCE 좌표(l,h,z)의 빠른 축/느린 축을 바꾸는 6가지 직렬화에서도
동일한 구조를 전달하면 구성비·부하가 보존됐다.
유한 곱셈 관계를 새 번호로 옮기는 샘플 연산도 검사했다.

반면 비용·가중치를 유지하고 판독 효과만 재배정하는 대조 시험은 결과를 바꿨다.
2와4의 판독 재배정: 약5% / 52.95312513% / 42.04687487%.
9와11의 판독 재배정: 약4.44279755% / 26.8% / 68.75720245%.
이 시험은 같은 우주의 좌표 변경이 아니라 판독 규칙 변경이다.

6. 최소 원자 선택의 대조
다른 원자를 잔존 판독 기준으로 쓰고 계수는 고정했다.
기준 원자2: 약5% / 26.8% / 68.2%.
기준 원자3: 약17.47540370% / 12.40550059% / 70.11909571%.
기준 원자5: 약24.13505849% / 4.70074781% / 71.16419370%.
이는 원자 선택이 실제 분할에 관여한다는 민감도 시험이다.
원자2가 모든 가능한 물리 이론에서 유일하다는 증명이나 대체 모형을 다시 보정한 비교는 아니다.

7. 현재 판정
산술 구조를 가진 주소 -> 소인수 비용 -> 기존 위상/가중치/필터의 계산 연결을 보완했다.
숫자 표기의 변경에 따른 가짜 의존성과 실제 구조·판독 규칙 변경을 구분했다.
이것은 명시된 산술 LAW 안에서 성립하는 구조적 연결 결과다.
산술 LAW 자체의 물리적 발생 원인이나 소수->입자 종류의 독립 도출을 해결했다고 확대하지 않는다.
이번 v0.1은 2단계의 계산·이론 정리본이며 아직 별도 재검토 후의 최종 완료본은 아니다.

재현: python address_structure.py
의존성: numpy, scipy.
Step-1 검토본의 원본과 macro 함수를 고정해 재사용한다.
