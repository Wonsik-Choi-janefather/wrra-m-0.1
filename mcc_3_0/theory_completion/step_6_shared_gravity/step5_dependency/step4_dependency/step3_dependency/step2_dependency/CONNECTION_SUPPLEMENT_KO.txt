WRRA 3.0 이론 보완 2단계 v0.3 — 주소·운반자·기록 연결

검증 입력: 고정 2단계 주소 상태와 SI 계수, 기존 Carrier 클래스,
기존 단일 측정 사례의 내부 에너지 간격·기록 간격·준비 강도·측정 기저.
WRRA 고유 변환: 동일 주소 판독 -> 부하 모멘트 및 조건부 준비 ->
운반자 상태의 연산자 기대값 -> 단일 쓰기 -> 공급·기록·물리 에너지 장부.
산출값: 균일/패킷 운반자 4조건에서 연결 계산, 주소-내부 상관의 비영 값,
유한 공급으로 쓰기 비용 충당, 포함 경계의 에너지 및 q 보존.
반증조건: 주소 재표시가 준비·부하를 바꿈, 공동 상태를 평균의 곱으로
대체해 상관을 잃음, 에너지를 두 번 더함, 공급 음수, 같은 에너지 함수와
압력의 불일치. 추가15개 검사 통과.

1. 연결 계약
주소 모멘트 mu_s=sum_n w(n)E_s(n)g_s(n)는 v0.1과 같은 값을 사용한다.
거시 부하 운반자는 기존128차원 격자 모델의 A=(I,Kc/2,Kb/2)다.
부문 에너지 E_s=V0*eta_s*mu_s*Tr(rho A_s).
균일 rho=I/128에서는 세 부하가1이므로 앞선 거시 계산을 그대로 재현한다.
기존 패킷 상태와 비가환 강도8에서도 같은 mu와 eta로 부하를 계산했다.
운반자 기저 순열에 상태와 연산자를 함께 옮기면 부하가 보존됐다.
이는 실행된 기존 부하 운반자 연결이다.128차원 격자와 CCS-15 채널 공간은
같다고 선언하지 않는다. 양자를 연결하는 전체 대응 연산자를 이번 계산에서
실행했다고 주장하지 않는다. 채널 수·주소 수·운반자 격자 크기를 구분한다.

2. 주소와 내부 준비의 공동 장부
기존 bridge_0_2의 선택 규칙은 '3으로 나누어짐'이 아니라 v_3(n)이 홀수인
주소다. 선택한 소수의 지수 좌표를 이용해 그 규칙을 유지한다.
조건부 표현형 가중치 pi(n)=w(n)E_P(n)/f_P,
선택 몫 t=sum_n pi(n)1[v_3(n) odd], 준비 인구 p=.2*t.
이번 고정 위상 필터에서는 t=.4020461347060741, p=.08040922694121483.
이전 사례의 t=.3998832725128894를 그대로 복사하지 않았다.
이전 준비는 이전 분기 모형에서 나온 것이며, 차이를 SOURCE 용량 변화만의
효과라고 해석하지 않는다.

응답 r(n)=1+.25*log(n)/log(N)에 대해
J_joint=sum_n pi(n)r(n)*.2*selector(n)=.08549046481975917.
J_product=(sum_n pi(n)r(n))*p=.08516449658539786.
차이=.0003259682343613513으로 비영이다.
이는 내부 준비와 주소 응답의 공분산이다. 별도 물리 에너지로 추가하지 않는다.
주소에 민감한 관측에서는 공동 장부를 계산해야 하며, 주변 평균의 곱으로
자동 대체하지 않는다. 동일 주소를 재표시할 때 선택 규칙도 같이 전달한다.

3. 기존 단일 쓰기 규칙과 연결
내부 에너지 간격431.08124431500187MeV와 기록 간격
3.559611212147983e-15J는 기존 공개 계산 결과에서 고정 입력으로 가져왔다.
이번에는 원래95차원 내부 Hamiltonian 및450개 검사를 전체 재실행한 것이
아니다. 그 두 모드 간격을 입력으로 받은2상태 쓰기 행렬을 실제 계산했다.
기존 X 측정 기저와 W=P_plus tensor I+P_minus tensor X를 유지했다.

준비된 정지·여기 에너지의 합이 현재 표현형 예산을 한 번 대체하도록
평균 점유수 nbar=E_P/(m_rest+p*gap)를 계산했다.
이는 조건부 평균 예산 모형이며 분수 개의 실현 양성자를 뜻하지 않는다.
기록 쓰기 이후 증가량:
내부 상태:7.0288444093013494e-12J.
기록:4.316791266963542e-16J.
합계 공급:7.029276088428041e-12J.
공급 전:7.561582499072275e-12J.
공급 후:5.323064106442342e-13J.
두 조건부 분기 모두 유한 공급 한도 안에 있다.
공급에서 같은 비용을 차감해 포함 경계의 전체 에너지가 보존된다.
기록은 표현형 내부 예산 항목이며 제4우주 부문으로 추가하지 않는다.
8프레임의 판독 기여 각각을 실제 기록 쓰기 비용으로 계산하지 않는다.

4. 경계와 압력
이 단일 쓰기는 고정 부피에서 압력 없는 상태·기록 증가로 모델링한다.
R의 기존 E_R(V)=E_R(V0)*V/V0를 유지하므로 P=-E_R(V0)/V0다.
시스템만 볼 때 공급 유입으로 진단 q는
-.5285585894376319 -> -.5192163980944755로 바뀐다.
공급을 포함한 경계에서는 q=-.5185158489464727로 전후 같다.
이것은 포함 경계의 현재 에너지·압력 일관성 검사이며, 단일 양성자 쓰기가
실제 우주의 q를 이 크기로 바꾼다는 관측 주장이 아니다.

5. 지금 보완한 것과 범위
주소 정체성·선택·부하·기록을 연결할 때 필요한 계산 계약을 명시하고
실행했다. 균일 상태에만 숨겨져 있던 운반자 계수를 패킷 상태에서도
확인했고, 공동 주소-내부 상관과 기록 공급을 잃지 않는 연결을 마련했다.
계수 재보정 없이 기존 경로를 유지했다.
CCS-15 전체 연결, 입자별 판독 완성, 반복 쓰기·소거 누적 비용은 이번
결과의 검증 범위가 아니다. 새로운 완료 조건을 추가하는 대신 현재
실제 실행 경로와 별도 연결 범위를 구별해 기록한다.
이 v0.3으로 전체 이론 또는2단계 최종 완료를 선언하지 않는다.
