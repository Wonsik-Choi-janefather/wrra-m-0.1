# 부록 J. 실행 보강과 표기·판정의 편집 기준

## J.1 검증 입력과 판본 범위

v0.28-r5의 한·영 전체본을 보존하고, KZF 엄밀성 v1.0, SPARC 벤치마킹 v0.3, 반증 조건 v0.4의 실제 기록을 연결한다. 이 부록은 문서에 결과를 통합한 것이다. 별도 코드들을 하나의 전 우주 실행 경로에 접합했다는 뜻이 아니다. 현 판은 v0.28-r6이며 DOI는 https://doi.org/10.5281/zenodo.23551789 이다. 과거 DOI는 그 판의 출판 기록이다.

읽기 순서는 검증 입력 → WRRA 고유 변환 → 산출값 → 반증조건 → 결론이다. 알려진 관측과 상수는 정당한 보정 입력이고, WRRA 구조를 통한 재현은 설명 성과다. 새 수치의 독립예측을 독창성의 필수조건으로 요구하지 않는다.

## J.2 의미·단위·타입 표준

기존 수식의 지역 기호는 유지한다. 아래 구분용 별칭은 문맥을 연결하는 편집 규칙이며 원전의 변수명을 바꾸거나 새로운 물리량을 더하는 규칙이 아니다.

| 원 기호 / 구분용 별칭 | 의미·단위·경계 |
|---|---|
| $g_b,g_{obs}$ | 바리온·관측 중력가속도, m/s$^2$ |
| $g_{opt}$ | 122장의 광학 결합 계수, 무차원; 원전의 $g$ |
| $g_{\mu\nu},\det g$ | 계량과 그 행렬식; 좌표·단위 규약에 종속 |
| $L_{addr}$ | SOURCE 정수 해상도500, 무차원; 원전의 $L$ |
| $L_{eff},D_{path}$ | 광학 유효 노출량과 광로차, 각각 m; 서로 같다고 가정하지 않음 |
| $H_{reg}$ | 하모닉 최대값으로 채택한 레지스터 크기29; 직렬화 $h=0,\ldots,28$ |
| $H_{Hub},\widehat H$ | 허블률(s$^{-1}$)과 Hamiltonian(물리형은 에너지); 무차원 생성기와 구별 |
| $C_{zero},\Sigma_{obs}$ | 영점 개수70과 측정 공분산; 공분산 원소의 단위는 두 관측량 단위의 곱(분산은 단위의 제곱) |
| $Q_{gate},Q_{stat},Q_A^\nu$ | Boolean 허가, 무차원 잔차 통계량, 에너지운동량 교환 벡터 |
| $B_{bar},E_{ledger},origin\_id$ | 바리온 수, 장부 에너지(MeV 또는 명시한 단위), 원천 식별자 |
| $N_{active\ parts},N_{reserve}$ | 활성 부품 수와 예비 원천 수; 부품 하나가 여러 원천을 포함할 수 있음 |
| $A,p,s,q_{curv},t_{turn}$ | 피팅의 진폭·구배·별 배율·곡률·전환 반경비, 모두 무차원 |
| $R,R_{pivot},R_t$ | 물리 반경, 기준 반경, 전환 반경; 피팅에서는 kpc, $R_t=t_{turn}R_{pivot}$ |
| $k_{fit},k_{wave}$ | 추정 모수 개수와 파수; 전자는 정수, 후자는 역길이 |

곡률형의 $q_{curv}$는 우주 감속계수 $q_0$가 아니며, 전환형의 $t_{turn}$은 물리 시간이 아니다. $A_m$은 제타 출력 포트 연산자이고 피팅 진폭 $A$와 다르다. 타입·정의역·단위가 다른 같은 문자를 서로 대입하지 않는다.

본문의 바리온 수·활성 부품 수·주소 수·원시 부품 종류 수는 별도 계수다. 미사용 원천은 inactive reserve(비활성 예비자원)로 남을 수 있다. 에너지의 개별 원천별 분배가 정의되지 않은 집계 항목은 임의 균등분배하지 않는다. WRRA 명칭의 역사적 표기는 해당 원전과137장의 설명을 따르며, 편집 과정에서 임의의 새 약자 풀이를 넣지 않는다.

단위 변환은 수치와 함께 명시한다. $u=\rho_{mass}c^2$의 에너지 밀도는 J/m$^3$이고 압력 Pa와 동차원이다. MeV 장부와 SI 장부를 연결할 때 변환 인자를 기록한다. 무차원 수치 생성기와 물리 Hamiltonian을 같은 객체로 표시하지 않는다. 공분산·잔차·AIC·BIC는 어떤 관측 우도와 정의를 사용했는지 함께 제시한다.

## J.3 수학·계산 보강 기록

KZF 입력의 정확 유리수 분모와 하모닉 규약, $\gamma<T$의 엄격한 경계를 적용했다. $L=500,H=29,C=70$, 주소1,015,000개이며 비활성 기준1개·소수79,608개·짝수 합성수507,499개·홀수 합성수427,892개다. 주소의 활성 영역1,014,999개는 물질 입자 수가 아니다.

기존 검사15/15, 신규 경계·예외 검사44/44, 격리 훼손9/9 탐지와 전체 주소 장부 대조는 동봉 패키지의 실제 기록이다. 전달된 H를 무시하는 원본 동작, C=0 처리, 경계 포함 규약을 검증용 구현에서 보강했다. 원래 공개 코드의 전역 실행 경로를 이미 교체했다고 표시하지 않는다.

Euler–Maclaurin 절단오차와 부동소수점 반올림오차를 구분했다. 절단을 늘려도 float64 오차가 단조 감소하지 않는 실제 사례를 남겼다. 유한 영점 검산은 RH의 증명이 아니며50/80자리 비교는 같은 mpmath 계열의 검사다.

## J.4 관측 보강 기록

동일 SPARC 표본과 오차, 은하별 별 질량광도비 배율을 사용했다. 아래는 고신뢰도9개 은하·257점의 전체 피팅이다. NFW는 은하당3모수, 두 신규 WRRA 후보는4모수이며 추가 자유도를 반영했다. BIC는 은하별 $\chi^2+k\log n$의 합이다.

| 모형 | $\chi^2$ | AIC | BIC |
|---|---:|---:|---:|
| NFW | 1013.78 | 1067.78 | 1100.83 |
| WRRA 곡률형 | 784.13 | 856.13 | 900.20 |
| WRRA 전환형 | 951.80 | 1023.80 | 1067.86 |

$x=R/R_{pivot}$에 대해 곡률형은 $a_T=a_{T0}A\exp[p\ln x+q_{curv}(\ln x)^2]$, 전환형은 $a_T=a_{T0}Ax^p(1+1/t_{turn})/(1+x/t_{turn})$이다. 두 후보 모두 기존 $g=g_b/[1-\exp(-\sqrt{g_b/a_T})]$를 실제 호출한다. 이는 관측으로 보정한 응력 응답의 확장이며 새 공변 장 방정식의 유도로 표시하지 않는다.

| 가린 관측점 검사 | NFW 점당 $\chi^2$ | 곡률형 | 전환형 |
|---|---:|---:|---:|
| 교차 간격48점 | 2.0505 | 1.6763 | 2.3564 |
| 외곽20%,56점 | 15.2907 | 48.1963 | 4.2500 |

곡률형은 전체 피팅과 교차 간격에서 우수하지만 외곽에서 악화된다. 전환형은 외곽에서 우수하지만 교차 간격에서는 NFW보다 나쁘다. 서로 다른 후보의 최고값을 하나의 모형 성과로 합치지 않는다. 은하별 BIC 우위는 각각3/9와2/9이며 bootstrap 구간은0을 포함한다. 합산 피팅 우위를 모든 은하의 우위로 확대하지 않는다. 후보 탐색은 기존 결과를 본 뒤 진행했으며 새 외부 표본의 확증 검정이 아니다. 렌징·CMB·BTFR 별도 회귀 완료도 뜻하지 않는다.

## J.5 반증·개정·실행 상태

실패를 입력·구현, 동결 분기, 공동 연결, 핵심 보존·인과 계약의 네 범위로 기록한다. 핵심 반례가 성립하면 그 명제와 의존하는 하류 결과를 재검토한다. 개별 후보의 실패만으로 모든 구조를 기각하지 않는다. 허용한 공통 모수·방해변수를 포함해도 공동 출력이 양립하지 않으면 해당 연결을 수정한다. 최적화 한 번의 실패를 허용 영역의 공집합 증명으로 취급하지 않는다.

새 판정기의 종료0은 관측된 비교 우위 또는 기각되지 않음,1은 해당 주장 실패 또는 동결 분기 기각,2는 입력 오류,3은 대응 미확인 또는 모집단 우위 미확정이다. 이는 판정기별 규약이며 책의 모든 과거 프로그램 종료코드를 소급해 재해석하지 않는다.

실제 SPARC 결과의 주장별12건을 판정하고 새 규칙11/11, 기존 광학 합성검사22/22를 실행했다. 곡률형 외곽 우위와 전환형 교차 간격 우위는 종료1이다. 광학의 자연계 결합이 미확정이면 무신호를 물리적 반증으로 선언하지 않는다. 합성검사 성공은 실제 광학 관측의 완료가 아니다.

보정 수정은 정당한 모형 구성이다. 다만 이전 버전의 입력·모수·실패 기록을 보존하고, 새 가정·자유도·영향받는 출력을 공개한다. 동일 출력에 대한 사후 몰래 재맞춤은 허용하지 않는다. 새 버전의 성공으로 구버전 실패를 지우지 않는다.

## J.6 재현·편집 범위와 결론

부록 J는 1~3번 별도 보강 결과를 한영 문서에 반영하고 기호·단위·역할을 연결한다. 동봉 코드 ZIP은 원래 실행 로그를 보존한다. 이번 편집에서는 그 검사를 다시 실행한 것으로 더하지 않는다. 자동 문서 검사는 원문 보존·기존 수식 보존·목차 식별자·이미지 파일 존재·한영 수치 표를 확인한다. 이는 모든 수식의 의미적 무오류나 물리학 전체의 참을 인증하는 검사가 아니다.

판본은 v0.28-r6, DOI는10.5281/zenodo.23551789이며 이전 출판 DOI는23550759다. 온라인 반영 기록은 저장소 PUBLICATION_RESULT.json에서 확인한다. KDP 등록·판형 검증은 수행하지 않았다. 재현 패키지와 문서의 연결은 제공하지만 전체 우주 실행 통합은 별도 검증 범위다.
