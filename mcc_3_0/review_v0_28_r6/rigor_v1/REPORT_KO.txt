최소계산우주론 3.0 — KZF 수학·계산 엄밀성 보강 v1.0
최원식 · 최정인 | 2026-10-22

1. 검증 입력
본문 v0.28-r5의 37–39장·38.A·38.B와 공개 코드 upstream/finite_klein_zeta_window_v0_1/code/compute.py를 대조했다. 기준 커밋은 51f96eb72d25a2043bdee701a2d6952c2c340a9e이다. 원본 코드 SHA-256은 004410b1673ef4c6d1996b18ec32b8c54c6098739bc433214d40bb8efdff07fa이며 바이트 단위 일치를 확인했다.
입력 비율 문자열 0.05·0.268·0.682를 정확 유리수로 읽어 L을 계산한다. 하모닉 장부(0,5,29)의 최대값으로 H를 택하고 T=2πH보다 작은 양의 제타 영점을 센다. α=1.8996876950554356은 기존 동결 입력이다. 기존 관측·상수·보정값의 사용은 모형 구성으로 명시한다.
H=29는 하모닉 0부터29까지의 모든 값의 개수30이 아니다. 기존 구성은 최대 하모닉 값을 곱 영역의 크기로 채택하며, 직렬화 인덱스 h는0부터28이다. 이 인덱스와 물리 하모닉 번호를 구분한다.

2. WRRA 고유 변환
L=lcm(20,250,500), C=#{0<γ<T}, N=LHC. n=1+ell+L[h+H(z−1)]로 직렬화한다.
일대일 대응의 산술 근거: q=n−1을 L로 나눈 나머지가 ell이고, 몫을 H로 나눈 나머지가 h, 그 몫+1이 z다. 유클리드 나눗셈의 유일성으로 허용 영역에서 역함수가 유일하다. 총량의 처음·마지막 값만 확인하는 기존 검사에서 전체 저장 행과 역변환을 대조하는 검사로 보완했다.
주소1은 비활성 기준이다. 2이상에서 소수, 소수가 아닌 짝수, 소수가 아닌 홀수는 배타적이며 전체를 덮는다. 2를 짝수 합성수로 분류하지 않는다. 원천 바리온 개수나 활성 부품 수와 이 주소 분류 개수는 다른 장부다.
Klein형 끝단 규약은 원본 inherited_phase_bridge.py의 ell→−ell mod L 반사를 계승한다. 신규 모듈에서는 z를1부터 세도록 바꿔 직렬화 표기와 맞춘다. 한 바퀴의 반사와 두 바퀴 복귀는 이 좌표 규약의 성질이다.

확인하고 보완한 구현 문제
• 원본 zeta_focus_count(H_value,...)의 스캔은 전역 H를 사용한다. 합성 영점 입력으로 H=3인데29행을 생성하는 문제를 재현했다. 새 window는 전달받은 H만 사용한다.
• 작은 H에서 C=0이면 원본은 max([])에서 실패한다. 새 구현은 빈 스펙트럼을 명시적으로 반환하고 주소 접근은 거부한다.
• 본문은 γ<T인데 원본은 γ<=T를 허용하는 종료 규칙이다. 정상 H=29 결과에는 차이가 없으나, 새 spectral_count는 엄격한 <를 사용한다. 경계와 정확히 같은 합성 값의 제외를 검사했다.
• 잘못된 좌표·정수가 아닌 인덱스·NaN·s=1 극점·수치 언더플로는 명시적 오류로 거부한다. 200만 주소 등 계산 예산은 실행 보호 규약이며 물리적 상한이 아니다. 입력 소수점 자릿수 변경으로 L이10000이 되는 사례도 검사했다.

3. 산출값
기존 원전 정상 검사 15/15 통과(종료0). 신규 계약 검사 44/44 통과. 독립 검증기가1,015,000개 저장 행의 주소·좌표·분류·가중치를 대조해 종료0.
L=500, H=29, C=70; 전체 주소1,015,000개, 활성 주소 영역1,014,999개.
비활성 기준1개 / 소수79,608개 / 짝수 합성수507,499개 / 홀수 합성수427,892개.
독립 검증기는 생성기의 최소소인수 체와 다른 Boolean Eratosthenes 체를 사용한다. 생성기 PASS와 해시를 신뢰하는 대신 실제 행을 재계산한다. 영점 비교는50자리/80자리 정밀도지만 같은 mpmath 계열을 사용하므로 독립된 영점 라이브러리의 교차 인증은 아니다.
T−γ70=0.0052954238415459154, γ71−T=2.662093940179501이다. 경계 이동이 이 여유를 넘으면 C가 바뀔 수 있다. H와C는 독립 측정값이 아니다.

Euler–Maclaurin 절단과 반올림을 분리했다. 기존 B2·B4 surrogate에서 생략된 B6항과 주기 Bernoulli 나머지로 정확산술 절단 상한을 구성했다. σ=Re(s)>−5, s≠1, 정수 M≥2에서
|error| ≤ |(s)5| M^(−σ−5)/30240 + [2ζ(6)/(2π)^6] |(s)6| M^(−σ−5)/(σ+5).
(s)k는 상승 계승이다. 첫 항은 생략된 B6항, 두 번째 항은 |B6(periodic)|≤2·6!·ζ(6)/(2π)^6와 적분으로 얻는다. 이는 절단 M 증가에 대한 정확산술 수렴을 제어한다. N_U는 반복 극한이 아니라 유한 곱의 정확한 개수다.
γ70의 50자리·80자리 계산에서:
M=7250: 실제 비교 오차3.896386e−15 / 상한1.330347e−13.
M=14500: 실제 비교 오차8.609777e−17 / 상한2.939680e−15.
M=29000: 실제 비교 오차1.902504e−18 / 상한6.495837e−17.
반면 동일한 반올림 입력에 대한 float64 오차는 약1.281e−13,6.671e−14,1.514e−13이다. 절단을 늘리면 float64 결과도 무조건 더 정확해진다는 주장은 성립하지 않는다. 이 상한은 부동소수점 반올림 전체의 구간 인증이 아니며, 표준 영점 수 자체를 이 surrogate만으로 처음부터 증명한 것도 아니다.

특히 분류 개수를 보존한 바꿔치기와 정규화 합1을 보존한 가중치 바꿔치기도 실패한다. 파일 해시가 달라졌다는 이유만으로 거부하는 검사가 아니다. 정상 요약을 그대로 둔 상태에서 내부 내용 위반을 탐지한다.
선언한 유리수 입력·하모닉 선택·위상창을 바꿀 때는 L,H,C부터 재계산한다. 변경된 입력에서도 무조건1,015,000을 반환하면 실패다. 실제 하류의 원천 소유권·에너지 장부 전체를 새 모듈로 교체했다는 주장은 하지 않는다.

5. 결론
기존 KZF 구조와 알려진 입력의 재현을 유지하면서 주소 전수 검증, 명시적 예외 처리, 독립 저장 장부 검사, 훼손 탐지와 절단오차 설명을 실제 코드로 보강했다. 이는 WRRA의 유한 SOURCE 구성·연결에 대한 계산적 성과다. 수론 구조에서 관측 입력의 물리적 선택까지 새로 입증했다는 뜻은 아니다. 전 우주 실행 완료와는 범위를 구분한다.
기존 공개 원본은 변경하지 않았다. core.py는 이번에 추가한 검증용 보강 구현이며 공개본의 전역 실행 경로에 이미 통합됐다고 표시하지 않는다. BOOK_38C_KO.txt에 본문 반영 문안을 제공한다.
