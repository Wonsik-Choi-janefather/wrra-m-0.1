# 부록 H — 반증조건·OPEN 연결과 한영 용어표

## H.1 이 목록을 읽는 방법

평가 순서는 **검증 입력 → WRRA 고유 변환 → 산출값 → 반증조건**이다. 아래 표는 현행 누적본의 핵심 계약을 찾기 위한 색인이다. 각 장·원전의 정의와 명시한 허용오차가 개별 검사를 지배한다. 이 목록은 계산을 재실행하거나 과거 산출을 변경하지 않으며 미완료 과제를 모두 실패로 바꾸지 않는다. 알려진 상수·관측은 정당한 구성·보정 입력이고, 선언한 구조로 재현하면 설명·정합성 성과다. 새 독립 예측은 그 성과의 필수조건이 아니다. 모형 고정 뒤 계산한 미측정량은 해당 모형의 예측으로 기록한다.

OPEN 연결은 아직 제공하지 않은 내용을 표시하며 좁은 완료 계산을 그 자체로 반증하지 않는다. 반대로 선언한 비교의 실패는 그 범위의 실패로 유지한다. 예를 들어 138장의 선택 개수 불일치를 수치 수렴과 함께 남긴다. WRRA와 통상 대조 모형에 같은 기준을 적용한다.

## H.3 경계 규칙: 실행·인과율과 계승 물리

재생은 구조에 구현된 관계의 실행이다. 외부 컴퓨터·우주의 선행 완료 연산·미리 녹화한 미래를 가정하지 않는다. 이 책의 수치 코드는 명세된 구조를 계산·검사하는 도구이며, 코드가 존재한다는 사실만으로 자연이 그 코드를 실행한다고 입증되지 않는다.

타입 장부는 각 양의 타입·소유자·단위·허용 전달·갱신 규칙을 지정한다. 구현의 감사를 가능하게 하지만 장부 형식만으로 국소 인과율이나 에너지 보존이 유도되지는 않는다. 물리 구현은 공급자·수신자를 포함하는 국소 균형 법칙과 인과·사건 순서를 함께 명세해야 한다. 136장의 $\nabla_\mu T_A^{\mu\nu}=Q_A^\nu$, $\sum_AQ_A^\nu=0$는 실제 구현한 유효 전환 계약이며 미래의 모든 미시 모듈에 대한 보존 증명은 아니다.

모듈 경계에서는 입력 상태·단위·소유자를 정하고, 채택한 SM·GR 수신계와 근사를 명시하며, 유효 원천을 이중 계상하지 않고 필요한 전체 상태를 전달한 뒤 선언한 오차 노름으로 제약·보존·좌표 대응·수렴을 확인한다. 필요한 전환·수신계가 빠졌으면 접합을 OPEN/PARTIAL로 표시하고 독립 결과는 검사한 범위에서 유지한다. 이는 기존 소유권·접합 실행을 요약한 것으로, 아직 실행하지 않은 컷오프 매칭 알고리즘을 도입한 것이 아니다. 보편적 플랑크 영역 오차 한계나 강한 장의 이산–연속 매칭을 확립하지 않았다. 135장의 국소 블랙홀 보강도 그 빠진 접합을 대신하지 않는다.

## H.5 v0.28: 다섯 추가 검증 영역

완전한 식과 실행 산출값은 제139장에, 다섯 행의 반증·OPEN 표는 139.9절에 둔다. 이는 H.2의 기존 시험을 대체하지 않고 확장한다. 스케일링(139.3)은 보존적 전달과 유한 수렴을, 동역학(139.4)은 자원·게이트 및 생성기 에너지 균형을, 중력(139.5)은 경험적 RAR을 유지한 채 명시적으로 채택한 수신기의 공동 회전·렌징을, 제타(139.6)는 포트·에너지·위상·잡음 및 구동 종점을, 자유도(139.7)는 보정값을 고정한 공동 출력과 공개된 검출기·SOURCE 방해변수를 시험한다.

해제한 네 로그 좌표에 대한 중력 응답 계수는 1이며, 네 개를 각각 식별하는 측정이 아니다. 30항목 장부는 적용 범위를 지정한 기록이며 전체 모형의 독립 적합 파라미터 수가 아니다. 초기 유계 감수율의 RAR 실패 분기는 현행 중력 법칙으로 유지하지 않는다. QUMOND는 채택한 방법으로 인용한다. 원래 SOURCE와 CRT 제타 준비를 동일하다고 선언하지 않으며, 뒤틀림 저장 압력을 압력 없는 암흑물질과 동일시하지 않는다. 별도 등록판의 일곱 계산/검산 쌍과 교차 검사 19개가 통과했고, 내부 표본 불변량 1,459개는 독립 실험 수가 아니다. 새로운 SPARC 적합, 완전한 CMB 주입, 입자 스펙트럼, GR/SM 극한 또는 외부 심사를 뜻하지 않는다. 제138장의 Gaia 카운트 템플릿 불일치는 계속 기록한다.

## H.6 v0.28-r1: 132–134장 원전과 실행 근거의 복구

**검증 입력.** 원본 `MCC_3_0_Book_v0.24_Projector_Focus_Complete_Package.zip`(76,970,934바이트)에서 R1–R5 원전 다섯 개를 바이트 그대로 복구했다. 원본 SHA-256은 `09e8f19d163931792b501e36ba6f070d2745916065a592925bfd829cf3072b93`이다. 공개 v0.25 게시 커밋에는 본문은 있었지만 두 원전 폴더가 빠져 있었고, 후속 본문에는 보존 문구가 남았다. 파일 선택이 누락된 구체적인 당시 이유는 확인되지 않았다.

**WRRA 고유 변환.** 132장의 관계계수·이차형식, 133장의 주소 투영·공통 보정, 134장의 상보 모드 대비·비용을 원전 코드로 각각 재생한다. 다섯 계산의 입력·변환·판정을 하나의 원전 계보와 실행 기록으로 연결한다.

**산출값.** 주 계산 5/5가 종료코드 0, 과거 stdout이 있는 4/4가 JSON 일치, 원전 내부 파일 25개의 해시가 일치했다. 새 임시 폴더에서도 원전 프로그램을 실행하고 산출·인증서를 대조했다. 이 개수는 유한 프로그램과 파일 검사 수이며 독립 실험 수가 아니다. 실제 실행 파일은 132.6, 133.4, 134.5절에 명시했다.

**반증조건.** 별도 재현 실행기 `reproduce.py`는 원전 ZIP·보존 출력의 SHA-256, 원전 내부 manifest, 프로세스 종료코드, JSON 출력 및 인증서를 검사한다. 격리한 복사본 ZIP에 바이트를 덧붙이자 `ARCHIVE_OR_RECORD_HASH_MISMATCH`와 종료코드 1로 거부했다. 중첩 과거 연구 전체와 본문의 모든 해석적 논증을 다시 검증한 것은 아니다.

**결론.** 누락 원전은 공개 복구됐으며 해당 유한 계산은 재현됐다. 기존 전체 감사의 ‘132–134장 원전 미확보’ 항목은 해소된다. 다른 모듈의 연결 실패나 미실행 항목까지 해소됐다고 판정하지 않는다. 전체 3.0 실행 검증의 완료 여부와 이 복구의 성과는 별도로 기록한다.

[고정 커밋의 원전·실행기·실제 로그](https://github.com/Wonsik-Choi-janefather/wrra-m-0.1/tree/e5a833afd65c282b06fa1318467362de90156338/mcc_3_0/chapter_132_134_recovery_2026_10_22). 해당 폴더에서 `python reproduce.py`로 재현한다. `PROVENANCE.json`, `SHA256SUMS.json`, `REPLAY_RESULT.json`, `NEGATIVE_TEST.json` 및 `runs_2026_10_22/`가 근거다. 2026-10-17 기록은 `verification/`에 구분 보존한다. 역사적 R1–R5의 상대 링크도 book_v0_25–book_v0_28에 복구됐다.

## H.7 v0.28-r3: 실험 설계와 합성 자료 검증

검증 입력 → WRRA 고유 변환 → 산출값 → 반증조건 → 결론의 순서로 122.1절을 읽는다. 원전은 DOI 10.5281/zenodo.23380920의 보존 패키지에 있는 optical_model_v1_0이며, 입력 프로파일 SHA-256은 `8c53fb73b332db2805b7d614f166511094b54b3f1b2a291fbfdfe46312408d6b`다. 원전 해시 검사 29개, 기존 계산 17+11개, 새 설계 검사 22/22개를 실제 실행했다. 아래 자료는 모두 합성 자료이며 실제 관측 판정이 아니다.

| Case | Q / error | Exit |
|---|---|---:|
| synthetic_nominal | 6.59879688770414 | 0 |
| synthetic_no_loss | 7177.529448321479 | 1 |
| synthetic_missing_revival | 2105.0240834042634 | 1 |
| hash_change | SOURCE_PROFILE_HASH_MISMATCH | 2 |
| order_change | POINT_ORDER_MISMATCH | 2 |
| covariance_invalid | Matrix is not positive definite | 2 |

종료코드 0은 해당 통계 조건에서 기각되지 않음, 1은 동결 분기 기각, 2는 입력 오류다. 오류 자료는 격리된 복사본에서 검사했다. `design.py`는 측정 설계·합성 자료를 생성하고, `verify_observations.py`는 실제 원천 프로파일로 예측을 다시 계산하여 기록의 공분산으로 검정한다. `test_design.py`가 정상·무신호·회복 누락 및 입력 훼손을 실행한다. 전체 패키지에는 실행 로그와 원전 코드를 보존했다. 이 추가 기능은 실험 분석 절차의 검증이며 전체 우주 모형이나 실험적 검증 완료가 아니다.
