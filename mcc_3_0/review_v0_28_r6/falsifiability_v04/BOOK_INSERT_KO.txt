최소계산우주론 3.0 — 반증 조건과 실패 판정 보강 v0.4
2026-10-22 | 본문 반영용 보완 문안·실행 검증 보고서

1. 검증 입력
본문 v0.28-r5의 부록 H.1~H.7, 제139.9절, 앞선 KZF 엄밀성 v1.0과 SPARC 벤치마킹 v0.3을 기준으로 삼았다. 본문에는 이미 원천·장부·수송·CMB·광학·제타·은하에 대한 반증 조건이 있다. 이번 보완은 조건을 새로 발명하기보다, 어느 주장까지 철회하는지와 실제 판정 절차를 연결한다.
SPARC는 앞선 v0.3에서 검증한 비교표와 bootstrap 기록을 읽었다. 이번 단계에서 은하 최적화를 다시 수행한 것으로 세지 않는다. 광학 고정 분기의 설계·합성검사는 복사본에서 다시 실행했다. 실제 실험 관측은 새로 확보하지 않았다.
알려진 상수·관측값은 정당한 보정 입력이다. 자체 구조로 알려진 값을 재현하면 설명·정합성 성과이며, 독립된 새 수치 예측을 성과의 필수조건으로 두지 않는다. 보정된 모형으로 미측정량을 산출하면 그 조건 아래 WRRA의 예측으로 기록한다.

2. WRRA 고유 변환
검증 입력 → 원천·공통운반자·허가·자원 변환 → 표현형 산출 → 주장별 판정으로 연결한다. CLAIM_ID에는 모형 버전, 적용 범위, 입력 해시, 보정에 사용한 자료, 허용 모수 범위, 비교 지표, 오차 모형, 실패 시 영향을 받는 주장을 붙인다.

실패 범위를 네 단계로 구분한다.
A. 입력·구현 실패: 중복 원천, 자원 누락, 잘못된 단위, 수치 비수렴 또는 코드가 명세식을 계산하지 못함. 해당 실행 산출을 무효로 하고 구현을 수정한다. 이 사실만으로 명세된 모든 물리 구조를 기각하지 않는다.
B. 동결 분기 실패: 준비·원천·보정·수신기를 고정한 곡선이 선언한 검정에서 기각됨. 그 버전의 해당 분기를 철회한다. 다른 후보의 성공으로 실패 기록을 대체하지 않는다.
C. 연결 구조 실패: 동일 원천과 하나의 허용 모수 집합으로 동시에 설명해야 하는 출력들이 양립하지 않음. 모든 허용 모수와 명시된 방해변수를 검토했는데 교집합이 공집합이면 그 연결 규칙을 철회하거나 수정한다. 최적화기 한 번의 실패만으로 공집합이 증명되었다고 하지 않는다.
D. 핵심 보존·인과 계약 실패: 명세된 정의역에서 원천 보존·자원 회계·허가·공통운반자 인과 규칙이 서로 양립 불가능하다는 정확 반례가 성립하거나, 충분히 확인된 물리적 대응에서 그 핵심 규칙이 반복적으로 위반됨. 영향을 받는 핵심 명제와 의존하는 하류 설명을 재검토한다. 단독 피팅 실패를 곧바로 이 단계로 확대하지 않는다.

수치적 판정이 없는 선언은 반증 완료로 취급하지 않는다. 반대로 측정 가능한 출력에 연결하지 않은 선언만으로 모든 관측을 설명했다고 주장하지 않는다. 핵심 구조에 치명적인 반례를 회피하려고 새로운 숨은 자원·운반자·개별 출력 보정항을 추가하면, 새 가정과 자유도를 명시한 별도 버전으로 취급한다.

3. 산출값
새 판정기 judge.py는 다음을 구분한다.
종료0: 해당 비교에서 관측된 우위, 또는 명시한 검정에서 기각되지 않음. 자연의 참을 증명한 뜻이 아니다.
종료1: 명시한 우위 주장 실패, 또는 고정 분기 기각. 코드 계산 실패와 구별한다.
종료2: 입력·공분산·분할·재적합 규칙 오류. 물리적 기각으로 세지 않는다.
종료3: 대응 미확인 또는 모집단 우위 미확정. 통과나 기각으로 바꾸지 않는다.

고신뢰도9개·257점 SPARC 결과에서 실제 판정한 값:
곡률형 전체 BIC 차이(WRRA−NFW) −200.6300035: 합산 피팅 우위 성립.
곡률형 교차 간격 test χ² 차이 −17.9578179: 이 분할의 우위 성립.
곡률형 외곽20% test χ² 차이 +1842.7139096: 외곽 우위 주장 실패, 종료1.
전환형 전체 BIC 차이 −32.9664399: 합산 피팅 우위 성립.
전환형 교차 간격 test χ² 차이 +14.6841006: 이 분할의 우위 주장 실패, 종료1.
전환형 외곽20% test χ² 차이 −618.2772374: 이 분할의 우위 성립.
여섯 비교의 모집단 우위는 모두 종료3이다. 은하 단위 bootstrap 구간이0을 포함하고, 후보 선택이 기존 결과를 본 탐색이기 때문이다. 합산 우위라는 관측 사실은 유지하되 보편적 우위와 구별한다.
BIC의 부호 기준은 이번 우위 문장의 논리적 판정이다. 물리 이론 전체의 기각 확률이나 새 유의확률로 바꾸지 않는다. 외곽 구간은 동일 은하의 이미 측정된 자료를 가린 검사이며 미래 관측을 새로 얻은 것은 아니다.

광학 고정 분기 재실행:
128개 원천 프로파일 → 차등 위상 → 유한 합 → 가시도 곡선을 계산하는 기존 설계를 보존했다. 532·1064·1550 nm에서 총9점, 목표 가시도 표준불확도0.01, 알려진 공분산·Gaussian 근사·시험자료 재적합 없음의 조건이다.
기존 test_design.py 22/22 통과. 정상 합성자료 Q=6.59879688770414, 종료0. 손실 없음 합성자료 Q=7177.529448321479, 종료1. 회복 누락 합성자료 Q=2105.0240834042634, 종료1. 입력 해시·순서·공분산 훼손은 각각 종료2.
이 수치들은 합성자료에 대한 실제 코드 실행이다. 자연계에 해당 결합이 구현되었다거나 무신호가 실제로 관측되었다는 뜻이 아니다. 원래 정적 위상식에서는 셔터 간격이 소거되므로 이를 셔터의 직접 검출 실험이라고 부르지 않는다.
새 judge.py 검사11/11 통과: 정상, 불일치, 대응 미확인, 시험자료 재적합, 부적합 공분산, 비유한 수치, 미교정 검정분포, 버전 누락, 단일검정, 다중검정, 비교조건 불일치. 실제 하위 프로세스 종료코드를 검사했다.

4. 반증조건과 실패 후 절차

[원천·자원 장부]
초기 원천 집합 = 활성과 예비 집합의 서로소 합집합이어야 한다. 미사용 자원도 장부에 존재해야 한다. 총 B·E가 맞아도 원천 식별자·전이 이력·소유권이 틀리면 해당 실행은 실패다. 반대로 장부에 이미 보존된 예비자원을 표현형에 나타나지 않는다는 이유로 소멸했다고 판정하지 않는다. 본 단계에서 주소105 코드를 재실행한 것은 아니므로 해당 검사 통과를 새로 계수하지 않는다.

[유한 SOURCE]
명시된 유리수 입력, H 규약, 영점 경계를 고정하고 직렬화·소수 분류·가중치를 검사한다. 입력을 변경하면 L,H,C부터 재계산해야 한다. 정수 항등식의 정확 반례와 부동소수점 오차를 구별한다. 코드가 상수 총량만 출력하는 경우 그 실행의 증거성을 기각한다. 유한 영점 목록 검산만으로 RH나 제타-물리 대응의 필연성이 증명되지는 않는다.

[공동 회전·렌징]
같은 바리온 원천·응력 상태·보정값과 선언한 수신 방정식이 두 출력을 함께 산출해야 한다. 각각 다른 보정값으로 맞췄다면 공동 검증 통과가 아니다. 관측 공분산과 원천 불확도를 포함한 허용 영역이 겹치지 않으면 그 동결 공동 분기를 기각한다. 현재 패키지에는 새로운 렌징 관측 판정이 없으며 실행 상태는 미확인이다.

[관측 곡선]
평가 전에 자료 버전·표본 선택·분할·목적함수·모수 범위·오차 모형·계산 정밀도를 고정한다. 동일 기준을 NFW 등 대조 모형에도 적용한다. 기존 자료를 보고 수정한 후보는 탐색으로 표시한다. 훈련 χ² 감소, 자유도 벌점 포함 비교, 가린 관측점 예측을 따로 보고한다. 이 세 가지를 서로 다른 모형에서 골라 하나의 모형 성과로 합치지 않는다.

[실험 무신호]
먼저 SOURCE 준비, 결합 상수, 유효 노출량, 검출기 응답이 해당 실험에서 확인되어야 한다. 이것이 미확정이면 무신호 판정은 OPEN_MAPPING이다. 확인된 조건에서 고정 예측과 불일치하면 해당 분기를 기각한다. 결합을 사후 임의로0으로 낮추거나 노출량을 다시 정의해 원래 예측을 구제하지 않는다.
Gaussian·알려진 공분산·동결 예측의 경우 Q=(y−μ)^T C⁻¹(y−μ), 자유도는 관측 벡터 차원이다. 공분산 추정이나 시험자료 적합을 추가하면 검정분포를 재교정해야 하며 기존 임계값을 그대로 사용하지 않는다. 새 판정기는 family_alpha/m의 Bonferroni 기준을 지원한다. 검정군 크기 m은 자료를 보기 전에 정해야 한다. 이번 시연의 m=1/100은 합성 규칙검사이며 실제 연구의 사후 유의수준 조정이 아니다.
judge.py의 mapping_confirmed 등 선언 필드는 물리적 대응을 스스로 증명하지 않는다. 실험 적용 시 별도의 준비·교정 기록과 함께 감사해야 한다. 예측 벡터의 WRRA 계산은 optical/verify_observations.py가 담당하며 새 judge.py는 범용 판정 계층이다. 이 역할 구분 없이 판정기만 실행해 WRRA가 통합되었다고 부르지 않는다.

[개정 규칙]
실패 기록에 이전 버전·입력·모수·출력·판정과 원인을 보존한다. 허용할 수정은 관측·수학·구현 근거를 명시하고 새 버전을 부여한다. 새로운 보정 자유도와 다른 장에 미치는 영향을 함께 기록한다. 이전 자료로 보정한 뒤 같은 자료를 재현한 성과는 보정 후 재현으로 표시한다. 새 버전의 성공은 구버전 실패를 삭제하지 않는다.
새로운 보존 위반을 발견했을 때는 최초 위반 지점을 추적하고 그 출력에 의존하는 하류 결과를 보류한다. 관련 없는 성공까지 자동 삭제하지 않되, 영향을 받은 결과를 계속 유효하다고 발표하지 않는다.

예상 비판과 답변 기준
“변수를 늘리면 다 맞는다”: 함수와 경계·은하별 자유도·후보 수를 공개하고 벌점·가린 자료·외삽 실패를 함께 남긴다. 임의 함수 자유도가 관측점 수만큼 늘어나면 그 재현만으로 구체적 응력 법칙의 설명력을 주장하지 않는다.
“같은 데이터를 두 번 썼다”: 보정과 검증의 역할을 공개하고 재현 성과는 인정하되 새 자료 검증으로 표시하지 않는다.
“검사 PASS가 우주론의 참인가”: 명세 구현·합성 판별·실제 관측 기각을 구분한다.
“공통운반자라면서 출력별로 바꾼다”: 공통 상태와 공유 모수를 먼저 고정하고 출력별 몰래 재적합을 금지한다.
“무엇이 나오든 설명한다”: 동결 버전의 기각 조건과 핵심 계약 반례를 위와 같이 공개하고 실패 시 명시적 철회·개정을 실행한다.

5. 결론
이번 보강은 WRRA의 재현·설명 성과를 유지하면서, 실패의 범위와 결과를 피할 수 없도록 명시했다. 합산 피팅 우위는 유지하고 외곽·교차 예측 실패는 실패로 기록했다. 광학 실험은 실제 실행된 합성 검정과 자연계 결합 미확인을 구분했다.
본문 부록 H에 이어 붙일 수 있는 보완 문안을 제공한다. 공개된 전체본·GitBook·GitHub·Zenodo를 이번 단계에서 수정한 것은 아니다. 3.0 전체 실행이나 실제 광학 실험의 완료를 주장하지 않는다.
