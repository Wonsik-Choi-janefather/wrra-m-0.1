# 제타 영점 위상의 중첩과 소수 공간 출력 — v0.1

2026-10-16. MCC 3.0 v0.21 제37–39·116–117·130장을 바탕으로 한 별도 계산 후보. 현재 책의 수정본이나 외부 게시 완료본이 아니다.

## 검증 입력

- 주소 상한 N=1,015,000, 서로 다른 소인수가 둘 이상인 935,155개 주소. 주소 1은 제외한다.
- 첫 70개 양의 제타 영점 rho_j=1/2+i gamma_j. 알려진 영점을 고정 입력으로 사용한다. 전체 영점에 대한 리만 가설을 가정하거나 증명하지 않는다.
- 130장의 CRT 공간 (213,65,77), 용량 M=1,066,065. J|n>=|n mod213,n mod65,n mod77>.
- 소수 그래프 L=sum_a(2I-U_a-U_a†), U=exp(-i L). 여기의 매개변수 1은 무차원 시험값이며 물리 시간·광자 Hamiltonian이 아니다.
- 두 준비 상태: 선택 주소에서 균등한 진폭과, 기존 alpha=1.8996877935161325를 상속한 n^(-alpha/2) 진폭. 둘 다 선택 부문 안에서 norm 1로 정규화한다. 실제 기존 SOURCE의 부문별 payload 배열을 재구성한 것은 아니다.

## WRRA 고유 변환

제타의 Dirichlet 항에서 n^(-rho_j)=n^(-1/2)exp(-i gamma_j log n)이다. 이 항별 항등식은 유한 주소에 그대로 적용할 수 있지만, 임계선에서 무한 Dirichlet 급수의 수렴을 뜻하지 않는다. 따라서 유한 합을 해석적 제타값이나 영점 증명으로 취급하지 않는다.

영점에서 추출한 위상 연산자를 D_j|n>=exp(-i gamma_j log n)|n>로 정의한다. 공통 n^(-1/2) 크기는 SOURCE 준비와 분리한다. 이번 계산은 위상만 사용하며, n^(-1/2)까지 채택하는 것은 alpha=1이라는 다른 준비 상태에 해당한다. 영점 번호를 임의의 Laplacian 고유모드 번호와 대응시키지 않는다.

선택된 입력 psi에 대해 영점별 공간 파동묶음은 phi_j=U J D_j psi다. 이들은 일반적으로 서로 직교하지 않으며 L의 개별 고유모드도 아니다. 다만 하나의 기존 공간에서 정의된 norm 1의 출력 상태들이다.

새 구성 가정은 모든 영점 가지의 진폭을 같게 준비하고 같은 위상으로 다시 결합하는 것이다. C=70일 때

K(n)=(1/C)sum_j exp(-i gamma_j log n),

out=U J K psi=(1/C)sum_j phi_j,

hold=sqrt(1-|K|^2) psi.

|K|<=1이므로 ||out||²+||hold||²=1이다. 균등 영점 보조 레지스터를 준비하고 제어 D_j를 작용시킨 뒤 균등 상태 포트를 선택하면 K가 나온다. 나머지 포트의 총확률은 보류 확률이다. 적은 수의 변수로 쓴 위 hold는 그 보완확률을 보존하는 최소 instrument이며 나머지 모든 실제 포트의 미시 상태와 같다고 주장하지 않는다. 강도는 |out(x)|²이며 조건부 분포는 출력 확률을 별도로 기록한 뒤 정규화한다.

개별 영점의 R3 허가조건은 기존 130장에 남는다. 이 시험은 허가된 영점 70개를 입력으로 받는 후속 중첩 층이다. 새 코드가 R3 판독을 다시 검증한 것은 아니며, mpmath로 해당 영점들의 zeta 잔차를 별도 확인한다. 허가가 0인 가지를 넣으면 해당 가지는 보류로 보내야 한다.

## 산출값과 대조

results.json에 두 준비 상태 각각의 출력 확률·보류 확률·보존 오차·공간 분포 차이를 기록한다. 비간섭 대조는 (1/C)sum_j |phi_j(x)|²로 계산한다. 중첩 출력은 그와 다른 교차항을 가진다. 출력 성공확률과 조건부 분포를 함께 비교하므로 사후 정규화로 총량을 숨기지 않는다.

대조는 영점 높이 전체에 0.5를 더한 경우, 양끝 사이 등간격 높이, 같은 영점에 무작위 상대위상을 준 경우다. 앞의 두 대조에서는 제타 허가를 강제로 열어, 허가 자체가 아니라 형태 형성만 비교한다. 이 대조를 실제로 허가된 제타 출력으로 해석하지 않는다.

공통 높이 이동은 K_shift(n)=exp(-i delta log n)K(n)이므로 배치 전 강도와 출력 성공확률을 바꾸지 않는다. 공간 전파 뒤에는 바뀔 수 있다. 영점 순서를 바꿔도 동일한 가중 합은 변하지 않는다. 이 두 항등식을 검사한다.

## 반증조건과 결론 범위

주소 충돌, norm 보존·선형 중첩·역변환 실패, 선언한 위상 연산과 결과의 불일치는 구현의 실패조건이다. 비간섭 대조와의 차이는 이 입력·파라미터에서 간섭이 나타나는지를 확인한다. 그것만으로 제타 영점의 물리적 우월성이나 유일성을 입증하지 않는다. 다른 높이 집합도 공간 패턴을 만들 수 있다.

현재 가정만으로는 영점 가지의 균등 가중치·공통 상대위상이 강제되지 않는다. 진폭·위상의 물리적 준비법, 셔터·안정기록에 의한 개별 관측 결과 선택, 3차원의 유일한 도출은 남는다. 고정된 3축 공간 위의 조건부 출력장을 계산한 것으로 판정한다. 물질·암흑물질 구성비와 연결하지 않는다.
