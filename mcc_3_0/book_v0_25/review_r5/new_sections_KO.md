#### 135.18 두 해상도 출력과 측정에 따른 조건부 확정

**검증 입력.** 기존 셔터 고유주기와 광속을 유지한다. 관측 확정에는 플랑크 시간을 국소 내부 갱신의 최소 간격으로, 플랑크 길이를 그에 대응하는 내부 세분화의 하한으로 가정한다. 이 하한은 실험으로 확정된 최소시간·최소길이가 아니다. 복소 결합상태·유니터리 변환·보른 확률·측정 연산자는 관측 구조를 재현하도록 채택한 해석기 입력이다.

$$\Delta\tau_{\rm sh}=1.4813019664158633\times10^{-21}\ {\rm s},\qquad L_{\rm sh}=c\Delta\tau_{\rm sh}=4.440831575520451\times10^{-13}\ {\rm m}.$$

$$\Delta\tau_{\rm obs}\ge t_P=\sqrt{\hbar G/c^5},\qquad\ell_P=ct_P.$$

**WRRA 고유 변환.** 주기적 표현은 안정된 장치·환경 기록의 갱신을 기술한다. 셔터 사이의 미시 상태와 위상을 강제로 소거하지 않는다. 측정 허가 $Q_{\rm obs}$는 실제 대상–장치–환경 상호작용과 기록 형성에 적용한다. 사람의 의식이나 시선은 별도 허가 조건이 아니다. 준비 상태 $\rho$와 허용된 측정 연산자 $M_a$에 대해

$$p(a)=\operatorname{Tr}(M_a\rho M_a^\dagger),\qquad\rho_a=\frac{M_a\rho M_a^\dagger}{p(a)},\qquad\sum_aM_a^\dagger M_a=I.$$

확정되는 것은 해당 측정 기록이다. 비가환 물리량의 모든 불확정성이 동시에 사라지는 것으로 정의하지 않는다. 내부 해상도와 측정 장비의 달성 가능한 정밀도를 동일시하지 않는다. $L_{\rm sh}$는 주기적 표현의 척도이며 더 작은 파장·상태를 삭제하는 보편적 격자 간격이 아니다. 플랑크 하한은 같은 국소 장치의 연속 등록 사건에 적용하며, 서로 다른 장치의 좌표시간 차이나 광자의 고유시간에 적용하지 않는다. 두 주기의 비를 정확한 정수로 요구하지 않고 우주 전체의 동시 갱신도 부과하지 않는다.

공간꼴로 분리된 측정에는 공동 통계의 순서 독립성과 비조건부 원격 신호 불변성을 요구한다. 외부 결과를 안 뒤 조건부 상태 기술을 바꾸는 것과 물리적 신호 전달은 구별한다. 측정 등록은 입자 생성 허가와 별개이며 물질·반물질 셔터 위상을 추가로 진행시키지 않는다. 관측 이전의 얽힘은 독립적인 두 국소 숫자로 임의 분해하지 않는다.

**산출값.** 공개된 단독 논문 v1.5의 계산을 통합한다. 361개 위상에서 간섭 확률의 오차는 최대 $5.55\times10^{-16}$, 이상적 싱글렛 CHSH는 $2.82842712474619$다. 200개 결합 혼합상태의 비선택 채널 1,000개에서 원격 축약상태 변화는 최대 $2.22\times10^{-16}$, 공간 분리 분기 순서 대조 4,000개는 $1.11\times10^{-16}$ 이하다. 101개 부스트의 고유간격 202개는 상대 오차 $9.88\times10^{-15}$ 이내다. 이 계산은 채택한 양자 규칙과 유한 측정 인터페이스의 정합성 검사이며 플랑크 하한을 실험으로 판별한 결과가 아니다. 이전 630개·288개 검사와 구분한다.

**반증조건.** 물리적 어느 경로 기록 없이 위상을 지움, 확률·상관관계 실패, 비조건부 초광속 신호, 좌표 순서 의존 공동 통계, 장치·환경을 포함한 보존 실패가 있으면 연결 규칙을 수정한다. 재현 자료는 review_r5/two_resolution 아래에 둔다. 원전 DOI: https://doi.org/10.5281/zenodo.23487366.

#### 135.19 최상류–중간층 유사소수 교환의 명시적 유한 구현

**검증 입력.** 제38장의 $L=500,H=29,C=70$, $0\le\ell<L$, $0\le h<H$, $1\le z\le C$와 직렬화 $a=1+\ell+500[h+29(z-1)]$를 그대로 사용한다. 주소 1은 비활성 기준이다. 상류 교환에 초·거리·셔터·플랑크 시간·유량을 배정하지 않는다.

**WRRA 고유 변환.** 다음 합성 운반자를 하나의 구현 후보로 채택한다.

$$Q(\ell,h,z)=2^{\ell+1}3^{h+1}5^z,\qquad (\ell,h,z)=(v_2(Q)-1,v_3(Q)-1,v_5(Q)).$$

이 장의 ‘유사소수’는 내부 합성 구조를 원자적 전달 단위로 다루는 WRRA 작업 명칭이며 표준 Fermat 유사소수가 아니다. 서로 다른 세 소인수의 지수로 좌표를 복원하므로 허용된 유한 집합에서 전단사다. 다른 부호화로 교체할 수 있으며 2·3·5에 물리적 특별함을 부여하지 않는다. 큰 정수 크기는 질량·에너지나 새 SOURCE 상태 수가 아니다. 희소 지수로 저장하면 기존 좌표 저장으로 충분하다.

한 세션은 허가된 최상류→중간층 전달 한 번과 응답 전달 한 번으로 구성한다. 활성 운반자의 소유자는 한 곳뿐이며 출발지의 활성 소유권을 비운다. 닫힌 허가, 재실행 요청, 잘못된 소유자와 상태 표지를 거부한다. 16비트 응답 예시 $F_a(x)=x\operatorname{XOR}(a\bmod65536)$는 $F_a(F_a(x))=x$를 만족한다. 이는 가역 피드백의 실행 예시이며 물리적 힘 법칙이 아니다. 미지 양자상태는 복제 대신 SWAP으로 이동한다.

중간층 사상 $\mathcal A$는 주소 1을 기준 상태로, 짝수 주소를 정보가 보존되는 보류 상태로, 홀수 $a>1$을 $r=2a$인 단일 짝수 후보로 읽는다. 마지막 분기는 $r\to a+a$와 역판독 $a=r/2$를 갖는다. $9\to18\to9+9$, $105\to210\to105+105$가 예다. 소수 5도 산술 후보 10이 되지만 질량화의 홀수 합성수 필터는 통과하지 않는다. $r$는 전환 표지이며 SOURCE 창을 확장한 주소가 아니다.

차원과 가중치는 원래 주소 $a$의 함수로 유지한다. 합성 운반자 $Q$ 때문에 원래 소수를 3차원 물질로 재분류하거나 $w(a)$를 $w(Q)$·$w(r)$로 바꾸지 않는다. 구조 후보 외에 종·에너지·운동량·양자수와 실제 출력 허가가 필요하다.

**산출값.** 1,015,000개 주소의 생성·역판독·분기 왕복 전수 검사, 활성 주소 1,014,999개의 왕복 세션, 소유권 이동 2,029,998회와 거부 대조 18개를 실행했다. 원래 소수 79,608개·짝수 합성수 507,499개·홀수 합성수 427,892개가 유지됐다. 작은 양자 SWAP 검사 200개에서 외부 기준과의 결합상태 오차는 최대 $1.13\times10^{-16}$다. 이 검사에서 실제 입자를 방출하지 않았다.

**반증조건.** 주소 충돌·역판독 실패·활성 소유권 중복·재실행 허용·원래 가중치 또는 분류 변경·허가 위반이 있으면 수정한다. 생성식·교환 사상의 미정 항목은 이번 유한 후보에서 구체화했으며 상류 두 층의 물리적 식별이나 유일 최소비용을 증명한 것은 아니다. 재현 자료는 review_r5/upstream_exchange, 원전 DOI는 https://doi.org/10.5281/zenodo.23487587 이다.

#### 135.20 최초 일괄 물질 출력과 더 단순한 역설계의 채택 기준

**검증 입력·초기조건.** 우리 우주의 최초 표현형 경계 $\Sigma_B$에서 출력기는 물질 모드로 준비되어 있고, 물질세계의 초기 내용이 일괄 구현된다고 둔다. 최초부터 유한·무경계의 공간 구조이며 초기 뒤틀림도 포함한다. 현재의 별·행성·생명이 완성된 모습으로 출현한다는 뜻은 아니다. 이후 공간의 뒤틀림·팽창·냉각·구조 형성이 변화하고 개별 쌍생성·쌍소멸은 확률적으로 발생한다.

**WRRA 고유 변환.** 최초 모드의 선택 원인을 추가 도출하는 것을 이번 구성의 완료조건으로 요구하지 않는다. 초기 물질 모드는 채택한 준비 입력이며 법칙이 반물질 모드도 허용한다는 점은 유지한다. 이전의 No Extra Asymmetry Register는 원인 유도를 추가로 요구하는 엄격 분기다. 이번에 채택한 물질 준비 분기와 그 엄격 분기의 전제를 동시에 강제하지 않는다. 정확한 대칭 법칙과 대칭 준비에서 비대칭을 임의 생성할 수 없다는 과거 정리는 그대로 유효하며, 이번 준비는 대칭 준비를 가정하지 않는다.

‘한순간’은 초기 경계에서의 일괄 구현을 가리킨다. 모든 관성계에 같은 절대 좌표시각을 새로 부과하지 않는다. 유한·무경계라는 위상 조건 자체가 뒤틀림의 크기·분포를 유일하게 정하지는 않는다. 기존 공간 위상을 유지하며 초기 계량·외재곡률·물질 준비는 그 경계의 입력으로 공개한다. 이 준비가 기존 팽창·열역사와 동역학적으로 이어지는 모든 계산을 새로 실행한 것으로 세지 않는다. 최초 출력에는 반대 부문 전체의 다음 셔터 예약을 넣지 않는다.

현재 구성비는 반드시 영원히 고정돼야 할 목표가 아니다. 기존 설계가 검토한 현실을 무리 없이 설명하면 유지한다. 같은 관측 범위·단위·허가·보존 조건에서 자유 매개변수, 예외 분기, 상태와 연산 부담을 줄인 대안이 같거나 나은 정합성을 보이면 그 대안으로 교체한다. 숨은 재보정이나 늘어난 예외를 단순화로 세지 않는다. 이번 개정은 새 단순화 대안의 수치 우월성을 검증하지 않았으므로 기존 구성비·필터 입력을 유지한다.

**산출값·반증조건.** 최초 일괄 출력과 후기 국소 반응을 구분한 초기조건 명세다. 순물질 차이를 생성 확률만으로 새로 맞추지 않는다. 정량 반응률·바리온/광자 비율과 초기 기하의 동역학 접합은 그 모듈을 실제 실행할 때 판정한다. 관측·보존·준비 조건과 충돌하면 해당 초기조건·접합 또는 확률 규칙을 수정한다.

#### 135.21 블랙홀 출력 경계: 국소 계량·지평선·열역학과 정보 소유권

**검증 입력.** 정보·에너지의 소유권을 유지하는 기존 장부와, 구대칭·비회전·무전하인 정상 블랙홀의 GR 계량 및 Bekenstein–Hawking 관계를 역설계 입력으로 채택한다. $G,c,\hbar,k_B$는 관측 상수 입력이다. 코드 크기나 ‘출력부 접촉’이라는 말만으로 이 계량과 면적 계수를 새로 도출했다고 하지 않는다. 기존 에너지 장부가 소유한 중력 질량 $M=E_{\rm grav}/c^2$를 사용한다.

**WRRA 고유 변환.** 관측 가능한 외부 포트의 접근 해제를 내부·경계 정보 소유권으로 연결한다. 지평선에서 모든 자유낙하 관측자의 입자가 보편적으로 소멸하는 규칙은 넣지 않는다. 국소 검출기에서는 허용된 물질 상호작용이 계속 가능하다. ‘표현형이 사라진다’는 이 구현에서 외부 관측대수의 접근이 닫힌다는 뜻이다. 실제 질량·정보가 삭제되거나 외부 수신기에 순간 소거 신호가 도착한다는 뜻이 아니다.

$$r_s=\frac{2GM}{c^2},\qquad ds^2=-c^2dt_{\rm PG}^2+\left(dr+c\sqrt{r_s/r}\,dt_{\rm PG}\right)^2+r^2d\Omega^2.$$

$$\frac{dr}{dt_{\rm PG}}=c\left(\pm1-\sqrt{r_s/r}\right).$$

바깥 방향 광선은 $r=r_s$에서 좌표 반지름 변화가 0이고 내부에서는 두 미래방향 분기 모두 반지름이 감소한다. 이는 국소 광속을 넘는 통신이 아니다. 콤팩트성 $r_s/r\ge1$을 이 정상 모형의 외부 접근 게이트 조건으로 사용한다. 일반 동적 우주에서의 전역 사건지평선은 이것만으로 판정하지 않는다. 여기서는 유한 국소 패치를 계산하며 기존 유한·무경계 우주를 무한한 점근 평탄 우주로 바꾸지 않는다. 우주 전체와의 계량 매칭은 별도 범위다.

곡률·열역학은 다음 채택 관계를 장부와 함께 실행한다.

$$R_{\mu\nu}=0\ (r>0),\qquad\mathcal K=\frac{12r_s^2}{r^6},\qquad A=4\pi r_s^2,$$

$$S_{\rm BH}=\frac{k_BA}{4\ell_P^2},\qquad T_H=\frac{\hbar c^3}{8\pi Gk_BM},\qquad T_H\frac{dS_{\rm BH}}{dM}=c^2.$$

형체 접근의 해제 뒤에도 $M$은 외부 중력 계량의 소유량이다. 양의 에너지 $E_{\rm in}$ 흡수는 $M'=M+E_{\rm in}/c^2$로 닫는다. 같은 에너지를 외부 점유와 내부 질량 양쪽에 중복 계상하지 않는다. 작은 유한 정보 레지스터는 에너지 보존 SWAP으로 내부 소유자에게 이전한다. 이 역변환의 수학적 존재는 지평선 안에서 바깥으로 메시지를 보낼 허가가 아니다. 면적 엔트로피와 유한 예제의 현재 얽힘 엔트로피를 동일시하지 않는다.

**산출값.** 기호 계산으로 Ricci 텐서 16성분의 0과 곡률 불변량을 확인했다. $10^{20},10^{25},10^{30},10^{35},10^{40}$ kg의 선언한 질량 입력에서 광선 1,210건의 최대 정규화 잔차는 $1.99\times10^{-16}$, 열역학 제1법칙 5건의 오차는 $2.22\times10^{-16}$ 이하다. 흡수 25건의 에너지 오차는 $2.06\times10^{-16}$ 이내다. 외부 기준과 얽힌 정보 전달 200건의 결합상태 오차는 $1.13\times10^{-16}$ 이내이며 선언한 레지스터 에너지 오차는 0이다. 고전적 병합 면적 예산 9건과 거부 대조 7건도 실행했다. 복사량을 병합의 새 예측으로 도출하지 않고 허용 예산 내 입력으로 지정했다.

예를 들어 $M=10^{30}$ kg이면 $r_s=1485.2320538$ m, $T_H=1.2269006706\times10^{-7}$ K, $S_{\rm BH}/(k_B\ln2)=3.8273066732\times10^{76}$이다. 이는 입력한 GR·열역학 관계를 WRRA 경계 장부에서 재현한 산출값이다.

**반증조건·범위.** 질량 삭제, 에너지 중복, 정보 복제·파괴, 허용되지 않은 내부→외부 신호, 광선·곡률·열역학 불일치가 나타나면 접합을 수정한다. 호킹 스펙트럼·greybody 계수·증발률·방출 정보의 완전 복원·미시상태 계수·회전 붕괴를 새로 계산한 결과는 아니다. ‘출력부 접촉’의 미시 기하를 유일하게 결정한 것으로 세지 않으며, 외부 접근 게이트와 보존적 정보 이전이라는 조건부 구현을 제공한다. 재현 코드는 review_r5/black_hole_bridge.py와 black_hole_results.json이다.

#### 135.22 일곱 검토 항목의 현행 상태

|---|---|
| 1. 수론–물리 판독 | 역설계 선언과 기존 288개 유한 해석기 실행을 유지 |
| 2. 조건부 셔터·측정 | 제135.18의 두 해상도와 채택한 양자 규칙을 통합 |

6번의 OPEN은 기존 CMB·초기 평균 준비·렌즈 계산을 무효화하지 않는다. 다만 평균 준비에서 하나의 개별 우주 실행으로 가는 준비·비용·확률 동역학을 이번 개정에서 해결했다고 표시하지 않는다. 새 연결마다 검증 입력 → WRRA 고유 변환 → 산출값 → 반증조건의 순서를 유지한다.
