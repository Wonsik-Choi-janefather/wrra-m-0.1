# Minimal Computing Cosmology 3.0 — full bilingual book v0.20

Wonsik Choi and Jeongin Choi | Independent Researchers | 15 October 2026.

This reviewed edition incorporates Chapters 1–129: the 2.3.2 skeleton, seven manuscripts, finite-frame/time/SOURCE/CMB bridges, independent optical/supplier/photon/higher-CMB outputs, and the reviewed macroscopic registry.

Inputs → WRRA transformations → outputs → falsification conditions precede conclusions. Known-value reproduction is explanatory achievement; outputs from fixed calibrated rules are model predictions. M1 vertical disk kinematics, M2 galactic lensing and M3 matter growth remain numerical candidates. No new observational confirmation or new Astra/external peer review is claimed.

Validation: direct 128-state phase/timing recomputation; the inherited v0.2 suite rerun with 176/176 controls; 58 frozen input/source hashes and stable values checked. All 46 image references in each language resolve. Final PDFs were rendered and inspected. Korean PDF: 216 pages; English PDF: 237 pages.

The complete ZIP includes bilingual Markdown/PDFs, existing figure assets, review reports and verification JSON, original manuscript evidence, a time-to-CMB source snapshot, original coherence package and reviewed macroscopic/source follow-up archives. Original scientific archives retain their own hashes and computational versions. New review summaries are outside them.

## Build and reproduce

PDF build requires pandoc, XeLaTeX, DejaVu Sans and Noto Sans CJK KR. Run `sh render.sh` with the system font installed. This host used official Noto CJK Korean Regular with synthetic bold/slant; source: https://github.com/notofonts/noto-cjk, Sans/OTF/Korean/NotoSansCJKkr-Regular.otf. Fonts and runtime dependencies are not redistributed.

For numerical reproduction, unpack each relevant source archive and follow its own README/requirements. The v0.20 inherited-suite rerun receipt is `rerun_v02_summary_v020.json`; it uses existing CAMB transfers rather than a new Boltzmann evolution. Full M1–M3 solvers are not included because their numerical outputs remain pending.
