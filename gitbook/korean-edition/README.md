# **3.0 판본 선언**

최소계산우주론 3.0은 2.3.2를 폐기하고 새 이론으로 교체하는 판본이 아니다. 2.3.2에서 누적 통합한 최소 실행구조, 공통운반자, 물질 표현형, 네 힘의 비대칭 통합, 유한 무경계 뒤틀림 우주, 표준물리 모듈 접속을 보존한 채, 이후 WRRA_M에서 실행한 고에너지-표현형 연결 연구와 3.0의 finite SOURCE 생성 규칙을 그 앞단과 중간층에 추가한다.

이 책에서 기호 ⊕는 산술합이 아니라 원래의 소유권과 출처를 보존하는 비대체적 누적 통합을 뜻한다.

MCC 3.0 = MCC 2.3.2의 누적 뼈대 ⊕ WRRA_M 0.1-0.12 구조 통합 ⊕ finite Klein-Zeta SOURCE 후보

3.0의 새로운 중심 질문은 “유한한 우주를 말한다면, 그 우주를 실행하는 SOURCE의 크기와 상류 생성구조도 내부에서 유한하게 닫힐 수 있는가?”이다. 현재 3.0은 이 질문에 대해 계산 가능한 하나의 후보를 제시하고, 그 상태가 component, phenotype, energy, pressure, gravity, galaxy rotation, lensing, cosmic expansion까지 전달되는지를 같은 장부 안에서 검사한다.

이 책의 계산·모형 판정은 가능한 한 다음 순서를 고정한다.

## 3.0 개념 관계도와 빠른 용어 지도

3.0의 새 용어들은 각각 따로 움직이지 않는다. 이 책에서는 다음 실행 순서를 먼저 기억하면 뒤의 수식과 장부가 훨씬 쉽게 읽힌다.

> **LAW → finite SOURCE → FILTER / RESIDUE → RECORD → COMPONENT → CODEWORD / HARMONIC → PHENOTYPE → SI ENERGY / LOAD → GRAVITY / LENSING / EXPANSION**

공통운반자(common carrier)는 이 흐름에서 여러 표현과 힘이 공유하는 transport basis이며 제5의 힘이 아니다. Standard Model·GR·FLRW 같은 표준물리는 Reality 층의 정밀 계산 모듈로 유지되고, string theory는 필요할 때 미시 구현을 보강하는 선택적 수리 재료로만 사용한다.

| **층위**    | **핵심 개념**       | **한 문장 역할**                                          |
|-------------|---------------------|-----------------------------------------------------------|
| 규칙        | LAW                 | 대칭·보존·상태공간·경계조건을 소유                        |
| 상류 생성   | finite SOURCE       | 실행 가능한 유한 주소창을 생성하는 3.0 후보               |
| 선택/잔여   | FILTER / RESIDUE    | 허용·잔존·복귀와 현재에 남는 이력을 분리                  |
