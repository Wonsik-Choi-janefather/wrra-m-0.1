WRRA M 상하류 연결 연구 0.7
유한 비균질 상태-장 되먹임의 조건부 구현
Wonsik Choi · Jeongin Choi / 2026-10-03

1. 실행 범위와 입력
0.2의 ground/첫 excited 인구를 두 운반 성분에 전달했다. 두 성분은 같은 공간 운반 법칙을 쓰되 서로 다른 초기 밀도 프로파일을 갖는다. 지지 모드는 기존 핵자 에너지 모드이며 성분 간 새 전이는 없다.
0.6의 측정·기록 결과와 0.5의 시계 결과를 근거로 보존하지만, 기록 장치가 공간장을 바꾸는 동역학은 이번 계산에 추가하지 않았다. 0.6의 물리 장치·기록 안정성 공백은 그대로 남는다.
구현은 무차원 비상대론적 Schroedinger-Poisson 유효 모형이다. 공변 계량·Einstein 방정식·우주 전체 비균질 팽창을 구현한 결과가 아니다.
영역 길이 L=20, 결합 lambda=1, 주기 경계와 초기 Gaussian 프로파일은 공개한 구성 입력이다. 관측 우주의 길이·중력상수를 새로 보정하거나 유도하지 않았다.

2. 상태에서 장으로, 장에서 상태로
두 성분 psi_j의 합 밀도 rho=sum_j |psi_j|²로 장을 계산한다. 주기 경계의 Poisson 식은 phi''=lambda*(rho-mean(rho)), mean(phi)=0이다. 평균을 빼지 않으면 주기 경계의 Poisson 해가 존재하지 않는다.
상태 진화는 i dpsi_j/ds = [-0.5 d²/dx² + phi] psi_j이다. 각 갱신에서 실제 밀도로 phi를 다시 계산한다. 미리 처방한 비균질 경로를 읽는 계산이 아니다.
공간 Fourier 미분과 대칭 split step으로 potential 반 단계, kinetic 한 단계, 갱신된 potential 반 단계를 수행했다. 성분별 노름과 인구를 보존한다.
성분 파동함수는 인구 가중 순수 공간 블록의 표현이다. 두 내부 성분을 coherent하게 합친 완전한 순수 상태라고 가정하지 않는다. 대각 내부 H의 빠른 위상은 밀도와 인구를 바꾸지 않으므로 이 운반 계산과 분리한다.

3. 에너지·국소 보존과 중복 방지
동적 에너지는 E_dyn=0.5 integral sum_j |dpsi_j/dx|² + 0.5 integral rho*phi다. 장이 자기 일관적으로 생성되므로 밀도-장 항의 1/2를 유지한다. 같은 장 에너지를 다시 더하지 않는다.
보존 오차는 이 동적 에너지에서 검사한다. 큰 일정 rest/internal 에너지를 분모에 포함해 오차를 작게 보이게 하지 않는다.
Fourier kinetic 연산자는 유한 격자에서 Hermitian이다. 이 연산자의 격자 간 전류를 직접 구성해 반대칭과 국소 밀도 연속식을 검사했다. Fourier 연산자의 전류는 일반적으로 여러 격자 쌍을 잇는 것이며 최근접 전류로 임의 바꾸지 않는다.
준비와 기록에 필요한 외부 일이나 noise 에너지는 이 닫힌 운반 구간에서 발생시키지 않는다. 이것은 준비 후 교환이 멈춘 유효 구간이다.

4. 계산 사례와 결과
최종 s=1까지 N=64에서 ds=0.01,0.005,0.0025를 실행했다. N=128에서도 ds=0.0025를 실행했다.
두 시간 간격의 최종 밀도 차이는 3.8405271542e-7과 9.6012194357e-8이다. 비는 4.000041이며 대칭 방법의 2차 시간 수렴과 일치했다.
N=64와 N=128의 같은 좌표 밀도 L2 차이는 9.0234811629e-12다. 이 수렴은 지정한 매끄러운 초기 상태와 유한 구간에서의 결과이며 모든 조건의 정확도를 보증하지 않는다.
최대 동적 에너지 drift는 ds=0.01에서 4.0902602305e-8, ds=0.0025에서 약 2.55648e-9다. 이는 근사 적분의 오차이며 엄밀한 0으로 표시하지 않는다.
양방향 진화를 실행해 초기 상태 복원을 확인했다. 결합 lambda=0의 자유 진화와 비교해, 밀도-장 되먹임이 최종 밀도를 바꾸는 것도 확인했다.
균일 밀도에서는 평균을 뺀 phi가 0이고 일정 공간 상태가 정지했다. 이 검사는 이번 Poisson 모형의 균일 극한이며 하류 FRW 배경을 새로 재현한 검사가 아니다.

5. 물리적 연결의 제한
장 소스는 두 성분을 같은 가중치로 센 운반 점유 밀도이다. 여기 에너지를 포함한 공변 stress-energy tensor에서 장을 만든 것이 아니다. lambda의 실제 G·종별 질량·입자 수·길이 사상은 미완료다.
0.5의 외부 보정 omega를 선택하면 s=omega*tau로 시간 좌표를 붙일 수 있다. 그러나 이 정의만으로 kinetic 계수·길이·중력 결합의 SI 값이 정해지지는 않는다. 실제 길이·질량과 부하 사상을 함께 보정해야 한다.
기록·준비·공급원·운반자·공변 계량을 동시에 진화시키는 전체 계산은 아직 없다. 기존 상류와 하류의 입자·에너지 결과를 이 모형이 무조건 대체한다고 해석하지 않는다.

6. 판정과 0.8 전달
40개 구현·수학 검사 통과: 정규화, 성분 인구, 동적 에너지 drift, Poisson 잔차, 비균질 장, 역진화, 전류 반대칭·국소 연속식, 자유 진화 대조, 시간·격자 수렴, 균일 극한.
0.7에서 비균질 상태와 장의 최소 자기 일관적 되먹임을 실행했다. 완전한 비균질 공변 중력 연결은 미완료다. 이는 0.8 통합 검토와 1.0 논문의 열린 항목으로 반드시 유지한다.
0.8은 0.1-0.7 전체 입력·출력·범위·재현을 검토하고, 실행한 연결과 미실행 연결을 최종 판정한다. 0.8 종료 뒤 자동 추가 단계는 만들지 않고 수정은 r1/r2로 처리한다.
상류 0.10·하류 0.12 마감 유지. 연결 연구 1.0은 검증된 실행 범위의 통합 확정판이며 미완료 항목의 삭제가 아니다.
