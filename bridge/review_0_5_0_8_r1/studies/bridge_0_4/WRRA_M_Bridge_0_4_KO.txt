WRRA M 상하류 연결 연구 0.4 — 같은 에너지에서 압력과 균일 팽창
Wonsik Choi · Jeongin Choi / 2026-10-03

1. 입력과 구성 선택
0.3의 기준 교체 에너지와 signed 환경 교환 16개 행을 입력으로 사용했다. 보정값을 다시 맞추지 않았다.
준비가 끝난 뒤 고정 comoving 입자 수와 고정 내부 상태를 가정한다. φ의 정지·여기 에너지와 D 에너지는 부피에 무관한 총 에너지이며 R은 일정 에너지 밀도이다.
V=V0 a³, V0=1 m³, E(V)=M+L V.
M=Erest+Eexc+ED, L=ER_ref/V0. 공급 환경을 포함하면 M에 Eenv를 한 번 추가한다.
이 부피 법칙은 선언한 유효 구성 선택이다. 실제 핵자 압력, 준비 장치의 상태 방정식이나 미시 부피 결합을 유도한 것이 아니다.

2. 같은 E에서 유도한 압력·기하 응답
P=-∂E/∂V=-L, u=M/V+L.
H²/H0²=u/ucrit, q=(u+3P)/(2u).
압력은 다섯 점 수치 미분과 비교했다. 부피가 바뀌는 동안 a du/da+3(u+P)=0이며, 이는 준비 후 교환이 멈춘 균일 연속 방정식이다.
계산한 가속도는 -q H² a와 같은 식을 만족한다. 재현은 기존 균일 FRW 응답 안에서 수행했으며 새 중력 방정식을 유도한 것은 아니다.

3. 공급 환경의 두 경계
외부 환경: 공급 장부는 중력 계산 영역 밖에 둔다. 고정 부피의 준비 과정에는 경계 교환이 있으며, 준비 후 시스템의 균일 진화를 계산한다. 이를 준비 중에도 닫힌 우주라고 해석하지 않는다.
포함 환경: 환경 에너지를 중력 장부에 포함하며 환경 Penv=0을 가정한다. 시스템이 받는 여기 에너지와 환경의 감소는 전체 M에서 상쇄된다. 환경의 실제 압력과 전달 동역학은 미해결이다.
환경을 포함하면 기준 총 에너지는 ucrit보다 커진다. 따라서 기존 H0·q0 기준과 동일한 보정 사례가 아니다. 이 차이를 숨기기 위해 재보정하지 않았다.

4. 기준 결과
외부 환경, 기존 보정, a=1:
u=7.668947767821907×10^-10 J/m³, P=-5.258597484395482×10^-10 Pa, q=-0.52855, H/H0=1.
외부 환경, 대체 보정, a=1:
P=-5.230222377654542×10^-10 Pa, q=-0.523, H/H0=1.
포함 환경, 기존 보정, a=1:
q=-0.5185075158932921, H/H0=1.004917907094903.
포함 환경, 대체 보정, a=1:
q=-0.512871287128713, H/H0=1.0049875621120892.
환경 포함의 두 값은 유한 환경 입력을 더한 모형 결과이며 관측 보정이나 새로운 우주 예측으로 제출한 값이 아니다.
기준 q0는 a=1의 결과이다. a=.5,1,2에서는 변하는 에너지 비중으로 q(a)를 계산했다.

5. 실제 균일 진화와 검증
16개 준비 입력 × 두 경계 × 세 부피에서 96개 결과 행을 실행했다.
각 입력·경계에 대해 d a/dτ=a sqrt(M/(ucrit a³)+L/ucrit), τ=H0 t를 적분했다. 32개 진화에서 τ=0..1의 17개 지점을 계산했다. 이는 기존 H0를 기준으로 표현한 균일 시간이며 소스 프레임의 물리 초를 새로 결정한 것이 아니다.
동일 계수의 dust+일정 배경 해와 비교한 최대 scale-factor 오차는 3.2974289965181924×10^-11이었다.
총 600개 사례별 구현·수학 검사 통과: 양의 계수·밀도, 포함 경계의 교환 상쇄, 에너지 미분 압력, 배경 밀도, 연속 방정식, 가속도 일치, 기준 q/H 재현, 적분 해 비교, 단조 팽창.
600은 반복된 사례별 검사 수이지 독립 실험이나 독립 물리 법칙 수가 아니다.

6. 판정과 후속 전달
0.3의 에너지 교체를 선언한 부피 법칙으로 확장해 압력·균일 팽창을 연결했다. 이 범위의 0.4 구현과 검증을 완료했다.
공급원이 내부에 있으면 에너지 이동 자체가 총 중력 부하를 추가하지 않는다. 공급원을 외부에 두면 시스템 변화는 경계 교환이며, 전체 우주 해석은 공급원의 위치·압력과 함께 해야 한다.
미완료: 준비가 진행되는 동안의 Q(t), 실제 공급 환경의 압력, 부피에 따른 내부 상태 변화, 입자 생성·종별 수량, 비균질 공변 동역학. 로컬 회전·렌즈는 이번 연구에서 재계산하지 않았다.
0.5에서는 소스 프레임·준비 생성자·고유시간·SI 위상을 연결한다. 이번 τ 정의가 그 미완료 연결을 대신하지 않는다.
상류 0.10·하류 0.12 마감과 연결 연구 0.8 종료를 유지한다.

7. 재현
Python 3, numpy, scipy 설치 후 python compute_0_4.py.
source/bridge_0_3_results.json을 포함하며 해시는 results.json에 기록한다. 압력·연속식 잔차와 32개 적분 이력도 함께 제공한다.
