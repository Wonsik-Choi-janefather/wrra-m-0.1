WRRA M 상하류 연결 연구 0.1 — 연결 규약과 모순 판정
Wonsik Choi · Jeongin Choi / 2026-10-03

1. 목적과 완료 범위
상류 0.10(통합 1.0-r1)과 하류 0.12(통합 1.0)의 전달 규약을 정의한다.
0.1은 원고·입력·인터페이스의 대조와 정의 단계이다. 결합 상태의 동역학이나 새 물리적 예측을 실행한 단계가 아니다. 기존 검사 수를 새 연결 검증 수로 합산하지 않는다.
연결 연구는 0.1–0.8에서 마감하고 1.0은 전체 통합 논문 확정판으로 둔다. 수정은 r1/r2로 처리한다.

2. 고정 기준 사례
활성 주소 n=2..1,000,000; 주소 1은 활성 정규화 밖의 진공 기준이다.
공동 보정 α=1.8996876950554356, 상수 입장 β=0.865457012413696.
주소 비중 φ/D/R=0.05/0.268/0.682. 잔존 Actual은 φ+D=0.318이며 반환을 포함한 전체 장부는 1이다.
위상 입장 사례는 K=8, 위상 증분 0.1, 문턱 1.447673170352440을 사용한다. 같은 총 비중이어도 상수 입장 사례와 주소별 분포는 다르다.
하류 기본 SI 에너지 비중은 0.0493/0.265/0.6857이다. 대체 SI 보정은 0.05/0.268/0.682이다. 둘을 하나의 입력으로 혼합하지 않는다.
기준 부피 V0=1 m³는 회계 기준이며 우주 크기나 핵자 부피가 아니다.

3. 전달 규칙
확률·상태: 전체 상태 trace=1, φ 조건부 내부 상태 trace=1, 비정규화 φ 상태 trace=fφ를 구분한다. 선택되지 않은 분기를 앙상블에서 삭제하지 않는다.
측정: 네 미시 Kraus 분기를 보존한다. 두 반환 분기를 합칠 때 밀도행렬을 더하며 진폭을 합쳐 순수 상태로 만들지 않는다.
상태 공간: 95차원 핵자 공간, 128사이트 운반자 공간, 16채널 분류는 서로 다른 공간이다. 기저·차원·연산자·축소 사상을 전달해야 한다. 세 숫자의 차이는 모순 자체가 아니다.
전류: 같은 내부 밀도행렬과 고정 연산자를 사용한다. Q² 단위는 GeV²; 자기 모멘트 M/μN과 무차원 Sachs GM을 구분한다. 미실행 복소 전류 입력은 허용한 것처럼 처리하지 않는다.
에너지: 내부 에너지 MeV를 J로 바꾸는 것만으로 우주 에너지 밀도가 정해지지 않는다. 입자 수, 부피, 종, 공급원과 환경 교환을 추가해야 한다.
압력: 같은 에너지의 부피 미분으로 정의하며 고정하는 상태·주소·응답 변수를 명시한다.
시간: 프레임은 무차원 순서이다. 물리 초가 미지정이면 null로 전달한다. 선택 흐름 매개변수와 Born 확률을 동일시하지 않는다.
기록: 수학적 측정 레지스터, 표본 결과, 계산 로그, 물리적 영속 기록을 구분한다.

4. 상태 연결의 제안식과 제한
후속 0.2의 최소 출발점:
Σ = Σ_n w_n |n><n| ⊗ ρ_internal(n) ⊗ ρ_carrier(n).
필요하면 분기 레지스터를 추가한다. 이는 주소와 조건부 상태의 고전적 상관관계를 보존하는 제안이며 0.1에서 실행한 결과가 아니다. 일반 양자 얽힘까지 주장하지 않는다.
하류의 기존 곱 상태는 조건부 상태가 주소와 무관하거나, 해당 관측량에 대해 축소가 보존됨을 검증한 경우에 사용한다. 상류의 위상·코히런스를 제거하는 축소는 사상과 잃는 정보를 명시해야 한다.
0.2에서는 주소 주변분포와 에너지·전류 기대값을 비교해 곱 상태의 유효 조건을 판정한다. 기본 기준 사례의 스칼라 비중만 일치하는 것은 충분하지 않다.

5. 모순·공백 판정과 해결 담당
B01 정의로 해결: Actual 31.8% 대 100% → 잔존 집합과 전체 장부의 분모·범위 구분.
B02 조건부 해결: 주소와 SI 에너지 비중 차이 → 0.3–0.4에서 응답 계수와 기준 보정 공개.
B03 조건부 해결: q0=-0.523 대 -0.52855 → 각 에너지 입력에 대한 기준 부피 결과. 같은 입력 비교에서는 일치해야 한다.
B04 미해결: 조건부 내부 상태와 하류 곱 상태 → 0.2 결합 상태·주변분포·관측량 보존 검증.
B05 미해결: 여기 공급과 중복 계상 → 0.3 입자 수 및 시스템/환경 교환 장부. 내부 항이 거시 보정에 포함됐는지 명시한 후 대체 또는 추가 규칙 결정.
B06 실패 보존: 느린 일정/SI 위상 비=2.102556972196466e-43. 동일 시계라는 기존 가정은 실패했다. 0.5에서 생성자·보정으로 연결하며 임의 환산으로 덮지 않는다.
B07 미해결: 상류 기록 연산과 하류 물리 기록 미구현 → 서로 다른 구현 범위이다. 0.6에서 측정 후 하류 진화와 매체·에너지·지속 시간 시험.
B08 미해결: 서로 다른 공간과 종 → 0.2–0.7에서 기저 사상과 종별 연산자 정의. 주소 숫자로 입자 종을 자동 식별하지 않는다.
B09 미해결: 비균질 공변 결합 → 0.7의 실제 결합 진화와 균일 극한 검사. 처방된 경로 계산을 자가일관 동역학으로 표시하지 않는다.
B10 미해결: 총비중 일치와 미시 이력 차이, 경계 선택 → 0.2–0.8 고정 보정 비교와 민감도 기록.

6. 에너지·보정 규약
기존 하류식 E_s=V0 η_s μ_s a^νs Tr(ρ_carrier A_s)를 기준으로 한다.
주소 비중이 SI 비중이 되는 것은 응답 계수·운반자 기대값·부피를 선언한 보정 이후이다.
핵자 내부 H의 에너지를 이 식에 추가할지, 기존 항을 대체할지는 0.3에서 정한다. 현재 두 값을 합산하지 않는다.
기준에서 한 번 보정한 뒤 소스·측정·부피·경계를 바꾸는 검사에서는 계수를 고정한다. 재보정 비교는 별도 사례로 기록한다.
양의 배경 R은 물리 장부에 남는다. 공통 진공 에너지항의 상대 상쇄와 실제 상태 의존 에너지 변화는 구분한다.

7. 0.1의 인수 조건과 0.2 착수 조건
정의표, 기준 사례, 상태·단위 규약, 열 개 쟁점의 판정·담당 단계, 근거 파일 해시를 확보한다.
현재 원본에 대한 검사로 입력 비중의 정규화, Actual 범위, 두 q0 산출, 상류 physical_time_unit=null, D/R의 핵자 준비 제외를 확인한다.
이 검사는 인터페이스 대조 검사이며 새 결합 모형의 검증이 아니다. 기존 상하류 수치 결과는 수정하지 않는다.
0.2에서는 최소 결합 상태, 양성·trace, 같은 주소 주변분포, 상관관계 보존/손실에 따른 에너지·전류 비교를 실제 실행해야 한다.
