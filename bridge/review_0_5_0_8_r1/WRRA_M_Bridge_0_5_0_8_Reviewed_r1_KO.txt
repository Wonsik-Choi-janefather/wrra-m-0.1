2. 실제 연결과 보관된 근거

연결 | 판정 | 전달 내용 / 한계

0.2 → 0.3 → 0.4 | 실행 | 여기 에너지 → 외부 보정 인구의 SI 부하 → 같은 E(V)의 압력·FRW. 실제 입자 생성·준비 시간 법칙은 미포함.

0.2 + 0.5 → 0.6 | 실행 | 같은 내부 에너지 차와 선택한 프레임 → 관측 후 상태·반복 전환. 자율 장치·리셋 비용은 미포함.

0.2 → 0.7 | 실행 | 기준 인구 → 선택한 공간 분포 → 점유 밀도 → 장 → 상태. 무차원 비상대론적 유효 모형.

0.5 → 0.7 | 근거 보관 | 시계 결과는 해시·해석 근거다. 시계율을 바꿔도 장 계산은 변하지 않는다. SI 길이·운동항·G 보정 미완료.

0.6 → 0.7 | 근거 보관 | 측정 결과는 보관하지만 관측 후 상태·장치·기록 에너지를 장 진화에 되먹이지 않는다.

0.6 → 0.3/0.4 | 검토 진단 | 0.8에서 1회 측정 평균 비용을 기존 SI 장부에 삽입하고 외부/포함 공급원 경계를 검사했다. 실제 시간·공간 장치는 미포함.

입력 교란에 대한 실행 확인

독립 폴더의 변경 | 수치 결과

0.7 시계율 2배 | 밀도·장·수렴 결과 동일; 최대 밀도 차 0

0.7 측정 work 2배 | 밀도·장·수렴 결과 동일; 최대 밀도 차 0

교란은 해당 코드가 입력을 실제 사용하는지 확인하는 합성 검사다. 인구 변경은 상류 상태의 재보정이나 물리적 입자 생성 계산으로 세지 않는다.

0.7 시간 수렴 비는 4.000041, 64/128 격자 밀도 L2 차는 9.02348e-12다. 매끄러운 지정 초기 조건·유한 구간의 수렴 성과이며, 모든 조건의 정확도 증명은 아니다.




3. 측정 비용을 포함한 SI 장부 검사

검증·고정 입력: 0.2 기준 여기 인구 p=0.07997665450, 같은 H의 에너지 차 Delta, 0.5 프레임과 0.6 기록 갭, 0.3의 고정 기대 인구 Nbar와 저장고. 모두 기존 입력·실행 결과이며, 저장고 0.2 Ephi는 진단용 구성 입력이다.

WRRA 변환: 선택한 X 기저 측정은 비선택 내부 상태를 I/2로 바꾼다. 1회 평균 공급은 W=(1/2-p) Delta_J + record_gap_J/2다. 내부 여기 증가와 기록 에너지를 각각 한 번만 계상한다. 총 공급량은 Nbar W, 저장고 변화는 -Nbar W다.

산출값: 상속 보정·양성자·기준 부피 1 m3에서 여기 증가 7.0374395222e-12 J, 기록 증가 4.3176187869e-16 J, 공급 합 7.0378712840e-12 J다. 저장고는 7.5615824991e-12 J에서 5.2371121503e-13 J로 줄어 양수를 유지한다.

보정·종 | 공급 / J | 외부 q: 전 → 후 | 공급원 포함 q

inherited/proton | 7.0378713e-12 | -0.528550 → -0.519197 | -0.518508

inherited/neutron | 7.0285264e-12 | -0.528550 → -0.519209 | -0.518508

alternate/proton | 7.1378005e-12 | -0.523000 → -0.513566 | -0.512871

alternate/neutron | 7.1283229e-12 | -0.523000 → -0.513579 | -0.512871

외부 경계: 공급원을 제외한 계는 받은 에너지만큼 부하가 증가한다. 공급원 포함 경계: 공급원의 압력을 0으로 두는 기존 가정 아래 총에너지와 q는 재분배 전후 같다. 두 경계는 기준 총에너지부터 다르므로 서로 다른 q가 모순이 아니다.

반증조건: 내부 증가+기록 증가가 공급량과 다르거나, 저장고가 음수가 되거나, 포함 계 총에너지가 변하거나, 같은 E(V)에서 나온 압력이 달라지면 이 삽입 장부를 기각한다. 이번 네 조합은 모두 통과했다.

범위: 기대 인구의 평균 장부를 1회 쓴 뒤 고정 comoving 에너지 법칙을 적용한 조건부 진단이다. Q(t), 실제 장치 분포, 기록 리셋, 10만 회 물리 메모리 비용, 비균질 공변 중력을 구현한 것으로 표시하지 않는다.




4. 모순 여부와 해결 방식

겉보기 충돌 | 판정·해결

31.8% 대 100% | resident Actual은 잔존 phi+D이고 전체 장부는 반환까지 포함한다. 범위 형식으로 구분한다.

5/26.8/68.2 대 4.93/26.5/68.57 | 주소 확률과 SI 에너지 비율은 다른 입력 형식이다. 한쪽을 자동으로 에너지에 대입하지 않고 지정 보정만 사용한다.

q=-0.52855 대 -0.523 | 각 SI 에너지 보정에서 같은 압력 법칙을 적용하면 각각 재현된다. 보정과 계 경계를 항상 같이 기록한다.

측정 뒤 p=0.5 대 0.4의 고정 준비 상태 | 측정 중에는 상태가 바뀌고 공급 work가 필요하다. 측정 이후 E(V)에 새 부하를 넣을 수 있으나 Q(t)는 열린 항목이다.

0.7 균일 phi=0 대 FRW 팽창 | 주기 Poisson은 평균을 빼므로 배경 zero mode를 계산하지 않는다. 균일 시험을 FRW 재현으로 읽지 않고, 공통 배경·섭동 adapter를 미완료로 남긴다.

SI 시계·기록을 보관했으니 장과 통합? | 입력 교란 결과는 0.7에서 두 파일이 수치 의존성이 아님을 보여준다. 실제 연결된 것만 통합 성과로 표시한다.

재현·설명·예측 판정

기존 값을 WRRA 내부 변환으로 재현한 것은 현실 정합성과 설명 성과다. 알려진 값이라는 이유로 성과를 제외하지 않는다. 이 연구의 구조적 성과는 주소 조건부 상태, 내부 H, SI 교환, 압력과 관측·기록 비용을 같은 형식의 장부로 연결하고 경계별 결과를 실제 계산한 데 있다.

검증 입력과 구성 선택을 고정한 뒤의 반복 전환 확률, 잡음별 기록 오류율, 공간 밀도·장·유한 진화는 조건부 WRRA 모형 예측이다. 예를 들어 p_flip=0.001, 256 tick에서 오류 확률은 0.2005056913이다. 실제 매체·잡음과 다른 조건으로 관측한 결과는 이 수치를 곧바로 시험하지 않는다. 같은 조건의 관측과 불일치하면 해당 모형 규칙을 수정하거나 기각한다.

6. 최종 판정·재현·1.0 이관

연결 연구의 개발 단계는 약속한 0.8에서 종료한다. 0.1–0.7의 유한 조건부 실행 성과는 보존하고, 완전한 자율·공변 연결은 열린 항목으로 남긴다. 상류 0.10·하류 0.12 마감은 변경하지 않는다. 1.0은 이 검증 범위의 통합 논문·공개 확정판이며 미완료 항목의 삭제가 아니다. 수정은 r1/r2로 처리하고 자동으로 새 개발 단계는 만들지 않는다.

재현: numpy, scipy 설치 후 OPENBLAS_NUM_THREADS=1 python reproduce_all.py. 새 0.2 상태·기저를 0.3/0.5/0.6/0.7로, 새 0.3 장부를 0.4로, 새 0.5 시계를 0.6으로 순서대로 전달한다. 0.7 시계·기록 사본은 근거 보관으로 명시한다. 결과 8개 JSON의 바이트 동일성과 입력 해시를 확인했다. 수치 환경은 environment.json, 전체 근거는 results.json·clean_replay.json에 기록했다.

7. r1 수정 내역과 공개 명세

단계 | 수정 | 검사 수: 이전 → r1

0.5 | 작은 SI 생성자 Hermitian 검사를 상대 norm으로 변경. 전자 모드 보정과 SI 에너지 규모를 직접 비교. | 133 → 134

0.6 | 원래 95차원 H의 Hermitian성, 두 모드 불변성, 투영한 상대 생성자와 초기 여기 에너지를 직접 검사. | 83 → 87

0.7 | FFT 운동 연산자의 Hermitian성과 gradient 에너지 일치, 밀도와 동적 에너지 오차의 2차 수렴을 검사. 격자 연속식의 drho가 셀 질량 미분임을 명시. | 40 → 51

0.8 | 원본 ZIP에서 7단계 수치 payload를 직접 비교. 최초 10개 문제와 B09 열린 범위를 검사. 새 결과를 의존 순서대로 전달하고 현재 검토 기준을 동결. | 179 → 188

수정 전후의 과학적 수치 payload는 모두 동일하다. version·검사·입력 해시는 의도적으로 갱신했다. 원본 0.5–0.8 ZIP은 historical/에 보존했다. 0.1–0.4 검토 r1 코드는 변경하지 않고 의존 자료로 포함한다.

전체 통과 수는 1,116 단계 검사 + 188 검토 검사 = 1,304다. 원래 1,279개보다 25개 증가했다. 수정한 0.5–0.7 단계만의 검사는 272개이고, 앞 단계의 844개는 재현 기반 검사다. 188개 검토에는 이전 36개 교차 검사를 한 번만 포함한다.

공개 파일은 한·영 PDF와 전체 재현 ZIP이다. ZIP에는 수정 코드, 선언 입력, 결과, 검토 전후 비교, 최종 문제 장부, 수치 환경과 SHA256SUMS를 포함한다. 정해진 가정 아래의 재현·설명·조건부 예측 성과를 유지하며, 실제 자율 장치·전체 SI 공변 통합은 열린 항목으로 유지한다.
