WRRA M 상하류 연결 연구 0.2 — 조건부 결합 상태와 곱 상태의 비교
Wonsik Choi · Jeongin Choi / 2026-10-03

1. 실행 범위
상류의 고정 95차원 핵자 Hamiltonian과 전류 연산자를 재구성하고, n=2..1,000,000의 φ 조건부 주소 분포로 내부 상태를 준비했다. 128차원 운반자는 I/128로 고정했다. 종은 외부에서 지정한 proton/neutron을 유지했다. 새 보정은 하지 않았다.
주소별 블록 Σφ=Σ_n p(n|φ)|n><n|⊗ρ_internal(n)⊗I128/128를 실행했다.
ρ_internal(n)=(1-aχ(n))|g><g|+aχ(n)|e1><e1|, a=0.2.
χ(n)는 소수 3의 지수 ν3(n)가 홀수인 주소를 표시한다.
거대한 조밀 행렬 대신 주소별 가중치와 두 내부 모드로 정확한 블록 표현을 사용했다. 각 블록의 양성과 trace를 확인하고 실제 95차원 행렬에서 기대값을 대조했다.
D와 반환은 기존 네 분기 확률 장부에 남겨두며 핵자 준비를 적용하지 않았다. 전체 D/R 물리 상태를 새로 구성한 것은 아니다.
주소 탈위상은 상류의 measure-and-prepare 범위를 따른다. 주소 코히런스·일반 얽힘을 보존하는 연결을 구현했다는 주장은 하지 않는다.

2. 계산 사례와 결과
기준, 소수3 진폭 -0.15/+0.15, 소수3 위상 0.7의 네 사례를 계산했다.
기준 조건부 여기 에너지는 34.47643573912226 MeV이며, 기존 상류 결과와 수치 허용오차 내에서 일치했다.
저진폭/고진폭 사례는 각각 34.706412618296916, 34.02221523985407 MeV였다. 위상만 바꾸는 사례는 탈위상 준비의 특성상 기준 결과를 유지했다.
Q²=0,0.01,0.1 GeV²에서 proton/neutron GE를 실제 고정 연산자로 평가했다. 결합 상태의 내부 주변 상태와 곱 상태는 주소에 무관한 내부 에너지·전류 기대값을 보존했다.

3. 곱 상태의 적용 조건과 실패 사례
주소 의존 진단 응답 r(n)=1+0.25 log(n)/log(N)을 사용했다. 이는 하류의 응답 함수 형태를 사용한 검사이며 φ에 대한 확정 물리 에너지 법칙으로 채택한 것이 아니다.
관측량 r(n)⊗ΔH에서 결합 상태와 주변 상태의 곱은 일반적으로 다르다.
차이 = a·gap·[<rχ>-<r><χ>]이며 직접 계산과 공분산 식이 일치했다.
기준 차이 0.1447722277347907 MeV, 저진폭 차이 0.09544470472893352 MeV, 고진폭 차이 0.1880146565534062 MeV였다.
주소 가중 전류도 같은 공분산 형태로 대조했다. Q²=0의 전하 고정 조건에서는 차이가 사라질 수 있으므로 모든 전류에서 비영 차이를 주장하지 않는다.
주소 응답이 상수인 극한에서는 같은 진단 에너지가 복원됐다.
따라서 곱 상태는 주소에 무관한 내부 관측량에는 정확한 주변 상태 표현이다. 주소·내부 상태에 동시에 작용하는 관측량에는 상관관계가 필요하다. 특정 응답과 준비가 무상관인 경우에도 곱 축소가 가능하다.

4. 검증과 재현
총 95개 구현·수학 검사: 내부 모드 직교성, 95차원 공간, 운반자 양성/trace, 네 분기 정규화, 주소·내부 주변 상태 정규화, φ 가중 trace, 같은 H 에너지, 같은 전류 연산자, 공분산 식, 상수 응답 극한, 상류 기준 재현.
통과 수는 실험 검증 수가 아니다. 두 번의 동일 검사를 새 수로 합산하지 않는다.
Python 3, numpy, scipy, mpmath를 설치하고 패키지 내부에서 다음 명령을 실행한다:
OPENBLAS_NUM_THREADS=1 python compute_0_2.py
results.json은 전체 사례·검사·근거 소스 해시를, internal_and_carrier_basis.npz는 실제 내부 모드·H·운반자 행렬을 제공한다. 0.1 규약은 함께 보존한다.

5. 0.2 판정과 0.3 전달
φ 조건부 결합 상태, 양성·trace, 주변 상태 보존 및 상관관계에 민감한 관측량 비교를 완료했다.
기존 하류 곱 상태를 폐기하지 않는다. 해당 상태가 정확한 관측량 범위를 제한하고, 주소 가중 내부 관측량에는 결합 상태를 사용한다.
0.3은 내부·여기 에너지를 J로 옮기고 입자 수·부피·환경 공급을 선언한 뒤, 거시 보정 에너지와의 중복 여부를 판정해야 한다. 현재 에너지 진단을 하류 우주 밀도에 더하지 않는다.
물리 초, 여기 공급 기원, 종별 풍부도, 기록 안정성, 비균질 중력 동역학은 아직 구현하지 않았다. 실제 운반자 상태가 주소에 의존하는 경우와 복소 전류 연결도 후속 검증 범위다.
상류 0.10·하류 0.12 마감 유지. 연결 연구 0.8에서 종료, 1.0은 통합 확정판.

검토 r1: 근거 파일 범위를 포함한 의존 파일로 제한하고, 교환 입력 검증과 상태 trace 검사를 보강했다. 전체 자료집의 reproduce_all.py 및 review_checks.json이 최신 검토의 실행 근거이다.
