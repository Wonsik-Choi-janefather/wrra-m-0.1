## Executed scope

0.1 defines typed interfaces and ten issue assignments. 0.2 executes the dephased phi-conditioned address/internal classical-quantum state with stationary I/128 carrier. Product reduction preserves address-independent internal observables, while address-weighted probes retain covariance. 0.3 matches an expected population to the reference phenotype allocation and replaces it by rest plus excitation rather than adding it twice; finite reservoir exchange has opposite signed entries. 0.4 derives pressure and homogeneous FRW response from declared post-preparation volume laws.

The bridge is conditional on external species/population calibration, a finite reservoir input, fixed comoving prepared states and a pressureless included-reservoir assumption. It does not derive physical preparation apparatus, actual species abundance, source-frame SI time, durable records or nonuniform covariant dynamics. Address-sensitive probes are diagnostics, not additional cosmic energies. Historical numerical rows are unchanged.

## Reproduction

Install numerical dependencies numpy, scipy and mpmath, then from this directory run:

```sh
OPENBLAS_NUM_THREADS=1 python reproduce_all.py
```

Stage case checks: 15 + 95 + 134 + 600 = 844. Cross-stage checks: 36. Total: 880 mathematical/implementation case checks, not independent experiments.
Five audit/result JSON files reproduce byte for byte in a clean directory. See clean_replay.json. Native numerical results are in studies/. The historical/ directory holds the original four stage packages; those are preserved snapshots, not current review outputs. See document_checks.json for visual QA of both five-page review PDFs.

To rebuild review PDFs, install reportlab and NanumGothic, then run build_review_pdfs.py. This PDF rebuild is separate from numerical replay. Dependency versions used in review are recorded in environment.json.
