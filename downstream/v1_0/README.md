## Reproduction

Use a Python environment with NumPy, SciPy and mpmath as specified by the archived requirements. Auditing the integrated documents additionally requires python-docx, lxml and pypdf. Run from the extracted integrated package:

```text
python synthesis/prepare_and_replay.py
```

The driver creates a fresh `audit_work` directory, unpacks the preserved archive, removes captured results, runs the release and review commands, then checks the regenerated bytes and bilingual manuscripts. It refuses to overwrite an existing working directory. Use `--work-dir` to select another new directory. Differences on another platform should be examined in the numerical receipts and file hashes; bitwise reproduction here was verified in the supplied execution environment.

To regenerate editable Word from the integrated sources, install pandoc and python-docx and run `python synthesis/build_publications.py`. PDF rendering also needs LibreOffice, Poppler and the stated language fonts. The supplied rendered PDFs are the reviewed publication versions.
