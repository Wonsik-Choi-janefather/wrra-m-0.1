### 평가 요약과 초록

**검증 입력.** 고정 WRRA Core 1.0과 최소계산우주론 MCC 2.3.2, 검토된 상류·하류·연결 연구, 검증 상수와 채택한 관측 보정값을 사용한다. 유한 주소 범위, 내부 상태, 종별 점유수, 에너지 응답, 공급 경계와 시계 선택은 각각 장부에 명시한다.

**WRRA 고유 변환.** 유한 SOURCE 주소와 합성 관계를 두 단계 필터로 분할하고, 표현형 조건부 주소를 같은 내부 Hamiltonian의 상태로 준비한다. 그 상태의 에너지와 전류를 함께 판독하고, 기존 표현형 에너지를 정지·여기 에너지로 교체한다. 공급원과 측정 기록의 에너지 증분을 중복 없이 합산한 뒤 같은 에너지의 부피 미분에서 압력과 균질 팽창을 계산한다. 선택한 고유시간에서 측정 후 진화와 반복 기록을 실행하며 별도의 유효 공간 모형에서 상태와 장의 되먹임을 계산한다.

**산출값.** 유한 비보정 잔존 4.876893353%, 공동 보정 주소 분할 5%·26.8%·68.2%, 같은 내부 상태의 기준 여기 34.4764357391 MeV를 연결한다. 에너지 보정에 따라 현재 감속계수 −0.52855 또는 −0.523을 재현한다. 이상적 측정·기록의 일과 공급 경계를 함께 계산하며, 지정한 기록 잡음에서 256회 뒤 오류 0.2005056913을 산출한다. 이번 재실행에서 연결 연구의 1,116개 단계 검사와 188개 검토 검사, 하류 96개 구별된 검사군 및 37개 파일의 동일 재현을 확인했다.

**반증조건.** 정규화·양성성·분기 완비성·에너지 수지·압력 미분·전류·시간 위상·입력 의존성·수렴 중 하나라도 선언 명세와 다르면 해당 변환을 수정하거나 기각한다. 동일 보정과 물리 준비 조건에서 관측이 조건부 산출과 불일치하면 대응 규칙을 재검토한다.

**결론.** 본 논문은 최소계산·공통운반자·표현형이라는 한 방법 아래 유한 생성, 공통 상태의 물리 판독, 측정·기록 비용 및 기하 응답을 실행 가능한 연결로 통합한다. 이는 한 비특권적 우주의 선택된 구성에 대한 재현·설명과 조건부 예측 성과이다. 자율 공급·측정 장치, 실제 입자종 풍부도, 시계율의 물리적 결정 및 균질 배경과 비균질 상태를 함께 진화시키는 SI 공변 모형은 명시된 접속 과제로 남는다.

핵심어 WRRA M 최소계산 공통운반자 두 단계 필터 표현형 정보부하 에너지 장부 양자 측정 고유시간

# 1 연구 목적과 통합의 의미

WRRA의 목적은 특별한 지위를 부여하지 않은 하나의 우주를 최소계산·공통운반자·표현형이라는 공통 방법으로 설명하는 것이다. WRRA M은 그 구조를 검증 상수와 관측값에 맞추어 우리 우주의 선택된 실행으로 구체화한다. 여기서 최소계산은 필요한 표현과 재사용 규칙, 안정성을 위한 여유를 포함하는 충분한 실행 구조를 뜻한다. 본 계산은 가능한 구성 중 하나를 택하며 우주의 유일한 해나 전역 최적화 정리를 전제하지 않는다.

상류는 무엇이 생성·진입·잔존하고 어떤 표현형을 판독할지 구성한다. 하류는 주어진 상태가 어떤 에너지·압력·전류·시계·기하 응답으로 읽히는지 계산한다. 두 연구를 연결하려면 같은 분모, 같은 상태, 물리 단위, 공급 경계와 시간 좌표가 실제 계산에서 전달되어야 한다. 같은 기호를 쓰거나 결과 숫자가 같다는 이유만으로 통합을 선언하지 않는다.

**검증 입력 → WRRA 고유 변환 → 산출값 → 반증조건.** 상류 통합 1.0 r1 [1], 하류 통합 1.0과 그 재현 계열 [2], 연결 검토 0.1~0.4와 0.5~0.8 [3,4]를 입력으로 사용한다. 연결 코드의 입력 전달을 추적해 실행한 경로와 근거로만 보관한 경로를 판별한다. 그 결과 주소 조건부 상태에서 SI 장부와 균질 팽창까지, 같은 내부 생성자에서 측정과 반복 판독까지 실행된 연결을 얻는다. 연결되었다고 표시한 입력의 변화가 계산에 전달되지 않으면 그 연결 주장을 기각한다.

**판정.** 독창성은 알려진 숫자의 새로움에 두지 않는다. WRRA 고유의 주소 구성, 순서 있는 필터, 조건부 상태 준비, 공통 에너지·전류 판독과 경계별 수지 연결에서 판정한다. 알려진 값에 의한 모형 수정과 재현은 현실 정합성과 설명 성과이다. 검증 입력과 구성 선택을 고정한 뒤 계산한 미측정 물리량은 조건이 명시된 WRRA 예측이다. 다른 이론의 같은 숫자는 이 내부 계산의 귀속을 없애지 않는다. 외부 이론의 식은 본 장부에서 실제 실행된 범위에 한해 통합이라고 부르며, 모든 모형에 같은 입증 기준을 적용한다.

# 2 상태 공간과 보정 장부

주소, 운반자, 입자 내부 상태와 채널 표현은 서로 다른 공간이다. 주소 n은 자동으로 입자종, 물리 길이 또는 정보 bit 수가 되지 않는다. 정보부하는 양의 상태 의존 연산자의 기댓값이며 Shannon 정보량이나 채널 개수와 동일시하지 않는다. 표현형은 선택된 판독 출력이고, 표현형이 없는 부문에도 양의 부하를 배정할 수 있다.

**검증 입력 → WRRA 고유 변환 → 산출값 → 반증조건.** 고정값, 단위 정의, 구성 가정을 서로 다른 장부 항으로 표시하고 상태 공간의 형식을 분리한다. 주소 비율에서 물리 에너지로 넘어갈 때 응답 계수를 명시한다. 그 결과 잔존 31.8%와 전체 100%, 주소 비율과 에너지 비율을 모순 없이 다룬다. 서로 다른 정규화나 공간을 직접 더하거나 같은 물리량이라고 치환하면 그 산출을 거부한다.

**판정.** 본 논문의 통합은 형식과 단위가 보존된 전달에 근거한다. 세대 수와 채널 배치, 내부 모드 수, 공간 격자 수는 각각 독립된 구성 명세이다.

# 3 공통운반자와 조건부 채널 선택

하류의 출발 구조는 두 7차원 부문과 불변 1채널이다. SU(3) 색 부분군에서 각 7은 삼중항·반삼중항·단일항으로 분기한다. 그 결과 15채널은 최소 표준모형 한 세대의 색 다중도와 대응한다 [7]. 여기서 7은 관측된 공간 방향의 수가 아니다.

$$\mathcal C_{15}=\mathbf1_0\oplus\mathbf7_A\oplus\mathbf7_B,\qquad
\mathbf7\downarrow SU(3)=\mathbf3\oplus\overline{\mathbf3}\oplus\mathbf1.\qquad(1)$$

중성 운반 채널을 더한 16채널의 채택한 짝짓기는 (4,2,1)과 (반4,1,2)이다. 이 조건 아래 한 초전하 규칙이 알려진 한 세대 전하 배치와 anomaly 상쇄를 재현한다.

$$\mathcal C_{16}=\mathcal C_{15}\oplus\mathbf1_N,\qquad
Y=T_{3R}+\frac{B-L}{2},\qquad Q=T_{3L}+Y.\qquad(2)$$

색을 보존하는 네 후보 필터의 적합도는 공통 양의 운반 계량에서 응답 차이의 음의 제곱노름이다. 목표 필터가 유일한 최대인 조건은 좌·우 점수 간격이 모두 양수인 것이다. 양의 율의 replicator 선택은 목표 필터의 초기 지지가 영이 아니면 수렴하며, 최소 간격이 4ρ보다 크면 크기 ρ의 항별 교란 아래 선택이 보존된다.

**검증 입력 → WRRA 고유 변환 → 산출값 → 반증조건.** 고정 채널 짝짓기와 원점별 보정 응답을 입력으로 공통 계량의 점수를 계산한다. 균일 기준 응답 0.672634137과 0.825428002에서 좌·우 간격 0.04669193039를 얻고 공개한 아홉 상태·부피 사례에서 목표 필터가 선택된다. 양의 간격, 운반 rank 또는 초기 목표 지지가 사라지면 유일 선택 주장은 성립하지 않는다.

**판정.** 공통 운반과 조건부 채널 선택을 실행했다. 대칭 시제품의 간격이 영이라는 실패 결과도 유지한다. 보정된 방향 배치의 기원, Yukawa 상호작용, 세대 혼합과 전체 상호작용 표준모형은 이 채널 계산에서 유도되지 않는다. 게이지 중성 채널은 관측된 sterile neutrino의 질량이나 점유를 확정하지 않는다.

# 4 유한 SOURCE와 순서 있는 두 단계 필터

유한 주소 가중치는 소수 인수 계보를 재사용하는 구조를 따른다. 소수는 독립 SOURCE 주소이고 합성수는 인수와 지수를 보존한 관계 주소이다. 접힘 지표 Ω(n)−1은 산술 관계 지표이며 물리 공간 차원으로 치환하지 않는다. 소수로 오독되어 진입한 합성수도 산술적 합성수 정체성을 유지한다.

$$Z_N(\alpha)=\sum_{n=2}^{N}n^{-\alpha},\qquad
w_n=\frac{n^{-\alpha}}{Z_N(\alpha)},\qquad \sum_n w_n=1.\qquad(3)$$

기본 계산은 유한 합이다. Euler 곱은 소수 인수 재사용의 수학적 근거를 제공한다 [9]. 실현되지 않은 무한 물리 자원은 실행 장부에서 Null로 취급한다. 수학적 극한을 비교 도구로 사용하는 것과 무한한 물리 실재를 요구하는 것은 구분한다. 모형의 유한 실행을 위해 무한 실재를 추가하지 않는다.

입장 contraction A와 복귀 contraction B는 A†A ≤ I, B†B ≤ I를 만족한다. 입장 후 복귀하지 못한 양과 전체 복귀는 다음과 같다.

$$q_{\rm res}=\operatorname{Tr}[\rho A^\dagger(I-B^\dagger B)A],\qquad
q_R=1-\operatorname{Tr}(A\rho A^\dagger)+\operatorname{Tr}(BA\rho A^\dagger B^\dagger).\qquad(4)$$

두 항의 합은 1이다. 일반 연산자에서는 순서가 중요하다. 실제 주소 구현에서는 정상 복귀가 소수를 선택하고 짝수 합성수는 D에, 홀수 합성수의 선택된 진입은 φ에 남는다. 일정 입장률 β의 효과 연산자는 다음과 같다.

$$E_\phi=\beta P_{\rm odd,c},\qquad E_D=P_{\rm even,c},\qquad
E_R=P_{\rm prime}+(1-\beta)P_{\rm odd,c},\qquad\sum_\ell E_\ell=I.\qquad(5)$$

φ 판독은 n=2m+r의 이진 짝짓기 isometry V|n⟩=|m⟩⊗|r⟩에서 남는 r=1 포트를 합성수 선택과 결합한 것이다. 초기 반사와 정상 복귀는 구별된 Kraus 분기이며 R로 coarse 합산할 때 밀도행렬을 더한다. 두 진폭을 임의로 더해 순수 복귀 상태로 만들지 않는다. 잔존의 지속은 후속 갱신이 ker B를 보존한다는 조건을 추가로 요구한다.

# 5 프레임 입장과 셔터 기록

위상 구동 입장은 네 zeta 영점 높이 γj, 동일 계수와 위상 증분 ξ = 0.1을 사용한다. 각 프레임의 새 입장은 아직 남은 후보만 소비하므로 같은 주소를 반복 계상하지 않는다 [1,2].

$$\delta_n(k)=\sum_j c_j\cos[\gamma_j(\log n+\xi k)+\theta_j],\qquad
a_n(k)=\frac{1}{1+\exp[h-\delta_n(k)]}.\qquad(6)$$

$$T_n(K)=1-\prod_{k=0}^{K-1}[1-a_n(k)],\qquad
\phi+D+S+R=1.\qquad(7)$$

대기 S는 선언한 회수 경계에서 R로 넘어간다. K = 8의 기준에서 문턱 h = 1.447673170352440이 5%를 맞춘다. 같은 α와 h에서 4 또는 16프레임을 사용하면 φ = 3.704795% 또는 5.682474%이다. 서로 다른 구동기를 따로 5%에 재보정해도 조건부 주소 분포는 다르다. 동일 총비율이 동일 생성 이력을 뜻하지 않는다.

셔터는 φ D R의 coarse 상태에서 분기 확률을 보존하며 코히런스를 줄이는 완전양의 trace 보존 채널이다. 기록 강도 ηrec는 자기 응답 보정 η와 구별한다.

$$\mathcal S_{\eta_{\rm rec}}(\rho)=(1-\eta_{\rm rec})\rho+
\eta_{\rm rec}\sum_\ell P_\ell\rho P_\ell,\qquad0\leq\eta_{\rm rec}\leq1.\qquad(8)$$

**검증 입력 → WRRA 고유 변환 → 산출값 → 반증조건.** 기준 분기와 선언한 셔터·후속 혼합을 입력으로 기록 순서를 비교한다. 완전 기록의 순도는 0.539448이며, 각도 0.25의 비교에서 회전 후 기록의 φ는 0.007845982335, 기록 후 회전은 0.063343500754이다. 셔터만으로 분기 확률이 변하거나 양성성·trace가 깨지면 채널을 기각한다.

**판정.** 기록은 당장의 확률을 유지하면서 후속 간섭을 바꾸는 연산이다. 상류 셔터가 제공하는 상태 갱신과 뒤에서 에너지를 배정하는 실제 유한 기록 레지스터는 서로 다른 단계이다. 선택된 zeta 구동이 유일한 우주 구동이라는 결론은 요구하지 않는다.

# 6 안정한 내부 상태와 같은 상태의 에너지 전류

상류 입자 예시는 잔존 표지 45와 75, 소수 3과 5의 계보를 선택한다. 양성자·중성자 종 표지는 외부에서 배정한다. 초기 공간 이차 결합은 두 모드에서 축전하와 자기 응답을 재현하지만 큰 공간 확대에서 하한 안정성에 실패한다. 이 실패를 보존하고 상호작용을 유계 함수로 수정했다 [5].

$$W_\lambda=\frac{W_0}{k_\lambda(1+\lambda s)},\qquad
s=\frac{x^2+y^2}{\ell^2},\quad\lambda>0,\qquad
H_B=(E_{B,\rm rest}-\Delta e_0)I+\Delta h.\qquad(9)$$

양의 kinetic·confining 항과 유계 결합은 하한을 제공한다. K = 8에서 165개 공간 모드와 95개 대칭 상태를 사용한다. 축전하 입력으로 xc = 0.8208877164를 보정하고 첫 양의 parity 여기의 중심을 1370 MeV로 배정하면 Δ = 507.032217686 MeV와 gap = 431.081244315 MeV를 얻는다. 이 이산 Hermitian 계산은 공명 폭과 복소 pole을 계산하지 않는다.

전하 반지름의 초기 점전하 모형은 중성자 평균제곱 반지름 −0.186912 fm²를 내어 비교값 −0.1155 fm²와 어긋났다. 영 전하의 isovector 보정항과 공통 폭을 추가해 두 전하 반지름을 공동 보정하며 ℓ = 0.65715059784 fm, cE = −0.09708290347 fm²를 얻었다 [6]. 이 수정은 검증값을 반영한 모형 구성이다. 차원 없는 내부 Hamiltonian과 여기 척도는 유지한다.

에너지·전하·자기·축전류는 동일 내부 상태에서 계산한다. 자기 응답은 같은 Hamiltonian의 장 미분이고, 유한 운동량의 실제 n→p 전류는 전자기 isovector 차이와 일치한다. 투영된 종방향 전류는 내부 연속 관계를 만족한다. 전체 횡방향 상대론적 게이지 전류까지 구현한 것은 아니다.

**검증 입력 → WRRA 고유 변환 → 산출값 → 반증조건.** 입자 상수와 선언한 공간·전류 보정을 같은 95차원 상태에 넣는다. Q² = 0.1 GeV²의 바닥 상태에서 GEp = 0.7367799, GEn = 0.0399134, Mp = 1.9543552 μN, Mn = −1.4207472 μN, GA = 0.9039833을 얻는다. Hermitian성, 대칭, 장 미분, 전류 연속 관계 또는 공간 확대 수렴이 깨지면 그 내부 구성은 실패한다.

**판정.** 내부 질량·여기·전류의 공통 판독을 실행했다. 미보정 중성자 자기 반지름 0.831987107 fm과 비교값 0.864 fm의 차이는 남긴다. β 붕괴도 같은 전류와 위상공간을 사용하지만 기존 κ 고정의 수명 846.204102380 s와 κ를 재보정한 878.3 s는 별도 장부이다. 고차 복사·recoil, 미시 γW box와 유도 pseudoscalar는 이 계산에 포함되지 않는다 [6].

# 7 주소 조건부 내부 상태의 공통운반자 연결

상류 주소 잔존이 내부 상태의 에너지·전류에 실제로 영향을 주도록 조건부 준비를 구성한다. χ(n)는 소수 3의 지수 ν3(n)가 홀수인지 표시한다. φ 조건부 확률 p(n|φ)에 대해 g와 e₁은 고정 내부 Hamiltonian의 바닥·첫 여기 고유벡터이다. 준비 강도 aₚ는 우주 scale factor a와 구별한다.

$$\rho_{\rm int}(n)=[1-a_p\chi(n)]|g\rangle\langle g|+
a_p\chi(n)|e_1\rangle\langle e_1|,\qquad
p_{\rm exc}=a_p\sum_n p(n|\phi)\chi(n).\qquad(10)$$

$$\Sigma_\phi=\sum_n p(n|\phi)|n\rangle\langle n|\otimes
\rho_{\rm int}(n)\otimes\frac{I_{128}}{128}.\qquad(11)$$

이것은 대각 주소의 고전 양자 결합 상태이다. 백만 주소의 거대 조밀행렬을 할당하지 않고 블록 수축으로 정확히 계산한다. φ 조건부 상태의 trace는 1이고 전체 장부에서 fφΣφ의 trace는 fφ이다. D와 R에 임의 핵자 준비를 적용하지 않는다. 준비 채널의 Kraus 완비성은 양성성과 정규화를 보장한다.

# 8 중복 없는 SI 에너지와 공급 경계

주소 확률은 입자 수를 자동으로 정하지 않는다. 선택한 순수 양성자 또는 중성자 예시에서 기준 V₀의 기대 점유수 N̄를 기존 표현형 할당 에너지에 맞춘다. N̄ < 1은 기대 점유수이며 한 실행에서 분수 입자가 생성됐다는 뜻이 아니다.

$$\overline N=\frac{E_{\phi,\rm ref}}{E_{B,\rm rest}+E_{\rm exc,base}},\qquad
E_{\rm sys}=\overline N(E_{B,\rm rest}+E_{\rm exc})+E_D+E_R.\qquad(13)$$

식 13은 기존 Eφ를 정지·여기 분해로 교체한다. 기존 총 에너지에 그 분해를 다시 더하면 Eφ 전체가 중복된다. 기존 보정 양성자 예시의 N̄ = 0.2425893464이며 기준 표현형 에너지는 정지 3.6467913480 × 10⁻¹¹ J와 여기 1.3399990150 × 10⁻¹² J로 나뉜다. 1 MeV = 1.602176634 × 10⁻¹³ J를 사용한다.

$$\Delta E_{\rm sys}=\overline N(E_{\rm exc,case}-E_{\rm exc,base}),\qquad
\Delta E_{\rm env}=-\Delta E_{\rm sys}.\qquad(14)$$

공급원이 경계 밖에 있으면 시스템 증가분은 외부 일이다. 공급원을 포함하면 두 증분이 상쇄되어 총 에너지가 보존된다. 실제 공급원 상태와 압력은 추가 명세이며, 유한 저장고 진단에서는 초기 0.2 Eφ,ref와 압력 없는 공변 총량을 채택한다. 이는 새로운 우주 성분비가 아니다.

**검증 입력 → WRRA 고유 변환 → 산출값 → 반증조건.** 같은 내부 여기, MeV 변환, 고정 기대 점유수와 유한 저장고에서 교체·signed 교환을 계산한다. 작은 준비 변화는 양성자 기준 시스템에 8.9385339569 × 10⁻¹⁵ J를 공급하고 환경에 반대 증분을 남긴다. 음의 저장고, 공급 부족, 비유한 값 또는 포함 총량 변화는 실패로 처리한다.

**판정.** 상태별 여기 차이를 SI 에너지 장부로 전달했고 공급 경계의 의미를 분리했다. 하류 입장 conversion work 1.3279304601 × 10⁻¹² J와 이번 내부 준비의 일을 동일 사건인지 확인하지 않고 더하지 않는다. 소스, 구동기, 장치와 저장고를 한 자율 Hamiltonian으로 진화시킨 결과는 아직 없다.

# 9 같은 에너지의 압력 팽창과 국소 중력

하류는 양의 운반 부하 Aφ = I, AD = Kc/2, AR = Kb/2를 사용한다. Kc는 주기 운반 격자의 −∇²에 대응하는 양의 준정부호 이산 연산자이고 Kb는 공개한 비가환 양의 대조 연산자이다. 주소 응답 μℓ와 SI 계수 ηℓ를 결합해 하나의 에너지 함수를 구성한다. 준비 뒤 상태·입자 수를 고정한 구간의 φ D 공변 총 에너지는 일정하고 R 밀도는 일정하다.

$$u_{\rm crit}=\frac{3H_0^2c^2}{8\pi G},\qquad
E_\ell=V_0\eta_\ell\mu_\ell a^{\nu_\ell}\operatorname{Tr}(\rho A_\ell),\qquad
(\nu_\phi,\nu_D,\nu_R)=(0,0,3).\qquad(15)$$

$$V=V_0a^3,\qquad u=\frac EV,\qquad
P_\ell=-\partial_V E_\ell=-\frac{\nu_\ell}{3}u_\ell.\qquad(16)$$

균질 연결에서는 E(V) = M + LV, P = −L, u = M/V + L이다. 같은 에너지와 압력에 채택한 균질 중력 응답을 적용한다.

$$H^2=\frac{8\pi G}{3c^2}u,\qquad
q=\frac{u+3P}{2u},\qquad a\frac{du}{da}+3(u+P)=0.\qquad(17)$$

전역 뒤틀림 판독은 D+R, 국소 추가 인력 척도는 D를 사용한다. 같은 에너지의 응력과 그 기하 판독을 두 번 더하지 않는다. 국소 응답과 계수 1/8은 선언한 구성 법칙이다.

$$a_T=cH_0\sqrt{\frac{u_D}{8u_{\rm crit}}},\qquad
\zeta_T\kappa_h^2=\frac{16\pi G}{c^4}(u_D+u_R),\qquad
g=\frac{g_M}{1-\exp[-\sqrt{g_M/a_T}]}.\qquad(18)$$

하류 전자 모드 23은 μE = Ee/23 = 22217.345682174 eV를 정한다. 그 시간 단위 tμ = ℏ/μE = 2.962603932832 × 10⁻²⁰ s이다. 하류의 선택 갱신 간격 0.05tμ와 소스의 위상 증분 0.1에 연결한 프레임 간격은 다르다.

# 12 유한 비균질 상태와 장의 되먹임

연결 0.7은 기준 내부 인구를 서로 다른 초기 공간 프로파일의 두 운반 성분에 넣는다. 두 성분의 운반 법칙은 같고 성분 사이 새 전이는 없다. 이 구간은 준비 후 외부 교환이 멈춘 무차원 비상대론적 유효 모형이다.

$$i\partial_s\psi_j=\left[-\frac12\partial_x^2+\Phi\right]\psi_j,\qquad
\partial_x^2\Phi=\lambda(\rho-\overline\rho),\qquad
\rho=\sum_j|\psi_j|^2.\qquad(24)$$

주기 경계에서 평균을 빼고 평균 Φ = 0으로 정한다. Fourier 미분과 대칭 split step은 갱신된 밀도로 장을 다시 계산한다. 점유 밀도→장→상태의 되먹임이 실제로 실행된다. 자기일관 장의 동적 에너지는 결합의 1/2를 포함한다.

$$E_{\rm dyn}=\frac12\int\sum_j|\partial_x\psi_j|^2dx+
\frac12\int\rho\Phi\,dx.\qquad(25)$$

**검증 입력 → WRRA 고유 변환 → 산출값 → 반증조건.** L = 20, λ = 1, 주기 경계와 Gaussian 초기 상태에서 최종 s = 1까지 진화한다. N = 64의 시간 간격 0.01, 0.005, 0.0025에서 밀도 차이의 비 4.000041을 얻는다. N = 64와 128의 격자 비교 L2 차이는 9.02348 × 10⁻¹²이다. 빠른 내부 정지 에너지를 오차 분모에 넣지 않고 동적 에너지 drift, Poisson 잔차, 국소 전류·연속식, 역진화와 자유 대조를 검사한다. 정규화·전류·수렴·에너지 진단이 명세에 어긋나면 유효 구간을 기각한다.

**판정.** 유한 비균질 자기일관 되먹임을 구현했다. source는 여기 에너지까지 포함한 stress energy tensor가 아니라 동일 가중 운반 점유 밀도이다. 시계율과 기록 일을 두 배로 바꿔도 이 계산의 밀도·장이 변하지 않는다는 0.8 의존성 대조를 유지한다. 준비 인구를 0.12로 바꾸면 최종 밀도가 최대 0.01681125416 변한다. 따라서 내부 인구는 실제 입력이며 시계·기록 파일은 근거로 보관된 자료이다. 균질 밀도에서 Φ = 0은 평균을 뺀 Poisson의 결과이고 FRW 배경 재현이 아니다. SI kinetic·길이·G의 공통 보정, 기록 후 상태의 공간장 전달 및 전체 공변 배경·섭동 통합은 아직 열려 있다.

이미 측정된 상수·입자 성질·구성비를 재현한 것은 재현·설명 성과로, 시험 은하와 lensing의 계산은 선언한 시험원 조건부 산출로, 미측정 prepared 상태의 응답은 해당 물리 사상이 고정된 WRRA 조건부 예측으로 표기한다. 단순 코드 대조와 seeded 표본은 구현 검증으로 표시한다. 각 성과를 숫자의 새로움만으로 부정하지 않으며 서로 다른 증거 수준을 한 개의 증명 횟수로 합치지 않는다.

# 14 재현과 최종 통합 판정

이번 논문은 새로운 관측 보정을 추가하지 않는다. 기존 두 에너지 보정을 유지하고 준비·측정·공급 경계의 전달을 재현한다. 연결 검토 패키지에서 0.1부터 0.7까지 새 출력을 의존 순서대로 전달한 뒤 0.8 검토를 실행했다. 15, 95, 134, 600, 134, 87, 51개의 단계 검사와 188개 검토가 통과하여 합계 1,304이다. 수는 수학·구현·근거·예상 실패 확인을 포함하며 관측 실험 수가 아니다.

하류 0.10~0.12는 결과 폴더와 한·영 계산 원고를 제거한 깨끗한 복사본에서 다시 계산했다. 32, 28, 36개의 구별된 검사군이 통과했고 37개의 결과·원고 파일이 보관 기준과 바이트 단위로 같았다. 현재 전체 archive manifest의 312개 항목도 확인했다. 이 재현과 연결 검사의 반복된 의존 자료를 더해 독립 증거 수를 부풀리지 않는다. 상류 0.4~0.6의 395개와 0.7~0.10의 1,395개는 선행 공개 기록이며 본 논문의 신규 실험으로 세지 않는다.

**검증 입력 → WRRA 고유 변환 → 산출값 → 반증조건.** 공개한 고정 입력·코드·결과·해시를 깨끗한 환경에서 다시 실행한다. 새 결과와 보관 결과의 동일성, 연결 입력의 해시와 선언한 실패 조건을 확인한다. 이번 전달·단위·압력·측정 검사가 통과했다. 원고·실행·해시의 불일치가 생기면 해당 출판 명세를 수정한다.

**최종 판정.** 상류 유한 생성은 선택된 내부 상태를 준비하고 그 상태는 에너지와 전류를 함께 낸다. 그 에너지는 기존 표현형 할당을 중복 없이 교체하며 공급과 기록 증분을 거쳐 같은 압력과 균질 팽창으로 전달된다. 같은 내부 생성자와 선택된 고유시간은 관측 후 진화와 반복 확률을 정한다. 별도의 유효 공간 구간은 기준 인구로 상태·장 되먹임을 실행한다. 이 연결 전체가 본 통합 논문의 성과이다.

상류 개발 0.10, 하류 개발 0.12, 연결 개발 0.8의 마감을 유지한다. 통합 1.0은 검토된 실행 범위의 한 논문이며 새 번호의 자동 확장을 뜻하지 않는다. 자율 소스·입장·준비·측정 공급원, 종 선택·실제 풍부도, 영속 기록 매체, 물리 시계율 및 공통 SI 공변 기하는 명시된 후속 연구 대상으로 보존한다. 비특권적 하나의 우주를 같은 방법으로 설명한다는 연구 목적과 현재 실행의 도달 범위를 함께 제시한다.
