# 방향별 해상도·검증·정보 보존 — 보강 v0.1

최원식 · 최정인. 『최소계산우주론 3.0』 v0.28-r6의 38장·139장·부록 J에 연결하는 온라인 보강이다. WRRA는 Wonsik Reality–Renderer Architecture다.

## 1. 방향별 해상도 비교

**검증 입력.** 기존 `finite_scale_bridge_v0_1`의 유한 주기 영역, 최근접 라플라시안, 약한 장 수신 해석을 고정했다. 기존 SOURCE 프로파일을 포함한 계산을 다시 실행해 179/179 검사 통과를 확인했고, 별도 모드/Parseval 검사와 격자 계산의 최대 차이는 2.1771e-16이었다. 수신 해상도가 바뀌어도 SOURCE 주소 수 1,015,000은 바뀌지 않는다.

**WRRA 고유 변환.** SOURCE와 수신 격자를 구분한 상태에서, 같은 파장을 서로 다른 방향으로 읽는다. h=1/n, k=2πm에 대해 기존 수신 연산자의 고유값은 다음과 같다.

$$\lambda_h(\mathbf k)=\sum_{j=1}^3\frac{4\sin^2(k_jh/2)}{h^2}.$$

이 차분식은 채택한 표준 수치 기법이다. 이번 WRRA의 기여는 기존 유한 스케일 수신 모듈 안에서 SOURCE·해상도·관측량·판정을 연결해 확장한 계산이다. m=(3,0,0), (2,2,1)은 모두 |k|=6π다. 위상속도 상대오차 δ=1−sqrt(λh/|k|²), Poisson 응답 오차 |k|²/λh−1을 비교했다. 이는 공간 수신 연산자의 반이산 분산이며, 시간까지 이산화한 전체 전파 실행은 아니다.

**산출값.**

| n | 축 방향 위상속도 오차 | 비스듬한 방향 위상속도 오차 |
|---:|---:|---:|
| 32 | 0.014394852504 | 0.005877829429 |
| 64 | 0.003610440030 | 0.001471750809 |
| 128 | 0.000903344360 | 0.000368081140 |
| 256 | 0.000225882009 | 0.000092029252 |

n=32,64는 실제 격자 연산과 모드식을 대조했으며 고유값의 절대 차이는 7.4e-13 미만이었다. n=128,256은 모드식 계산이다. 측정된 감소 차수는 1.9953–1.9999였다. 선도 오차 h²Σkj⁴/(24|k|²)는 방향별 계수가 다르면서도 지정한 미세화 계열에서 오차가 감소함을 설명한다. 좌표축 순열·부호 대칭을 확인했지만 이를 모든 회전의 대칭으로 확대하지 않는다.

간격 h를 유지한 별도 비교에서는 n=32·길이 1·모드 (3,0,0)과 n=64·길이 2·모드 (6,0,0)의 파장과 분산이 같았다. 계산 차이는 0이다. 부피만 늘려서는 이 수신 연산자의 분산 오차가 줄지 않는다. 코사인 형태의 60자리 계산으로 다시 확인한 위상 오차 차이는 최대 1.284e-16이었다.

**반증조건.** 기존 재현 실패, 격자 연산과 모드식의 불일치, 선언한 감소 차수 실패는 해당 수치 주장을 무효로 한다. 유한 간격에서 방향차가 전혀 없다는 주장은 위 표로 기각된다. 이번 추가 검사에는 부스트된 상태와 수신 연산자의 대응이 없어 완전한 로렌츠 공변성 검증은 OPEN이다. 관측 한계보다 작은 효과와 수학적으로 0인 효과는 구분한다.

**결론.** 기존 수신 모듈의 동일 파장·방향별 비교가 실행됐다. 유한 해상도에서는 방향별 오차가 다르고, 미세화하면 약 2차로 감소한다. 기존 15채널·광속 방향 계산을 보존하면서 수치 규격을 보강한 성과다. 무한한 물리 우주를 도입한 결과가 아니다.

## 2. 검증기가 오류를 잡는지 검사하기

**검증 입력.** 정상 합성 실행 기록, 16개의 개별 훼손·결측 기록, 난이도가 다른 문항에 대한 합성 오류 사례를 사용했다.

**WRRA 고유 변환.** 정보·상태·해석장치·자원·소유권의 구분을 실행 가능한 검사로 옮겼다. 생명 장부는 전역 유리수 보존식으로, 심리 상태분포는 8단계의 256개 행동 경로 전수열거로, 분산식은 고정밀 계산으로, 정보 소실은 SOURCE 상태군 전수열거로 대조했다. 같은 작업 내의 다른 계산 경로이며 외부 심사자의 검토는 아니다.

**산출값.** 이름을 부여한 두 번째 검증 52/52가 통과했다. 생명 기록의 16개 대조 중 13개 모순·훼손은 거부됐고, 근거가 누락된 3개는 OPEN으로 남았다. 이 수는 전 이론의 완전한 결함 검출률이 아니다. 합성 난이도 사례에서는 쉬운/어려운 문항의 오류확률을 0.1/0.7로 두고, 각 난이도 안에서는 두 응답자의 오류가 독립이라고 설정했다. 합친 공동 오류확률은 0.25로 주변 오류확률 곱 0.16보다 0.09 높지만, 난이도별 조건부 공분산은 0이다. 실제 AI를 새로 시험한 데이터가 아니다.

**반증조건.** 위의 잘못된 기록을 통과시키거나, 확률·자원 보존을 깨뜨리거나, 별도 계산과 불일치하거나, 미측정값을 0으로 처리하면 해당 검증 실패다. AI의 동의 자체로 이 검사를 대신할 수 없다.

**결론.** 기존 검증 체계에 오류 검출 내역과 공통 난이도 대조를 추가했다. 기존에 재현·검증한 성과는 그 범위대로 유지한다.

## 3. 정보 보존과 물리적 초기화 비용

**검증 입력.** 같은 확률의 SOURCE 상태 (a,b)∈{0,1}² 네 개, AND 출력, 세 가지 기록 보존 규칙을 고정했다. Shannon 엔트로피와 이상적 고전 Landauer 초기화 모형은 외부 검증·보강 자료이며 온도 300 K는 예시 입력이다.

**WRRA 고유 변환.** SOURCE 식별자를 해석장치의 출력까지 추적하고, 보존된 기록으로 구분할 수 없는 상태만 묶었다. 버려지는 정보는 H(a,b | 보존 기록)로 계산한다. 별도로 (a,b,t)→(a,b,t XOR (a AND b))의 8상태 가역 구현을 전수검사했다. 같은 변환을 두 번 적용하면 모든 상태가 돌아왔다.

**산출값.**

| 보존 기록 | 버려지는 조건부 정보(bit) | 300 K 이상적 초기화 하한(J) |
|---|---:|---:|
| AND 출력만 | 1.188721875541 | 3.412795405e-21 |
| 입력 a와 AND 출력 | 0.5 | 1.435489443e-21 |
| 입력 둘과 AND 출력 | 0 | 0 |

하한은 보존된 부가정보를 실제 초기화 과정에서 이용할 수 있는, 등온·에너지 준위가 같은 고전 기억장치 모형의 kBT ln(2)×조건부 정보량이다. 마지막 행의 0은 그 기록 대응에서 논리적 정보 소실이 없다는 뜻이다. 실제 장치의 작동 비용이 0이라는 뜻은 아니다. 측정·제어·복사·유한시간 손실과 나중에 부가정보를 초기화하는 비용은 별도 장부가 필요하다. 초기화 명령 수만으로 비용을 정하지 않는다.

**반증조건.** 8상태 복원 실패, 상태군 정보량의 오류, 부가정보 폐기 비용 누락, 조건부 하한을 실제 장치 발열로 보고하는 것은 해당 주장을 무효로 한다. 특히 a=0·AND 출력=0일 때 b는 0 또는 1이므로, 출력과 입력 하나만으로 언제나 원래 입력을 복원한다는 일반화는 성립하지 않는다.

**결론.** 유한 정보 보존 감사가 실제 실행됐다. WRRA 장부에서 무엇을 보존하는지 정밀화하는 성과이며, 실제 장치의 절감량과 우주론적 열역학 결합은 OPEN이다. Bennett의 원리를 WRRA의 새 발견으로 바꾸어 부르지 않는다.
