WRRA-M 상위 구조의 두 단계 차원필터 가설 1.0
최원식 Wonsik Choi | 2026-10-01

내용
초기 진입 필터와 정상 0차원 복귀 필터를 구분한 상류 구조 가설이다.
초기 변동 중 진입한 합성 관계의 접힘 보존을 Actual 잔존의 조건으로 둔다.
물질 표현형과 비표현형 Actual은 잔존의 두 판독이며 세 번째 필터가 아니다.
현재 상태의 갱신 순서를 시간 프레임으로 해석하는 확장을 포함한다.

완성된 출력
paper 폴더에 한국어 Word 원고와 같은 내용의 14쪽 PDF가 있다.
Word의 21개 수식은 기본 OMML 수식이므로 수정할 수 있다.
한 개의 구조도와 열한 개의 수치 및 정의 표를 포함한다.

재현
계산은 code 폴더에서 실행한다. Python 3, NumPy, SciPy가 필요하다.
python compute.py --max-N 1000000 --out results.json
python partition_26_8.py
python analytic_limit.py

장부의 의미
alpha=2, N=1000000, 첫 소수 2 필터의 홀수 합성수 잔존율은
4.8768933533645545%다. 같은 가중치의 산술적 극한은 약 4.876952810%다.
공동 보정 alpha=1.8996876950554356, beta=0.8654570124136961을 사용하면
표현형 5%, 비표현형 Actual 26.8%, 상류 복귀 68.2%를 같은 분모에서 얻는다.
전체 Actual 31.8%는 표현형 5%를 포함한다.
alpha와 beta는 해당 구성비 목표로 보정했다. 입자 상수에서 역산한 값은 아니다.
접힘 보존과 소수 2 계열의 물리 판독은 이 후보의 구성 규칙이다.
주소의 가중치를 에너지 구성비와 비교할 때는 공통 물리 부하를 계산해야 한다.
프레임 간격, 입자 에너지·전하 응답, 제타 영점 위상 변동과 배경 압력은
원고에 정식화한 다음 연결 과제이며 현재 코드에서 실행한 것으로 표시하지 않는다.

본문 및 수식 원문
manuscript.json에는 본문의 블록과 수식 원문이 들어 있다.
source 폴더의 manuscript.py 및 build_doc.py는 문서를 다시 만드는 소스다.
문서 재조판에는 Python 3, python-docx, Matplotlib, lxml, Pandoc 및
Noto Sans CJK KR와 Latin Modern Math 글꼴이 필요하다.
build_doc.py는 작업 환경에서 사용한 한국어 글꼴 경로를 포함한다.
다른 환경에서는 이 경로를 설치한 Noto Sans CJK KR 글꼴 경로로 바꾼다.

기준 구조
WRRA Core 1.0, MCC 2.3.2 및 기존 WRRA-M 하류 파일을 수정하지 않았다.
이 상류 가설은 별도의 원고와 재현 장부로 제공한다.
