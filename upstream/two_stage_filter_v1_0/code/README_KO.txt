WRRA 상류 합성수 잔존율: 유한 소수 필터와 제타 분모 가중치
최원식 Wonsik Choi | 2026-10-01 | 탐색 계산 v0.1

연구 질문
모든 가능성을 유한한 산술 주소로 펼친 다음, 낮은 소수부터 복귀 필터를 추가하면
유사소수처럼 잔존하는 합성수 상태의 비율이 약 5%에 도달하는가?
이 계산은 WRRA Core 1.0과 MCC 2.3.2를 변경하지 않는 별도 상류 탐색이다.
현재는 사용자의 지시에 따라 5% 표현형 잔존분에 집중한다.

검증 입력 → WRRA 고유 변환 → 산출값 → 반증조건

검증 입력
유한 주소 n=2,...,N; 최대 N=1,000,000.
1은 이 시험에서 항등/진공 자리로 제외했다. 이 선택은 물리적으로 확정하지 않았다.
소수는 SOURCE 주소, 합성수는 RELATION 주소로 분류한다.
제타 분모에서 가져온 가중치 후보는 w(n)=n^(-alpha)이다.
alpha=0, 0.5, 1, 1.5, 2, 3을 비교했다.
alpha는 이번 시험에서 입자 상수로 결정한 값이 아니다.

WRRA 고유 변환
기존 WRRA 모듈러 소수 필터를 작은 소수부터 순차 적용한다.
H_p(n)=1-(1/p) sum[k=0,...,p-1] exp(2*pi*i*k*n/p).
정수 주소에서 이는 p가 n을 나누면 0, 나누지 않으면 1이다.
소수 SOURCE를 별도로 분류하고, 합성수 중 모든 적용 필터를 통과한 주소를
잔존 후보로 집계한다. 소수 분류 자체도 LAW의 산술 계산이며 숨긴 추가 물리 결과가 아니다.

C(P,N)={n: 2<=n<=N, n은 합성수, 모든 소수 p<=P에 대해 p가 n을 나누지 않음}.
f_alpha(P,N)=sum[n in C(P,N)] n^(-alpha) / sum[n=2,...,N] n^(-alpha).

n=product(p^valuation_p(n))이므로
n^(-alpha)=product(p^(-alpha*valuation_p(n))).
따라서 각 합성수의 가중치는 그 소수 조합의 곱으로 계산된다.
이 시험의 복귀 필터는 모듈러 필터이며, 제타 가중치는 별도의 점유 가정이다.
제타 영점의 위상 간섭은 후속 계산에 해당한다.

산출값
1) 동일 가중치 alpha=0, N=161, 적용 소수 2·3·5:
   잔존 주소 49, 77, 91, 119, 121, 133, 143, 161.
   전체 160개 중 8개이므로 정확히 5%다.
   이 중 49=7^2와 121=11^2는 같은 소수 계보의 거듭제곱이다.
   서로 다른 소수의 결합만 세면 6/160=3.75%다.

2) 제타 분모 가중치 alpha=2, N=1,000,000, 첫 소수 2 필터:
   모든 잔존 합성수의 가중 잔존율 4.8768933533645545%.
   소수 거듭제곱의 기여 2.4983281300988886%.
   서로 다른 소수 조합의 기여 2.3785652232656660%.
   5%를 식의 출력값으로 직접 입력하지 않은 고정 alpha=2 시험 결과다.
   alpha=2와 마지막 필터 p=2의 물리적 선택은 아직 결정하지 않았다.

3) 같은 N과 p=2를 고정하고 지수 alpha를 목표 비율로 보정:
   목표 5%    -> alpha=1.985109689134182.
   목표 4.93% -> alpha=1.9935256407367197.
   이는 공개한 목표 보정 결과다. 입자 상수에서 이 지수를 유도한 결과는 아니다.
   보정은 정당한 모형 구성 단계이며, 고유 변환의 설명력은 별도로 평가한다.

반증조건과 실제 검사
독립 시험 나눗셈과 소수 분류가 어긋나면 분류 결과를 기각한다.
복소 DFT 필터가 모듈러 선택기와 어긋나면 필터 구현을 기각한다.
소수 인수 가중치의 곱과 n^(-alpha)가 어긋나면 가중 연결을 기각한다.
같은 입력을 재실행해 잔존 집합·비율을 재현하지 못하면 수치 결과를 기각한다.
해당 검사는 통과했다. DFT 최대 오차는 약 8.624e-14이다.
적용 필터를 추가할수록 잔존율은 감소한다.
N 범위에서 p<=sqrt(N)인 필터를 모두 적용하면 합성수 잔존은 0이다.
따라서 현재 시험은 선택한 단계의 잔존 후보를 계산한 것이며,
영구적인 물리적 비복귀를 증명한 것이 아니다.

민감도와 종료 조건
동일 가중치에서 P=5를 유지해 N을 161에서 321로 바꾸면 잔존율은 5%에서 6.875%로 변한다.
N=161을 유지해 7 필터를 추가하면 1.25%, 11 필터까지 추가하면 0%가 된다.
alpha=2, P=2에서는 N=10,000일 때 4.871477356%,
N=1,000,000일 때 4.876893353%다.
서로 다른 유한 범위와 필터 종료점에서 5%가 나타난다. 5% 자체가 구성의 유일성을 뜻하지 않는다.

입자 상수 연결의 다음 계산 명세
전자·양성자·중성자의 질량, 전하, 양성자-중성자 질량 차이를 같은 입력 장부에 넣는다.
공통 물리 사상으로 소수 조합·복귀 필터 종료점·가중 지수를 동시에 좁힌다.
입자마다 별도의 규칙을 만들기 전에 공통 에너지·결합·전하 응답을 명시해야 한다.
소수 거듭제곱이 SOURCE로 복귀하는 Echo인지, 실제 잔존 후보인지도 그 규칙에서 결정한다.
그렇게 결정된 필터의 출력 잔존율을 계산해 5%와 비교한다.
이번 패키지는 이 입자 역산을 이미 완료했다고 주장하지 않는다.

물리 사상 상태
현재 출력은 산술 주소의 점유 가중 잔존율이다.
우주 전체의 에너지 구성비와 연결하려면 상태별 물리 에너지 사상을 계산해야 한다.
현재의 '유사소수'는 WRRA 잔존 관계 상태를 뜻하며 Fermat pseudoprime의 동의어가 아니다.
양성자·중성자의 입자 모드, 질량, 붕괴 안정성은 아직 이 시험에서 산출하지 않았다.

재현
Python 3, numpy, scipy가 필요하다.
python compute.py --max-N 1000000 --out results.json
전체 단계, 범위 비교, 소수 거듭제곱 분해, 목표 보정, 검사 결과가 results.json에 저장된다.

수학 검증 자료
NIST DLMF 27.4, 제타 Dirichlet 급수와 Euler 곱:
https://dlmf.nist.gov/27.4
무한 Euler 곱의 통상적 절대수렴 조건은 Re(s)>1이다.
이번 계산은 모든 alpha에 대해 유한 합만 사용한다.
복소 s를 방출 진폭으로 해석하면 |n^(-s)|^2=n^(-2 Re(s))이며,
점유 가중치 n^(-alpha)와 동일시할 때 alpha=2 Re(s)라는 별도 해석 선택이 필요하다.
