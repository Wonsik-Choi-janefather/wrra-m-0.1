# WRRA M 상류 0.4–0.6 전체 검토와 교정 r1

최원식 / Wonsik Choi · 2026-10-03 · [ORCID](https://orcid.org/0009-0001-4263-9772)

교정 자료집 DOI: [10.5281/zenodo.23112253](https://doi.org/10.5281/zenodo.23112253). 이전 0.3까지의 검토 자료집: [10.5281/zenodo.23092499](https://doi.org/10.5281/zenodo.23092499).

공간 결합의 기저 정의, 안정성·척도 보정, 유한 운동량 전류와 β 보정을 논문·실행 코드·입력·결과에 걸쳐 다시 검토했습니다. 원본 물리 수치는 유지하면서 원시/정렬 모드의 표기, 비유한 입력 계약, shell·구적 조건, 배열 순서에 의존하던 수렴 검증을 교정했습니다. 투영 Fourier 전류의 수반 관계와 고정·재보정 κ의 역할을 분명히 했습니다.

| 교정판 | 내용 | 검증 |
| --- | --- | --- |
| [0.4-r1](studies/v0_4_r1) | 실제 공간 모드, 결합과 자기장 미분 전류 | 구현 86 + 별도 26 = 112 |
| [0.5-r1](studies/v0_5_r1) | 제한 결합, 공간 수렴, 여기·반지름 척도 | 구현 118 + 별도 32 = 150 |

| 원본·단계 간 비교 | 같은 계승 매개변수, 명시된 폭 재보정, 원본 장부 | 5 |
| **전체** | **수치·입력·재현 검증 통과** | **395** |

세 교정 원고는 각 `paper/`의 Word·PDF에 있습니다. [통합 검토보고서](report/paper/WRRA_M_Upstream_0_4_to_0_6_Review_r1_KO_2026_10_03.pdf)에는 변경 사항, 유지한 수치, 해석과 남은 한계가 있습니다. [수정 기록](CHANGES.md)과 [전체 검증 장부](reproduction_results.json)를 함께 보십시오. Word 수식은 편집 가능한 native OMML 개체입니다.

## 재현

ZIP을 압축 해제한 디렉터리에서 실행합니다.

```bash
python -m pip install -r requirements.txt
OPENBLAS_NUM_THREADS=2 python reproduce_all.py
```

검증 런타임: Python 3.12.14, NumPy 2.3.5, SciPy 1.17.0. 각 별도 검증은 결과 파일을 제거한 새 폴더에서 다시 계산하고 바이트 일치를 확인합니다. 전체 ZIP 역시 새 압축 해제 환경에서 같은 395개 검증과 결과 장부를 재현했습니다. 다른 런타임·BLAS의 마지막 비트 차이는 가능하므로 수치 검사와 장부를 함께 확인합니다.

0.5 원본 결과는 바이트까지 같습니다. 0.6은 새 수반 관계 검사 네 개와 검사 수를 제외하면 원본 장부와 같습니다. 0.4는 물리 장부가 같으며 반올림하지 않은 순열 잔차 한 곳에 약 5×10⁻²⁹의 차이가 있었습니다. 원본 비교는 이 진단 잔차를 분리하며 이를 숨기지 않습니다.

문서 재생성은 각 `source/build_doc.py`를 사용합니다. 추가 의존성은 각 `source/requirements.txt`이며 Pandoc, LibreOffice, NanumGothic와 Latin Modern Math가 필요합니다. PDF 페이지 검토와 Word 수식 구조 검사는 `document_checks.json`에 기록했습니다. 코드 검증과 문서 구조 검사는 다른 장부입니다.

## 남은 연구 범위

보정에 사용한 관측값의 반환은 공동 구성의 재현입니다. 0.5 중성자 점전하 반지름과 0.6 중성자 자기 반지름의 불일치, 조절 길이에 따른 미보정 전하 곡률, 조건부 여기 중심 배정, 미정 이차 자기 직접항을 유지했습니다. 내부 복사 기준은 Seng 등 2018의 고정 값입니다. 완전한 정밀 β 계산, 미시 QCD 결합·γW 상자, 횡전류와 공변 게이지 완성은 포함하지 않습니다.

원본 0.4–0.6 및 고정 계승 snapshot은 역사적 GitHub 경로에 보존됩니다. 교정 진입점이 새 입력 계약을 적용하며 snapshot의 원래 해시는 그대로 검증합니다. 기존 Core 1.0, MCC 2.3.2와 하류 연구는 별도 계보입니다.
