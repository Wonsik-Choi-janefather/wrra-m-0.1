## 실행 규칙

세 분기 순서는 φ,D,R이다. 0.7의 기준 분기 확률 p를 그대로 사용한다. 작은 상태 rho=|sqrt(p)><sqrt(p)|는 **새로 선언한 결맞음 시험 상태**이다. 0.7의 백만 주소 미시상태를 실제로 축약하여 유도한 상태가 아니다. 상류와의 연결은 기준 분기 장부와 입력 hash 수준이다.

셔터 S_eta(rho)=(1-eta)rho+eta diag(rho), 0≤eta≤1을 사용한다. 이는 항등 채널과 완전 대각 판독 채널의 볼록 결합이므로 완전 양성과 trace 보존을 만족한다. 부분 셔터 두 번의 합성 강도는 eta_eff=eta_1+eta_2-eta_1 eta_2이다. 완전 셔터는 멱등이다.

완전 판독의 분기 상태는 sigma_j=P_j rho P_j이고 확률은 trace(sigma_j)이다. 비선택 판독의 합과 실제 하나의 조건부 기록은 구별한다. select_record는 외부에서 명시적으로 준 [0,1) 표본값으로 분기 하나를 기록한다. 표본값의 물리적 기원은 이 단계에서 도출하지 않는다.

프레임은 준비→변환→셔터→기록이라는 유한 실행 순서이다. 이 계약의 최소 판독 단위는 분기 기록 하나이다. 이는 보편적인 최소 물리 시간, 플랑크 시간 또는 물리적 이산 시간의 증명이 아니다. 시간 환산 계수와 물리적 최소 시간은 null로 남긴다. 실현된 무한 상태나 무한 반복은 요구하지 않으며 무한=Null 전제를 유지한다.

0.7과 같은 기준 확률의 재현은 계승된 보정의 현실 정합성을 보존한다. 새 수치인 셔터 순도와 순서 대조는 선언한 시험 구조의 계산 산출이다. 이를 측정된 우주론 수치로 부르지 않는다. 시험 회전 각도 0.25 rad는 추가 구성 입력이다.

## 0.8-r1 마무리: 실제 주소 상태 연결

`address_bridge.py`는 0.7의 SOURCE·필터 함수를 직접 호출한다. N=1,000,000에서 각 분기 벡터 K_jψ를 계산하고, norm 제곱을 분기 확률로 사용한다. 최초 반사와 정상 복귀는 별도 분기로 보존하며 R 장부에서만 합한다. 따라서 복귀 혼합을 가짜 순수 진폭으로 합하지 않는다. 선택된 분기는 실제 주소 벡터를 자신의 norm으로 정규화하여 다음 단계에 넘긴다.

검증은 기준 입력, 소수 2 세기 변경, 소수 3 위상 변경에서 실시했다. 미시 주소 연결 28개 검사와 재현 가능한 셔터 감사 403개 검사가 통과했다. 셔터 모델의 시간 환산·물리적 확정 기원·기록 안정성은 열린 항목이다. 기록은 현재 실행에서 선택한 label과 조건부 상태이며 외부 물리 기록 매체를 계산한 결과는 아니다.

0.8의 유한 실행 계약은 준비→필터→셔터 판독→하나의 조건부 기록까지 닫는다. 0.9에는 입자·전류 사상을 남긴다. 추가 독립예측을 종료 조건으로 요구하지 않는다. 0.7 보정 출력의 재현은 계승 구조의 정합성으로 판정하며, 새 변환의 실행 증거와 구별하여 함께 보존한다.

재현: `python reproduce_all.py`. 순서 대조와 미시 주소 연결은 서로 다른 시험이며 세 분기 결맞음 시험을 백만 주소 축약으로 동일시하지 않는다.
