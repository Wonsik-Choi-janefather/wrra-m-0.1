# 상류 연구 마감 범위 - 0.10

사용자가 확정한 범위에 따라 **상류 개발은 0.10에서 마무리한다.**
이 문서는 초기의 1.0 개발 목표 표기를 정정한다. 1.0을 만들 경우에는 0.10까지의 검토·통합·동결판으로만 구분한다.

| 단계 | 실제 계산한 결과 | 상태 |
| --- | --- | --- |
| 0.7 SOURCE·필터 | 유한 주소 진폭, 두 단계 필터와 생성·귀환 재고 | 재검토 완료 |
| 0.8 셔터·기록 | 유한 순서·노름·조건부 기록, 미시 분기 연결 | 재검토 완료 |
| 0.9 상태·전류 | phi 잔여의 조건부 내부 준비, 동결된 같은 상태 전류 | 재검토 완료 |
| 0.10 통합 | SOURCE-필터-기록-상태-전류와 별도 스칼라 재고 규약 | 상류 마감 |
| 선택적 1.0 | 0.10까지의 검토·정리·동결 공개 | 새로운 개발 단계 아님 |

[0.7~0.10 재검토 통합판](../review_0_7_0_10_r1/README.md), DOI 10.5281/zenodo.23115550.
물리 시간·에너지 공급과 정보-에너지 환산·종 기원·기록 매질 안정성은 미구현 null 인터페이스로 명시한다. 계산된 통합의 완료와 이 물리 지도의 미구현을 구분하며 후속 번호를 자동 생성하지 않는다.

기준 31.8%는 한 번 방출한 창의 결과이며, 반복 방출의 고정점과 다르다. 위상 판독에는 결맞음과 비대각 작용이 필요하다. 귀환 stock의 위상 기억을 버리고 SOURCE를 재준비하는 것은 공개된 가정이다. 기존 보정·재현 성과와 남은 진단 불일치를 함께 보존한다.
