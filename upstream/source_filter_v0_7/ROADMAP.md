# 상류 연구 종료 계획

2026-10-03에 정한 계획이다. 이전에 0.9 또는 0.10으로 끝내기로 했다는 합의는
확인할 수 없으므로, 현재 계획은 아래 범위를 새로 명시한다.

| 단계 | 남길 결과 | 상태 |
| --- | --- | --- |
| 0.7 SOURCE와 생성 규칙 | 소수 방출 상태·변화량, 두 단계 필터의 진입·잔존·복귀 보존 장부 | 본 release |
| 0.8 시간과 양자화 | 순서·프레임·셔터 갱신, 최소 판독 단위와 norm 계약 | 다음 단계 |
| 0.9 입자와 전류 | 생성 잔존을 내부 상태·입자 판독에 연결하고 미해결 오차를 기록 | 예정 |
| 0.10 생성기 통합 | SOURCE에서 입자 판독까지 실행 경로, 하류 입력 계약과 단위 일치 | 예정 |
| 1.0 동결 공개 | 조건부 생성 모형 원고·코드·검증 증거·전달 명세 | 최종 목표 |

1.0 종료 조건은 계산 경로와 장부의 일관성, 입력·가정·보정·산출의 구분,
단위·norm·에너지 전달 계약, 남은 불일치의 공개이다.
완전한 미시 QCD 또는 모든 정밀 보정의 완성은 이 종료 범위에 포함하지 않는다.
아직 정의되지 않은 물리 대응을 도출된 결과처럼 적지 않는다.

0.7에서 발견한 조건은 후속 단계에도 유지한다. 기준 31.8% 잔존을 시간에 따라
유지하려면 생성 창의 닫힘 또는 명시적 균형 프로토콜이 필요하다.
위상 반응에는 SOURCE 결맞음과 위상을 읽는 비대각 작용이 필요하다.
반환 stock의 위상 기억을 버리는 재준비 규칙은 현재의 선언된 가정이다.
