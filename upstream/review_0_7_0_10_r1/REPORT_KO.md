# WRRA M 상류 0.7~0.10
## 재검토·수정 통합판 - 0.7-0.10-r1
최원식 Wonsik Choi | ORCID 0009-0001-4263-9772 | 2026-10-03
DOI: 10.5281/zenodo.23115550 (공개 시 등록)

SOURCE 준비부터 조건부 입자 전류까지의 유한 구현을 다시 검토하고 수정한 통합판이다. 상류 개발은 0.10에서 마무리한다. 이후의 1.0은 검토·통합·동결판으로만 구분하며, 새로운 상류 개발 단계가 자동으로 이어지는 것으로 취급하지 않는다. 공개된 보정과 기준 물리 수치는 유지한다.

## 결론에 앞서 확인한 입력
유한 SOURCE의 주소는 n = 2,...,N이며 N = 1,000,000이다. 고정 매개변수는 alpha = 1.8996876950554356, beta = 0.8654570124136961이다. 정규화 진폭은 n^(-alpha/2)에 공개된 소수 제어별 exp[(epsilon_p/2 + i phase_p) v_p(n)]을 곱해 구성한다. 소수 주소는 SOURCE 표지이고, 합성수 지표는 유한 후손과 필터 출력을 조직한다. 실제로 실현된 무한 주소 공간을 전제하지 않는다. Infinity = Null을 채택하며, 수학적 극한 표현을 물리적으로 실현된 무한이라는 주장으로 읽지 않는다.

0.9와 0.10의 내부 시험은 수정·동결된 0.6의 해밀토니안과 전류, 95차원 기저를 사용한다. 선택자는 홀수 v_3(n), 준비 강도는 0.2, 들뜬 모드는 1, 앙상블 운동량 격자는 Q2 = 0, 0.01, 0.1 GeV2이다. 이 값들은 구성 입력이며 양성자·중성자 표지도 외부에서 주어진다. 이번 검토로 종 선택 법칙이나 에너지 기원 법칙을 추가하지 않는다.

## 0.7 - SOURCE와 유한 필터 원장
WRRA 변환: 짝수 합성수는 D, 홀수 합성수는 beta만큼 표현형과 1-beta만큼 초기 반사, 소수는 정상 귀환으로 분리한다. 각 유한 주소는 정규화 원장에 한 번 기여한다. 네 분기 도구는 입력 노름을 보존하고, 두 귀환 분기를 고전적으로 합산하면 세 항목 원장이 된다.

| 같은 SOURCE 분모의 산출 | 기준값 |
| --- | --- |
| 표현형 | 0.050000000000000 |
| D | 0.267999999999998 |
| 귀환 | 0.682000000000002 |
| Actual = 표현형 + D | 0.317999999999998 |

한 번 전량 방출하고 이후 창을 닫으면 이 기준 분할을 얻는다. 가용 SOURCE의 0.2를 32번 방출하고 누출을 0으로 두면 마지막 Actual 재고는 0.8778861396212083이다. 0.318은 단일 창의 결과이며 재활용 고정점이 아니다. 기존값의 보정·재현도 선언된 모형의 정당한 성과로 평가한다. 독립적인 새 수치 예측은 이 조건부 구성의 성립을 판단하기 위한 선행조건이 아니다.

수정: 0.7 재현 실행기는 저장된 결과 파일이 없어도 작동한다. 두 번 새로 생성해 바이트 결정성을 확인하고, 일부 기존 기준 파일이 남아 있으면 그 일치 여부도 보호한다. 반증 조건: 분기 총합의 정규화 실패, 주소 중복 집계, 독립 스칼라 감사와 불일치, 고정 실행 환경에서 깨끗한 재생성 바이트의 불일치이다.

## 0.8 - 유한 셔터와 하나의 기록
WRRA 변환: 세 표지의 거친 셔터는 S_eta(rho) = (1-eta) rho + eta diag(rho), 0 <= eta <= 1이다. 미시 도구는 네 이름의 분기 벡터 K_j psi를 유지한다. [0,1)에서 주어진 추출값 하나가 양의 확률 분기 하나를 골라 그 표지와 정규화된 조건부 주소 벡터를 반환한다. 두 귀환 벡터는 고전 합산 전까지 구분하며, 혼합을 순수 상태로 주장하지 않는다.

| 미시 분기 확률 | 기준값 |
| --- | --- |
| phi | 0.050000000000000 |
| D | 0.267999999999998 |
| 초기 반사 | 0.00777294456318944 |
| 정상 귀환 | 0.674227055436812 |

완전한 거친 셔터의 순도는 0.539448이며 세 분기 확률은 변하지 않는다. 결맞는 회전과 셔터의 순서를 바꾸면 표현형 판독은 약 0.00784598233과 0.06334350075로 달라진다. 이는 선언한 거친 인터페이스의 유한 순서 대비이며, 미시 위상 실험을 재구성한 결과는 아니다.

수정: 에르미트성의 상대 허용오차를 0, 절대 허용오차를 1e-12로 고정했다. 불리언 셔터 강도·추출값을 거부하고, 끝점 반올림에서도 확률 0인 분기는 선택하지 않는다. 미시 기록에는 네 정식 분기 이름, 같은 크기의 비어 있지 않은 유한 벡터, 정규화된 총 분기 노름을 요구한다. 사전 삽입 순서가 도구의 분기 순서를 바꾸지 않는다.

반증 조건: 트레이스·양성 실패, 대각 확률 변경, 0.7과 미시 노름의 불일치, 확률 0인 분기 선택, 비유한·비정상 벡터에서 기록 생성이다. 주어진 추출값 하나는 조건부 기록 하나이다. 네 시험 추출값은 우주적 비율이나 재고를 소모하는 표본 궤적이 아니다. 시계, 최소 물리 시간, 안정적인 기록 매질은 아직 지정하지 않았다.

## 0.9 - 조건부 잔여와 동결 전류
WRRA 변환: 주소 표지를 비결맞게 읽고 홀수 v_3(n)의 조건부 phi 가중치를 t로 둔다. 준비 강도 s이면 w = s t, rho_phi = (1-w)|g><g| + w|e1><e1|이다. 정규화 조건부 밀도의 트레이스는 1이고, 비정규화 형태의 트레이스는 f_phi이다. D와 귀환은 이 핵자 시험 준비 밖에 남는다.

같은 동결 H로 E_excess = Tr(rho_phi H) - E_ground = w 곱하기 에너지 간격을 계산한다. 같은 상태의 전류는 고정 전하 폭과 보정항을 유지한 바닥·들뜬 모드 판독의 선형 혼합이다. 들뜬 출력에 새로 맞추지 않고 선언한 유한 준비 지도를 실행한다.

수정: 조건부 벡터를 엄격히 증가하는 정수 주소와 맞추고 유한성·소수 선택자를 확인한다. 내부 모드는 유한·정규화·동일 크기·직교를 요구한다. 비어 있거나 중복된 격자와 모호한 SOURCE 사례 이름을 거부한다. 표시 기준은 이름 baseline과 기준 강도로 찾는다. 상속 전류 어댑터의 범위를 실수 동결 모드로 명시하고 복소 상태는 거부한다. 일반 복소 전류 구현을 주장하지 않는다.

## 실제 수치 산출과 범위
| 0.9·0.10 기준 산출 | 값 |
| --- | --- |
| 조건부 선택자 t | 0.3998832725128899 |
| 들뜬 점유 w | 0.07997665450257799 |
| 동결 들뜸 간격 | 431.081244315 MeV |
| 조건부 초과 에너지 | 34.47643573911998 MeV |
| Q2 = 0.1 GeV2의 양성자 GE | 0.7301767666507732 |
| Q2 = 0.1 GeV2의 약전류 GAV | 0.8971258414783907 |

SOURCE 강도 제어는 조건부 준비를 바꾼다. epsilon_3 = -0.15에서 w = 0.08051014298579888, 초과 에너지 34.70641261829451 MeV이고, +0.15에서 w = 0.07892297725436004, 34.022215239851846 MeV이다. 위상만 바꾸면 선언한 비결맞음 준비는 변하지 않는다. 강도 0은 동결된 0.6 바닥 상태 보정을 재현한다.

반증 조건: Kraus 완전성·양성 실패, 조건부 트레이스가 1이 아님, 독립 인수분해와 t의 불일치, 위상만 바꾸어 비결맞음 산출이 달라짐, 같은 H의 에너지와 불일치, 전하 연산자 트레이스와 전류 판독의 불일치이다. 이는 수학·구현 검사이며 독립 실험 확인 수가 아니다.

## 0.10 - 통합 마무리
WRRA 변환: SOURCE -> 순서 있는 필터 -> 기록 하나 -> phi 조건부 준비 -> 동결된 같은 상태 전류를 실행하고, 스칼라 재고 규약을 별도 형으로 병행한다. 여섯 SOURCE 사례를 계산한다. 선택된 phi 기록은 그 실제 조건부 주소 벡터에서 내부 상태를 준비한다. 다른 분기의 기록은 핵자 내부 판독을 갖지 않는다. 앙상블 확률·기록·정보 재고·MeV 출력의 의미를 구분한다.

수정: 기준 전달은 목록 첫 항목 대신 이름이 baseline인 무제어 사례에서 선택한다. 0.9 회귀 검사는 Q2 값으로 곡선을 맞추고, 같은 이름의 사례는 같은 SOURCE 제어를 유지해야 한다. 기록 운동량은 명시 입력 record_readout_Q2_GeV2 = 0.1이며 각 판독은 Q2_GeV2와 currents를 담는다. 이전 키 current_at_Q2_0_1은 교체했다. 규약 이름의 유일성, 방출·누출의 유한한 범위, 기준 창의 단일 전량 방출과 이후 폐쇄·무누출을 확인한다. 사용하지 않는 vectors_hash 변수는 제거했다.

반증 조건: 사례·운동량 목록의 순서 변경으로 대응 산출이나 기준 전달이 달라짐, 같은 이름의 제어가 조용히 바뀜, 미구현 지도가 null이 아니게 됨, 재고 보존·양성 실패이다. 별도 사본에서 목록을 뒤집고 기록 운동량을 0.01 GeV2로 바꾸어 검사했다.

마무리 판정: 선언한 조건부 범위의 상류 통합을 0.10에서 완료한다. 물리 시간, SOURCE 에너지 공급, 정보-에너지 변환, 종 기원, 기록 매질 안정성은 명시적인 null 인터페이스로 남긴다. 상속 중성자 자기 반지름은 약 0.83198710743 fm, 유지한 비교값은 0.864 fm, 차이는 약 0.03201289257 fm이다. 기존 유한 Q2 진단 불일치도 상속 원장에 유지한다. 이번 검토에서 이를 삭제하거나 해결했다고 주장하지 않는다.

## 재현·보존·평가
저장소 루트에서 다음을 실행한다.
python upstream/review_0_7_0_10_r1/reproduce_all.py

실행기는 OPENBLAS_NUM_THREADS와 OMP_NUM_THREADS를 2로 고정한다. 네 단계를 순서대로 다시 계산하고 단계별 독립 감사와 verify_review.py를 실행한다. 의존성은 Python 3, NumPy, SciPy이며 배포 환경에 설치 버전을 기록한다. PDF는 설명 보고서이고, JSON과 코드가 실행 가능한 근거 자료이다.

| 검증 묶음 | 통과 수 |
| --- | --- |
| 0.7 계산 + 독립 감사 | 113 |
| 0.8 미시 + 무작위 셔터 감사 | 431 |
| 0.9 구현 + 독립 감사 | 318 |
| 0.10 통합 + 독립 스칼라 감사 | 465 |
| 이번 단계 간 재검토 검사 | 68 |
| 집계 검사 합계 | 1395 |

합계는 상속 검사·수학 채널 검사·회귀 검사·비정상 입력 검사를 포함하며, 독립 물리 발견의 수가 아니다. 0.8 계산 코드의 추가 assert는 431개 집계에 포함하지 않는다. 0.9의 모든 수치 행은 정확히 그대로이며, 0.10의 여섯 물리 행도 공개한 기록 스키마 정규화 후 동일하다. 0.7 결과와 거친 0.8 결과는 바이트까지 같다. 부모 해시와 0.10 명시 입력·스키마는 구현 수정 때문에 바뀐다.

baseline/에 재검토 전 Python·JSON·Markdown을 보존하고 baseline_sha256.json으로 확인한다. 현재 단계 폴더에는 수정된 실행 구현을 둔다. 원래 단계 PDF는 과거 보고서로 보존하며, 바뀐 구현 설명은 이 한·영 검토 보고서를 우선한다. 배포 ZIP에는 필요한 동결 0.6 의존성, 네 단계의 코드·입력·결과·감사, 과거 보고서, 재검토 검사와 본 보고서가 있다. SHA-256 목록으로 패키지 내용을 확인할 수 있다.

평가 순서는 확인된 입력 -> WRRA 고유 변환 -> 계산 산출 -> 반증 조건 -> 결론이다. 기존값의 보정·재현은 달성한 결과로 인정한다. 통합 성과는 실제 계산된 범위에서만 인정한다. 유한 계산에서 정보 비율의 물리 에너지 전환, 물리 시계, 종 기원 법칙을 추가로 추론하지 않는다.
