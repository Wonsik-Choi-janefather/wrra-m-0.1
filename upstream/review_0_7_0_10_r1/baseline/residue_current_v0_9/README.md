## 이번에 닫은 연결

0.8의 실제 주소 분기 벡터 K_φψ를 직접 받아 정규화한 조건부 φ 상태를 사용한다. 이 연결은 앞선 세 분기 결맞음 시험 상태와 별개다. 0.6의 95차원 내부 공간에서 기준 바닥상태 g와 첫 들뜬 고유상태 e1을 같은 해밀토니안으로 재계산한다. 기존 입력과 보정계수·공간폭·전하 반경 보정항을 바꾸지 않는다.

S는 주소 n에서 소수 3의 소인수 지수 v_3(n)가 홀수이면 1인 대각 선택 효과이다. t=Tr(Sρ_φ), a=λt로 두고 내부 상태를 σ=(1-a)|g><g|+a|e1><e1|로 준비한다. λ=0·0.2·1을 비교하며 0.2는 공개한 구성 기준이다. 소수 3 선택과 첫 들뜬 모드 선택도 채택한 사상 규칙이며 SOURCE만으로 유일하게 유도된 물리 법칙으로 주장하지 않는다.

이 사상은 주소별 측정·준비 채널이다. 각 주소의 Kraus 작용은 sqrt(1-λs_n)|g><n| 및 sqrt(λs_n)|e1><n|이다. 두 작용의 K†K 합이 그 주소의 항등 효과이므로 전체 채널이 trace를 보존한다. 실제 단일 주소/상태 사건을 모두 실재하는 동시 기록으로 취급하지 않고, σ를 비선택 상태 장부로 보존한다. 계산의 선택 확률과 물리적 결과 발생의 기원은 구별한다.

준비 후 내부 밀도 상태의 trace는 1이고, 비정규화 장부 f_φσ의 trace는 f_φ이다. D와 R은 핵자 상태로 변환하지 않는다. 양성자·중성자는 기존 전류를 평가하는 별도 지정 채널이다. 이 사상은 우주의 양성자/중성자 생성 비율이나 D의 입자 정체를 산출하지 않는다.

## 전류의 동일 상태 조건

준비 강도 λ=0에서 0.6의 바닥상태 전류와 자기모멘트·축전류 입력을 재현한다. λ>0에서 들뜬 상태의 판독이 달라지는 것이 이 단계의 새 실행 결과다. 들뜬 상태의 반경을 맞추려고 전하 공간폭이나 counterterm을 다시 보정하지 않는다. 전자기와 약전류는 동일 σ와 기존 0.6의 공간·spin-flavor 연산자를 사용한다.

전하 전류는 Tr(σρ_charge(Q²))와 바닥/들뜬 상태 기댓값의 가중합을 독립 대조한다. 유한 Q²에서 G_E^V=G_E^p-G_E^n이 유지되며 Q²=0에서 양성자 전하 1·중성자 전하 0도 유지된다. 채택 채널은 주소 위상을 읽지 않으므로 위상 변화만으로 내부 상태가 변하지 않는다. 위상 반응을 얻으려면 별도 결맞음 전달 사상이 필요하다.

## 남은 오차와 물리 대응

교정된 0.6의 미보정 중성자 자기반경 0.83198710743 fm과 인용 기준 0.864 fm의 차이 0.03201289257 fm을 그대로 보존한다. λ=0.2의 전류 결과는 산란 측정과 새로 비교한 결과가 아니다. 실제 주소→입자 준비 규칙, 준비 강도의 물리적 기원, 종 선택, 에너지 공급, 물리 시간과 기록 매체 안정성도 남아 있다. 독립예측이나 숫자의 새로움을 이 단계의 필수조건으로 추가하지 않는다. 보정 재현과 내부 사상의 계산 실행을 각자의 성과로 판정한다.
