## 상류 0.10 마감 결정

상류 개발은 0.10에서 마무리한다. 미계산 항목은 이 판의 마감 장부에 남기며 새 개발 단계로 넘기지 않는다. 1.0을 만든다면 0.10까지의 검토·정리·동결판으로만 둔다.

## 상류 생성기를 하나의 실행 경로로 묶기

본 단계는 `reproduce_all.py` 한 번 실행으로 기준과 5개 SOURCE 대조 사례를 계산한다. 각 사례에서 백만 주소 상태를 실제로 준비하고 0.8의 네 분기 벡터를 산출한다. 분기 norm에서 φ,D,최초 반사,정상 복귀 확률을 구하며, R은 두 복귀 확률을 합한 고전 장부다.

그 상태를 0.8의 기록 함수와 0.9의 내부 상태 준비 함수에 직접 전달한다. 부모 결과 파일의 숫자를 새 실행 결과로 복사하지 않는다. 보관된 부모 결과는 새 계산의 회귀 대조에 사용한다. 입력과 각 부모 코드·결과의 SHA-256을 결과 장부에 기록한다.

고정 기준은 N=1,000,000, α=1.8996876950554356, β=0.8654570124136961이다. 내부 준비 강도 λ=0.2, 선택 소수 3, 첫 들뜬 모드 1과 유한 Q² 격자는 0.9에서 계승한 구성 입력이다. 소수 2·3의 로그 세기를 ±0.15로 바꾸고, 별도 사례에서 소수 3의 위상만 0.7 rad 바꾼다.

모든 행은 같은 N·α·β와 선언된 SOURCE 제어에서 나온다. 서로 다른 가중지수의 4.8769%와 26.7942%를 합하지 않는다. 기준 Actual은 φ+D=31.8%이며 전체 정보 stock의 부분 범위다. 검증된 값으로 확정한 보정의 재현은 현실 정합성과 설명 성과로 유지한다. 독립예측이나 수치의 새로움을 별도의 종료 조건으로 추가하지 않는다.

소수 2 세기는 φ와 D의 총량을 바꾸지만 조건부 φ 내의 준비 분포는 이 시험에서 유지되어, 조건부 여기 에너지가 같다. 소수 3 세기는 준비 상태의 들뜬 모드 비중과 전류에 전달된다. 위상만 바꾸는 사례가 유지되는 것은 채택한 주소 대각 측정·준비 사상의 결과이다. 이를 일반적인 위상 무효 법칙으로 확대하지 않는다.

## 하나의 기록과 확률 장부의 구분

각 SOURCE 사례에 0.02·0.1·0.32·0.9의 외부 표본값을 입력해 네 번의 판독 대조를 실행한다. 각 판독은 분기 하나와 norm 1인 조건부 주소 상태를 만든다. 기준 사례에서는 φ,D,최초 반사,정상 복귀의 네 기록을 각각 확인한다.

φ가 선택된 기록만 내부 상태와 전류 판독을 가진다. 이때 실제 선택된 주소 벡터에서 준비 상태를 다시 구해 비선택 φ 조건부 상태와 대조한다. D와 R을 핵자 상태로 바꾸거나 그 영역의 입자 정체를 임의로 정하지 않는다.

네 표본값은 각 분기를 점검하기 위한 공개된 시험 입력이다. 각 분기가 한 번씩 선택된 횟수는 우주 구성비가 아니다. 5%·26.8%·68.2%는 norm 확률 장부이며, 기록 횟수와 구별한다. 이 판독 대조는 같은 준비의 별도 시험이고, 기록마다 실제 우주 stock에서 입자를 꺼내는 물리적 누적 궤적을 구현한 것은 아니다.

## 생성 창과 유한 stock 보존

0.7의 stock 갱신 함수를 같은 분기 확률과 직접 연결한다. 기준 생성 창은 첫 사건에서 전량 방출한 뒤 7번의 사건에서 추가 방출을 0으로 둔다. 누출도 0이다. 최종 SOURCE·표현·비표현 stock은 68.2%·5%·26.8%이다.

대조에서는 방출률 0.2를 32번 적용한다. 기준 Actual은 87.7886139621%이다. 각 사건의 SOURCE+φ+D 합은 1이고 비음수이다. 독립 감사는 별도 scalar 반복식과 32회 유한 닫힌 식 a_k=1-(1-u r)^k를 대조한다. 무한 반복은 실행하지 않으며 물리 실재로 요구하지 않는다.

따라서 31.8% 유지의 조건은 명시한 생성 창 닫힘이다. 반복 재방출의 일반 고정점으로 표시하지 않는다. stock은 기대 분기량을 갱신하는 장부이며, 단일 입자 사건의 표본 경로와 동일시하지 않는다.

## 에너지·전류와 하류 전달의 형 구분

내부 상태는 동일한 교정 0.6의 해밀토니안 H를 사용한다. 기준 조건부 여기 에너지 34.4764357391 MeV와 Q²=0.1 GeV²에서 G_E^p=0.730176766651, G_A=0.897125841478을 재현한다. Tr(σH)-E_ground와 들뜬 모드 비중×gap을 대조하고, 전하 전류 trace와 상태별 가중합을 비교한다. 같은 σ에서 전자기·약전류의 CVC를 유지한다.

정보 비율을 물리 에너지 비율로 바로 바꾸지 않는다. 조건부 여기 에너지는 핵자 생성 질량이나 우주 전체 에너지 밀도가 아니다. 실제 여기 에너지의 공급, 생성 질량, 종 선택, 초 단위의 갱신 시간, 물리 기록 매체와 안정성은 null이다. 미구현 물리 시간·에너지 사상을 1 같은 숫자로 채우면 입력 검증에서 거부한다.

하류에 전달하는 것은 정보 분기량, 유한 조건부 상태와 전류 판독이다. 중력·팽창 시뮬레이터로 넣으려면 하류가 소유하는 명시적인 상태·에너지 사상을 적용해야 한다. 이번 통합은 그 에너지·중력·팽창 연결을 새로 구현했다는 선언이 아니다.

## 미해결 항목과 상류 종료 범위

교정 0.6의 중성자 자기반경 0.83198710743 fm과 인용 기준 0.864 fm의 차이, 유한 Q²의 측정 대조, regulator 선택과 기존 정밀도 제외 범위를 유지한다. 새로운 준비 사상의 물리 기원과 λ·종 선택의 기원도 열린 항목이다.

상류 개발 경로는 0.7 SOURCE 장부 → 0.8 셔터·기록 → 0.9 내부 상태·전류 → 0.10 생성기 통합을 거쳤다. 0.10은 공개한 구성·보정 아래의 조건부 유한 실행 경로를 마무리한다. 1.0은 이 결과·코드·한영 설명·전달 계약을 검토·동결하는 판이며 자동으로 새 개발 단계나 물리적 완전성을 덧붙이지 않는다. WRRA Core 1.0은 변경하지 않는다.

## 재현과 검증

`python reproduce_all.py`를 실행한다. 구현 검사 156개, 독립 검사 309개를 저장한다. 독립 감사는 사건별 scalar stock, 유한 반복식, 분기 선택, φ에만 속하는 내부 판독, SOURCE phase 대조와 비정상 입력 거부를 확인한다. 결과 파일을 지운 새 복사본의 바이트 동일 재현도 검증한다.
