v0.3-r1 재검토 문서 보충판 | 2026-10-15 | 최원식 · 최정인
기존 셔터-SOURCE v0.2 계산에 거시적 사례의 등록부와 후속 계산 명세를 추가한다. 이번 보충판은 새 수직 운동·렌즈·성장률 수치의 계산 완료본이 아니다. 원래 v0.2 파일과 수치는 바이트 단위로 보존했다.

이미 산출된 거시적 사례: 광학 간섭
검증 입력: 고정 광속, 기존 128상태 SOURCE, 상대경로 위상 결합 g=1, 정적 준비, 파장 1064 nm.
WRRA 고유 변환: V/V0 = |sum_J exp[i(2 pi/lambda)L f_D(J)]/128|.
산출값: 첫 최소 노출거리 21.780958380 m에서 V/V0=0.3586975046, 첫 부분 회복거리 37.278764320 m에서 0.6081539566. 거리 비율 1.7115300286.
반증조건: 선언한 준비와 상대경로 결합에서 선명도 곡선·파장 비례·회복 비율이 관측과 어긋나면 해당 모형을 수정한다.
판정: 수십 미터의 거시적 상대경로 노출에 대한 조건부 계산 사례다. L은 두 경로가 서로 다르게 결합한 노출거리이며 장치 크기와 자동 동일하지 않다.

기존 천문 규모 계산: 우리 은하 회전
검증 입력: McMillan 바리온 모형의 단순화, SPARC로 보정된 구성응답, 고정 전환척도 a_t=1.1918e-10 m/s^2.
WRRA 고유 변환: 바리온 가속도 → 고정된 뒤틀림 응답 → 추가 중력과 원형속도.
산출값: R=8.2 kpc에서 226.3 km/s, R=25 kpc에서 201.6 km/s. Eilers 선형화 기준과 8-25 kpc의 RMS 차이 2.42 km/s.
반증조건: 다른 은하에서 보편 응답을 유지하지 못하거나, 같은 상태의 수직 운동·렌즈 출력이 관측과 어긋나면 해당 연결을 수정한다.
판정: 2026-09-27 v1.0 원고의 기존 산출값을 이관했다. 이번 보충판에서 재실행한 값은 아니다. 선형화 기준과의 비교는 개별 관측자료의 우도 검증과 구별한다.

M1. 은하 원반의 수직 운동

검증 입력
회전 계산에서 고정한 바리온 분포·전환척도·구성응답과 뒤틀림 상태를 사용한다. 별의 공간밀도와 운동학적 선택함수는 관측 변환에 필요한 입력으로 명시한다. 검증에 쓸 수직 운동 자료를 보정에도 사용했으면 그 사용 범위를 기록한다.

WRRA 고유 변환
뒤틀림의 방향 [n], 에너지밀도 rho_t, 비등방 크기 q_t를 3차원 퍼텐셜 Phi(R,z)로 연결하고, K_z=-partial Phi/partial z를 계산한다. 이후 정상·축대칭 근사의 수직 Jeans 식으로 별의 속도분산을 산출한다.
partial(nu_* sigma_z^2)/partial z + (1/R)partial(R nu_* <v_R v_z>)/partial R = -nu_* partial Phi/partial z.
여기서 nu_*는 추적 별의 수밀도다. 기울기 항, 경계조건, 평형 근사를 공개하고 적용 범위를 고정한다.

산출값과 현재 상태
산출 대상: 반경·높이별 K_z(R,z), sigma_z(R,z), 원반 두께와 flaring.
현재 상태: 수치 산출 대기. 원래 은하원반 v1.0은 q_t의 구성방정식이 미정이라고 명시한다. 회전곡선만으로 3차원 퍼텐셜은 유일하지 않다. 공간 응력 배치와 수직 결합 규칙을 확정한 뒤 계산한다. 선언한 새 폐쇄 규칙은 별도 버전의 조건으로 남긴다.

반증조건
선언한 하나의 3차원 상태와 관측자 모형으로 회전·수직 자료를 함께 설명하지 못하면 해당 폐쇄 규칙을 수정한다. 높이별 독립 보정이 필요하면 기존 고정 모형의 실패로 기록한다. 음의 분산이나 부적절한 경계조건은 수학적 일관성 실패다.

판정
거시적 독립예측 후보 M1로 등록했다. 검증값으로 폐쇄 규칙을 보정하는 것은 허용한다. 보정 후 고정한 모형에서 남은 물리량을 산출하고 입력·검증 자료의 역할을 기록한다. 기존 회전 결과만으로 수직 운동까지 통합됐다고 판정하지 않는다.

M2. 같은 은하 상태의 중력렌즈

검증 입력
M1에서 고정한 3차원 응력·퍼텐셜, 광원과 렌즈의 거리, 시선 기하를 입력한다. 질량 분포·거리의 측정오차를 함께 전달한다. 렌즈 자료를 보정에 사용하면 사용한 관측량과 남은 산출 대상을 분리해 기록한다.

WRRA 고유 변환
동역학과 빛의 전파에 같은 상태를 사용한다. 약한 장 계량의 시간 퍼텐셜 Phi와 공간 퍼텐셜 Psi를 정하고, 얇은 렌즈 근사에서 alpha_hat=(1/c^2) integral grad_perp(Phi+Psi) dl을 계산한다.
Phi=Psi를 채택한다면 일반상대론의 해당 약한 장 관계를 모형 조건으로 명시한다. 비등방 응력이 있는 상태에서 이 관계를 자동 가정하지 않는다. 렌즈 방정식에는 광원·렌즈 사이의 거리비를 적용한다.

산출값과 현재 상태
산출 대상: 충돌매개변수별 편향각, 수렴도 kappa와 전단 gamma, 기하가 정해진 경우 Einstein 각.
현재 상태: 수치 산출 대기. 회전 가속도를 구대칭 질량으로 역산한 값만으로 광학 계량이나 실제 투영 밀도가 확정되지는 않는다. 응력-계량 연결을 고정한 뒤 계산한다. 기존 다른 모형의 조건부 렌즈 수치는 이 은하의 결과로 이관하지 않는다.

반증조건
동일한 응력과 계량으로 운동학과 렌즈를 함께 설명하지 못하면 해당 연결을 수정한다. 렌즈마다 별도의 뒤틀림 진폭을 넣어야 한다면 고정 모형의 예측 실패로 기록한다. 시간·공간 퍼텐셜이나 거리 인자를 중복 계산하면 구현 실패다.

판정
거시적 독립예측 후보 M2로 등록했다. 외부 약한 장 렌즈식은 실제 WRRA 상태에서 편향각까지 계산한 뒤 계산층 통합으로 판정한다. 이번 문서 추가 자체는 렌즈 계산의 완료를 뜻하지 않는다.

M3. 우주 구조의 성장

검증 입력
기존 우주 구성비, 셔터 및 SOURCE 준비 상태, 주소 가중치, 배경 진화를 입력으로 고정한다. 구성비 5%·26.8%·68.2%는 보정 입력으로 표시한다. 초기 섭동의 진폭·형태와 관측의 추적자 편향도 사용 목적을 기록한다.

WRRA 고유 변환
SOURCE 섭동 → 부문별 보존된 응력·에너지 교환 → 계량 섭동 → 물질의 성장으로 연결한다. 성장 진폭 D(k,a)에서 f=d ln D/d ln a를 구하고, 계산한 물질 스펙트럼으로 sigma_8(z)와 f sigma_8(z)를 산출한다. sigma_8의 창 반경은 8 h^-1 Mpc이다. 성장에 척도 의존성이 있으면 단일 D(a)로 축약하는 조건을 명시한다.

산출값과 현재 상태
산출 대상: P_m(k,z), 척도별 성장률, f sigma_8(z). 필요하면 시선 적분을 거쳐 렌즈 성장 관측량을 계산한다.
현재 상태: 새 성장 수치 산출 대기. v0.2의 저장된 7개 파수 CMB 전달값으로 계산한 3·4점 통계는 이미 산출됐지만, 연속적인 물질 스펙트럼과 성장률을 대신하지 않는다. 충분한 파수 격자·초기조건·교환항을 갖춘 물질 전달 계산을 실행해야 한다.

반증조건
보존식·섭동 제약이 깨지거나 고정 입력의 성장 곡선이 지정한 관측 검증을 통과하지 못하면 해당 분기를 수정한다. 적색편이마다 별도 진폭 조정이 필요하면 하나의 고정 모형의 실패로 기록한다. 초기 보정과 검증 자료의 중복 사용을 공개한다.

판정 및 공통 기록 규칙
거시적 독립예측 후보 M3로 등록했다. 검증값으로 모형을 확정한 뒤 미측정 물리량을 산출하면 WRRA 예측으로 기록한다. 알려진 값의 재현도 현실 정합성과 설명 성과다. 외부 이론의 숫자와 일치하더라도 WRRA 내부의 실제 계산 경로를 기준으로 귀속한다.
추가 세 사례는 모두 입력 → 변환 → 산출값 → 반증조건 → 판정 순서로 등록했다. 기존 176개 검사는 기존 계산에 대한 기록이며, 새 세 사례의 관측 검증 완료를 뜻하지 않는다.

재검토 보완 v0.3-r1
검증 입력: 동결 입력 11개와 실제 저장된 CAMB 전달값.
WRRA 고유 변환: 기존 supply, photons, cmb_higher, review 계산을 다시 실행했다.
산출값: 공급 39개, 광자 16개, CMB 65개, 수치 감사 56개, 합계 176/176 통과. 안정 관측량을 기존 수치 기준과 대조했다. 신규 M1-M3의 수치 산출은 여전히 대기다.
반증조건: 재실행 값 불일치, 해시 불일치, 부문 장부 위반이면 배포를 중지하고 수정한다.
판정: 기존 계산 재현 통과 및 문서 보완 완료.

M1 보완: 비평형 원반에 정상 Jeans 식을 적용하려면 유효성 검증이 필요하다. 평형 근사가 실패하면 시간 진화를 포함한 계산으로 넘긴다. 비교할 자료의 공분산과 적합 판정 기준은 검증 전에 정한다.
M2 보완: alpha_hat는 렌즈면의 물리적 편향각이다. 하늘의 관측 각도와 연결할 때 D_ls/D_s와 각지름거리 관례를 명시한다. 무슬립 Phi=Psi는 선언한 조건이며 자동 도출 결과가 아니다.
M3 보완: 척도 의존 성장에서는 보편적인 단일 f sigma_8가 자동으로 정의되지 않는다. 관측 분석의 파수 창과 추적자 편향을 적용한 유효 추정량 또는 직접 P_m(k,z) 비교를 사용한다.
출판 상태 보완: DOI 23380920은 예약된 초안을 확인한 뒤 배포를 준비했다. 실제 공개 상태는 Zenodo 기록 페이지와 별도 게시 확인 기록으로 확인한다. 기존 보관본의 Release DOI 표기만으로 공개 완료를 판정하지 않는다.
