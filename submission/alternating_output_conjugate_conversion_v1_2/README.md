# WRRA additions-only paper v1.2

Authors: Wonsik Choi and Jeongin Choi. 19 October 2026.

This revision replaces the v1.0/v1.1 contracts with equal-only conjugate splitting (2n -> n+n), the existing conditional shutter clock, and one-tick sequential output of the two particle phenotypes. Opposite twist or upper/lower remainder placement refers to the particle itself. Molecular chirality is excluded.

- [한국어 원고](WRRA_Alternating_Output_Conjugate_Conversion_KO_v1.2.md)
- [English manuscript](WRRA_Alternating_Output_Conjugate_Conversion_EN_v1.2.md)
- Exact consistency check: `python3 verify_clock_equal_split.py`

The downloadable package also includes both rendered PDFs and diagrams. The clock is an adopted existing model value, not a new measurement. The parent/environment must carry the unrendered partner's conserved quantities during the intervening tick. Validation covers 25 equal split examples, 100 placements and the pending partner ledger; it is not experimental validation.
