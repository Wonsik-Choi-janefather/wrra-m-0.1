# 보통 물질 5퍼센트 구성비의 재현

## WRRA 두 단계 차원필터 모형

공동저자: **최원식 Wonsik Choi · 최정인 Jeongin Choi**  
한글 원고 r9 · 2026년 10월 2일 · 22쪽

[PDF 원고](WRRA_M_물질5퍼센트_용어병기_한글_r9.pdf) · [Word 원고](WRRA_M_물질5퍼센트_용어병기_한글_r9.docx) · [공동 재현 자료](../reproducibility/WRRA_M_용어병기_r9_원고및계산자료.zip)

보통 물질 약 5%를 최소계산원리, 공통전달자와 같은 잔존 상태의 표현형 판독으로 설명하는 유한 실행 모형이다.
초록 다음에 WRRA 기초 설명을 두었으며, 표준 개념과 WRRA 용어의 대응은 본문 첫 정의와 부록 표 10에 제시한다.

| 평가 단계 | 원고의 계산 범위 |
|---|---|
| 검증 입력 | 활성 주소 2부터 1,000,000까지의 인수분해, 주소 가중치, 고정 지수 시험 및 공개된 5%·26.8% 보정 목표 |
| WRRA 고유 변환 | 초기 진입과 정상 복귀, 접힘을 보존하는 잔존 선별, 손실 없는 이진 주소 사상과 미짝 포트 판독, 공통 분모의 세 부문 정규화 |
| 산출값 | 고정 α = 2에서 4.876893353%; 공동 α·β에서 표현형 5%, 비표현형 26.8%, 복귀 68.2%; 같은 총량 뒤의 주소별 구동 대조 |
| 반증조건 | 주소 분류·양의 효과·완전성·기존 결과 재현·접힘 보존 또는 선언한 렌더러 결합의 실패 |

상류 구성비와 하류 물리 에너지 구성비의 접속은 같은 상태와 에너지 판독을 통해 명세한다.
부록은 초기 위상·누적 진입, 구동 대조, WRRA 구조와 구성비 유도를 지원한다.
진공·뒤틀림·생명과 미시 구현의 후속 접속은 [별도 확장 원고](../extensions_r8/README.md)에 정리했다.

이 등록은 검토된 원고의 공개이며, 기존 계산 코드와 결과를 변경하지 않는다.
원고 r9의 수식 25개와 수치 표를 보존했으며, 구동 대조 36개와 렌더러 결합 20개의 검사 기록을 재현 자료에 포함한다.
