# WRRA 6번 보강: 양자화 잔여·뒤틀림과 CMB v0.2

최원식 · 최정인, 2026-10-20.

한글 보고서 `REPORT_KO.md`와 `WRRA_Quantization_Twist_CMB_v0_2_KO.pdf`를 먼저 읽는다.

검증 입력 → WRRA 고유 변환 → 산출값 → 반증조건의 순서로 기록했다. 알려진 상수와 전달값은 공개한 구성 입력이다. 새 규칙에서 실제 산출한 수치를 기존 입력 수치와 구별한다. 역설계 구현·현실 정합성과 새로운 독립예측은 각 범위에서 평가한다.

## 실행

Python 3.12에서 `python reproduce.py`와 `python review.py`를 실행한다. 본 검사 46개와 별도 대조 검사 530개와 JSON·NPZ·스펙트럼 CSV가 생성된다. `python figures.py`는 그림을 재생성한다. 의존성은 requirements.txt에 기록했다. 기존 패치 CAMB 저장 전달값을 쓰므로 CAMB를 새로 설치·빌드할 필요가 없다. 새 Boltzmann 진화는 수행하지 않는다.

## 구현 범위

- 기존 주소에서 계산된 7개 조화 프로파일을 입력으로 사용한다.
- 128개 주기적 셀의 보존형 뒤틀림 응답을 새 규칙으로 채택한다.
- 복사 저장소에서 물질 저장소로의 전환 요구를 정확한 유리수 양자화 누적기로 처리한다.
- 128×128단계에서 에너지·양성·잔여 보존을 검사했다.
- 보상된 복사/물질 엔트로피를 기존 정규 D 등곡률 전달 기저에 실제 입력했다. 기존 R은 복사가 아니라 복귀·진공이므로 새 투영에서는 delta_R=0이다.
- 8~64 조화가 가진 초기 엔트로피 분산 10.8971852%는 장부에 보존했지만 CMB 전달하지 않았다. 그 CMB 기여의 비율은 아직 모른다.

기준 전환율 0.5, q=1e-8, 뒤틀림 결합 1은 새 조건부 설계 입력이다. q는 hbar·플랑크시간에서 유도되지 않았다. 전환 요구 단계는 우주 시간이나 무료 셔터 반복의 증명이 아니다. 정확 분수 잔여의 저장은 유한 기록을 요구하며 실제 물리적 기록 비용은 미산출이다.

6번 전체는 부분 구현·OPEN이다. 실제 보통물질 반응률, 전환 중 계량/속도/압력의 접합, 전체 파수와 관측 우도, 공급 비트의 개별 양자 실행과 자원 동역학은 미완성이다. 새 요동은 전체 관측 CMB의 대체물이 아니다. 3.0 v0.25-r5의 기존 공개본과 수치를 소급 교체하지 않는다.

## 출처와 보존

입력 원본은 Library `libfile_17590653d0908191b9a6d532be4a9842`, 판본 3의 `WRRA_Shutter_SOURCE_and_Macroscopic_Cases_v0_3_r1_2026-10-15.zip` 안 `shutter_three_tests_v02/inputs`이다. 사용한 8개 입력은 원본과 바이트 단위 SHA-256을 대조했다. 입력·결과의 해시는 SHA256SUMS.json에 담았다. 실제 CMB 전달은 당시 패치 CAMB 정밀도 2.5의 T/E/phi 배열이다. 원본의 별도 공급·광자·고차 CMB 검사 176개를 이번 실행에서 다시 돌렸다고 표시하지 않는다.
