# 유한 프레임 교환과 조건부 스칼라 브리지 v0.29.1

최원식 · 2026-10-13 · 토이모델 / 유효 현상학

DOI: https://doi.org/10.5281/zenodo.23329214

에너지 보존 유한 교환과 진공 구배의 운동량 전달을 포함한 단일 스칼라 모드를 공개한다. 주소는 유한 상태 표지, 128개 슬롯은 정보 처리 단위다. 물리적 공간 셀과 동일시하지 않는다.

가중·미가중 분기의 Einstein 00 잔차는 공통 진공 원천 단위로 9.9924e-9 / 1.03691e-8이다. 필요한 운동량 전달을 누락하면 같은 분모에서 0.999992가 된다. 단일 모드 26개 검사와 별도 감사 28개를 통과했으며, 관측 sigma나 공식 우도 점수가 아니다.

## 실행

```bash
python -m pip install -r requirements.txt
python single_mode.py
python review.py
```

이전 균질 CAMB 계산은 `python frame_baseline/run.py`로 재현한다. CAMB 2.0.4 설치에는 환경에 따라 gfortran이 필요하다.

## 해석 범위

공간 점유장, 표준 GR, 운동량 교환 수령자는 명시적 완성 가정이다. 기존 CMB H0=67.4499 / 66.9054와 첫 TT 피크 220 / 221은 표준 섭동 완성의 기준값 재현 결과다. 이번 상호작용 모드는 전체 CAMB 재결합 계산에 아직 결합되지 않았다. 공식 Planck 우도, BAO 공분산 검정, 미시 3D 주소 배치 및 원시 스펙트럼은 남은 과제다. BBN은 PRIMAT 보간이며 평탄성은 입력이다.

1,015,000은 우리 우주를 특별하게 만드는 수가 아니다. 이번 구성에서는 우연히 그 주소 수를 사용했으며 재현을 위해 고정했다. 관측으로 확인되거나 유일하게 유도된 상수는 아니며, 그 수의 생성 확률 법칙과 다른 주소 수에 대한 견고성은 아직 보이지 않았다.

원작성 문서·자료·코드는 상위 저장소와 같은 CC BY 4.0이다. CAMB 등 제3자 자료는 원래 라이선스를 따른다. AI는 구현·계산 감사·문서 정리에 사용했으며 독립 동료 심사나 출판 추천으로 표시하지 않는다.

## 문서 개정 v0.29.1

수치 코드와 결과는 그대로이며 설명 범위를 명확히 한 개정이다. 잔차 max|F|/max|S_R|의 정규화와 유한 오차를 명시했다. 고정 입력으로 추가 관측 최적화를 하지 않은 사실을 모든 물리 가정이 제거되었다는 주장과 구별했다. 기존 CMB 계산과 새 단일 상호작용 모드를 분리했다.
