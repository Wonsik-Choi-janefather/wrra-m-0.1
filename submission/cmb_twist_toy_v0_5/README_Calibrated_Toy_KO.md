# WRRA 뒤틀림 CMB 토이모델 가설 v0.5

## 목적

뒤틀림 응력의 중력적 표현형을 유효 압력 없는 성분으로 설정하고, 알려진 CMB 온도·편광 모양에 맞게 보정한 탐색적 모형 개발 원고다. 검증된 관측값을 보정 입력으로 사용하는 것을 허용하며, 재현 결과를 현실 정합성 성과로 기록한다.

## 판정 순서

| 단계 | 실제 구현 |
|---|---|
| 검증 입력 | Planck PR3의 TT 83·TE 66·EE 66개 관측 묶음. 보통물질 5%, 중성미자·광학깊이 등은 관측 자체와 구분한 고정 모형 가정이다. |
| WRRA 변환 | 뒤틀림 응력 → 중력질량 표현형 → 중성미자를 분리한 밀도 장부 → 복사를 포함한 배경 닫힘 → 채택한 표준 전달 계산. 유한 SOURCE·공통운반자에서 공간 요동을 만드는 변환은 아직 이 모듈에 구현하지 않았다. |
| 산출값 | 보정된 TT·TE·EE 곡선, 봉우리 위치·높이, 음향 척도·음향지평선. 보정한 계수 자체는 새 예측으로 부르지 않는다. |
| 반증조건 | 구현의 밀도 장부·반복 계산 실패, 확정된 유효 프로필과 적절한 관측 검사의 불일치, 이후 뒤틀림 실현에서 채택한 응력·보존 규칙이 나오지 않는 경우를 구분한다. 정확히 같은 CDM 규칙을 쓰는 두 해석은 CMB만으로 구별할 수 없다. |

## 보정 성과

- 보통물질 비율 5% 고정.
- 전체 비바리온 물질 예산 27.245975%: 뒤틀림 등가 성분 27.101523%, 표준 질량 중성미자 0.144452%.
- 복사를 포함해 닫은 배경 성분 67.745930%.
- H0=66.816515 km/s/Mpc; 초기 요동 크기 As=2.106307689×10^-9; 기울기 ns=0.962619429.
- 전체 잔차 RMS/묶음 오차 지표: 1.106151 → 1.034789.
- TT: 1.126762 → 0.973820; TE: 1.075921 → 1.097901; EE: 1.109802 → 1.044126. 전체가 개선돼도 모든 항목이 개선된 것은 아니다.
- 정수 격자 TT 봉우리: 220·536·813.
- 일부 묶음을 보정에서 제외한 진단: 1.134161 → 1.124183. 약한 개선이며 독립적인 관측 검증으로 표현하지 않는다.
- 계산 정밀도를 높였을 때의 변화는 관측 오차 단위 RMS 약 0.002866이다.
- 다른 초기값/미분 간격의 전체 지표 1.034791로 주 보정과 매우 가깝다.
- 보통물질을 물리적 밀도로 고정한 민감도 비교의 지표는 1.057212이며, 보통물질 비율은 약 4.945239%다. 고정 방식에 따라 계수가 달라짐을 공개한다.

## 파일

최신 원고는 WRRA_Twist_CMB_Calibrated_Toy_EN_v0_5.pdf이다. 보정 코드는 calibrate_twist.py, 추가 비교 코드는 check_twist_robustness.py이다. 수치·로그·원자료·심사 원문을 함께 제공한다. 이전 원고는 최신본과 구분한다.

이 잔차 지표는 공분산·밴드 창함수·전경 보정을 포함한 정식 Planck 우도가 아니다. 토이모델 가설의 보정 재현 성과와 정식 학술지 채택을 구분한다. CAMB 전달 법칙을 채택해 실행한 사실과 WRRA 유한 SOURCE에서 직접 유도한 사실도 구분한다.

## Astra Medium 심사

v0.4는 탐색적 토이모델·계산 모형 개발 논문 범위에서 경미한 수정 후 출판추천을 받았다. v0.5는 요청된 경미한 수정 세 가지(gradient 종료 기준 설명, 재현 명령·환경, 보통물질의 바리온 정의)를 반영한 최종본이다. 심사 원문은 수정하지 않았으며, v0.5가 별도의 새 심사를 받은 것으로 표시하지 않는다. 학술지의 채택 결정과는 구분한다.
