## 검증 입력

기준: MCC 3.0 v0.25-r4 제38장과 제135.12절.
https://zenodo.org/records/23486923
기존 KZF 좌표 0≤ell<500, 0≤h<29, 1≤z≤70와 직렬화
a=1+ell+500[h+29(z-1)]를 그대로 사용한다.
주소창은 1≤a≤1,015,000이고 주소 1은 비활성 기준이다.
상류에 셔터·플랑크 시간·초·미터·정보 유량을 부여하지 않는다.
교환 사건의 순번과 요청 표지는 물리적 시간 좌표가 아니다.

알려진 구조를 구현하는 해석기를 구성하고 불일치가 있으면 수정하는
역설계가 판정 기준이다. 재현은 정합성과 설명 성과로 평가하며,
독립예측은 추가 성과로 구분한다. 이번 결과는 상류 인터페이스의
명시적 생성·왕복·허가·보존 명세와 유한 실행이며 새 실험 결과가 아니다.

## WRRA 고유 변환

### 1. 유사소수 운반자 생성식

Q(ell,h,z)=2^(ell+1) × 3^(h+1) × 5^z

이 Q를 ‘WRRA 유사소수 운반자’의 한 구현으로 채택한다.
여기서 유사소수란 내부적으로 합성 구조를 가지지만 한 교환 사건에서
하나의 원자적 운반 단위로 다루는 표지다. 표준 수론의 Fermat 유사소수나
소수 판별을 통과하는 수라는 주장이 아니다. 이 명칭은 기존 제135.12절의
작업 용어를 구체화한 선택이며, 이 생성식이 물리적으로 유일하다고 하지 않는다.
2·3·5는 좌표를 구별하는 부호화 기저이며 물리적 특별함을 부여하지 않는다.

세 지수가 양수이므로 모든 운반자 정수는 합성수다. 소인수 지수로
ell=v2(Q)-1, h=v3(Q)-1, z=v5(Q)를 정확히 복원한다.
따라서 서로 다른 좌표는 같은 운반자가 될 수 없다. 복원 좌표를 기존
직렬화에 넣으면 원래 주소 a를 얻는다. 허용되지 않은 소인수나 지수는 거부한다.

운반자 상태 수는 여전히 1,015,000개다. 최댓값 이하의 모든 자연수를
새 SOURCE로 추가하지 않는다. 검산에서는 큰 정수로 평가했지만 실행용
운반자는 세 지수 또는 기존 좌표로 희소 저장할 수 있다. 세 좌표의 고정폭
저장에는 9+5+7=21비트가 충분하고 직렬 주소에는 20비트가 충분하다.
수치 크기 Q를 에너지·질량·공간 크기·추가 상태 수로 읽지 않는다.
이 인코딩이 모든 가능한 구현 중 계산 비용이 최소임을 증명한 것은 아니다.

### 2. 한 번씩 주고받는 양방향 소유권

각 활성 운반자는 최상류 또는 중간층 중 정확히 한 곳이 소유한다.
허가가 열리면 최상류→중간층으로 이동하며 원래 자리의 활성 소유권을
비운다. 응답은 중간층→최상류로 같은 규칙에 따라 이동한다.
‘한 번씩’은 한 세션에서 정방향 한 번, 응답 방향 한 번이라는 의미다.
중복된 요청 표지는 다시 실행하지 않는다. 허가가 닫히면 상태를 유지한다.
잘못된 출발 소유자·이미 점유된 도착지·비활성 주소의 활성 전달을 거부한다.

정보 전달은 단순 왕복 표지 변경만이 아니라 응답 내용도 포함할 수 있다.
이번 구현의 정보 레지스터는 16비트 x이며 중간층의 예시 응답은
F_a(x)=x XOR (a mod 65536)다. F_a(F_a(x))=x이므로 내용을 바꾸면서도
원래 정보를 복원할 수 있다. 이 XOR는 가역 피드백 예시이며 상류의 물리적
힘이나 유일한 응답 법칙으로 채택한 것이 아니다. 일반 정보 ξ의 실제 변환은
해당 모듈의 규칙을 명시해 연결하면 된다.

미지 양자상태의 전달을 상태 복사로 구현하지 않는다. 별도 SWAP 검사에서는
외부 기준 R과 얽힌 최상류 T의 상태를 빈 중간층 M으로 옮긴다.
|ψ>RT |0>M → |0>T |ψ>RM의 관계를 사용하며 외부와의 상관관계를 보존한다.
주소의 가역 재표지는 허용된 유한 기저 사이의 전단사이므로 선형 확장한
등거리 사상을 구성할 수 있다. 실제 실행은 작은 세 큐비트 SWAP에 한정되며,
1,015,000차원 전체 양자 연산자나 진폭 생성기를 실행했다고 하지 않는다.

### 3. 중간층에서 단일 짝수로 가는 사상 A

Q를 복원하여 얻은 원래 주소 a를 기준으로 판정한다.

- a=1: 비활성 기준 상태로 유지한다.
- a가 짝수: 원래 주소와 정보를 유지하는 보류 상태로 둔다.
- a>1이 홀수: r=2a를 단일 짝수 전환 후보로 만들고 정보를 함께 보존한다.

마지막 경우 r=2a≡2(mod 4)이므로 r→a+a라는 동일량 분해가 가능하다.
역사상은 a=r/2로 원래 주소를 복원한다. 보류·기준 상태도 별도 표지를
유지하므로 거부 상태의 정보가 사라지지 않는다. 사상은 각 분기를 포함한
형식 상태공간에서 가역이며, 모든 주소가 질량화되는 전사함수는 아니다.
잘못된 표지·숨은 레지스터·주소 범위 초과는 역판독에서 거부한다.

예: a=9의 좌표는 (8,0,1), Q=2^9·3·5=7680이다.
Q → a=9 → r=18 → 9+9로 기존 동일량 분해에 연결된다.
a=5는 r=10의 산술 후보지만 홀수 합성수 필터를 통과하지 않는다.
a=10은 짝수 주소이므로 상류 교환은 가능해도 해당 켤레 출력 후보로 바꾸지 않는다.
a=105는 r=210 → 105+105의 구조 후보가 된다.

구조 후보와 실제 입자 생성은 구분한다. 실제 질량화에는 원래 주소의
홀수 합성수 조건과 별도 허가·종·에너지·운동량·상관관계 장부가 필요하다.
이번 검산에서는 실제 입자 생성 사건을 실행하지 않았다.
전환 표지 r는 새 SOURCE 주소나 생성 에너지 값이 아니다.

### 4. 기존 책과의 접합 원칙

차원 판독과 가중치는 원래 주소 a에서 계산한다. Q가 합성수라는 이유로
기존 소수 주소까지 3차원으로 재분류하거나 w(a)를 w(Q), w(r)로 바꾸지 않는다.
기존 alpha·beta·가중치 표·SOURCE 크기·셔터·우주 구성비를 재보정하지 않는다.
이로써 상류 전달의 허용 범위와 질량화된 표현형의 허용 범위를 분리한다.
순물질 비대칭·기존 초기조건·블랙홀 기하·두 해상도 관측 규칙을 이 인터페이스
하나로 추가 유도했다고 주장하지 않는다. 별도의 전역 비대칭 비트를 만들지 않는다.

## 산출값

상세 결과는 results.json, 재현 명령은 python3 exchange.py다.
NumPy를 사용하는 부분은 작은 양자 SWAP 검산이다.

- 1,015,000개 SOURCE 좌표의 운반자 생성·정확 복원·중간층 왕복 검사를 전수 실행.
- 활성 주소 1,014,999개에서 정방향·응답 각 한 번, 총 2,029,998회 소유권 이동.
- 각 주소에서 허가 닫힘과 16비트 가역 응답 복원을 함께 확인.
- 기존 분류 유지: 비활성 1, 소수 79,608, 짝수 합성수 507,499,
  홀수 합성수 427,892.
- 중간층 표지: 기준 1, 짝수 보류 507,500, 홀수 산술 후보 507,499.
  그중 홀수 합성수 구조 후보는 427,892개다. 실제 입자 생성 횟수는 0이다.
- 비정상 소인수·범위·허가·소유권·중복·분기 표지 등 18개 거부 대조 실행.
- 양자 전달 200개 경우: SWAP 왕복 진폭 오차 0,
  외부 기준과의 결합상태 최대 오차 1.13×10^-16,
  결합 고유값 최대 오차 7.77×10^-16. 이동 후 원래 최상류 레지스터는 빈 상태다.

위 숫자는 반복 시행으로 늘린 독립 관측 개수가 아니라 유한 명세의 검산 범위다.
최대 운반자 평가값은 709비트지만 도메인의 정보 상태 수는 증가하지 않는다.

## 반증조건

서로 다른 주소가 충돌하거나 역판독이 실패함, 한 전달 뒤 활성 소유자가
둘이 됨, 요청 재실행이 허용됨, 원래 가중치·분류가 변함, 홀수 조건을
어긴 단일 짝수가 출력됨, 허가가 닫혔는데 질량화됨, 임의 양자정보를
복사하면서 원본도 보존한다고 요구함이 확인되면 해당 구현을 수정한다.
실제 관측과의 접합에서 불일치가 생기면 피드백·해석 사상을 수정한다.

## 결론

기존 ‘상류 두 층의 생성식과 교환 사상 미정’ 항목에 대해 한 가지
명시적 유한 구현을 구성하고 전수 검사했다. 공학적 인터페이스의 생성·
주고받기·응답·허가·소유권·역판독까지 이번 후보에서 닫았다.
이는 조건부 역설계 구현의 완료이며, 해당 부호화의 유일성이나 물리적
상류 두 층의 실험적 확정까지 의미하지 않는다. 이 논문은 상류 정보교환 결과의 별도 등록본이며 기존 책·다른 공개 논문의 PDF가 이미 개정되었다는 뜻은 아니다.
