# 시간 동기화에서 SOURCE 렌즈와 CMB까지

이 기록은 시간 동기화를 시작한 계산부터 유한 SOURCE의 공간·공급·응력 연결, 실제 CMB 계산, 주소 수준 보정, 초기 평균 준비와 렌즈·관측 평가까지를 하나의 재현 가능한 자료로 정리한다. 원래 단계별 버전과 실패한 대조 계산을 함께 보존한다.

### 검증 입력

관측으로 검증된 상수와 자료, 기존 유한 주소·슬롯·공급 장부, 단계별 고정 입력을 사용한다. 알려진 값에 의한 보정은 모형 구성의 일부이며 보정 자료와 이후 교차 검증 자료를 구분한다.

### WRRA 고유 변환

상태·사건 부호화 → 고정 규칙과 자원·에너지 장부 → 공통운반자의 시간·공간 판독 → 응력과 물리 진화 → 관측 평가. 외부 물리 모듈은 실제 실행된 범위에서 연결된 것으로 표시한다.

### 산출값

최신 고다중극 quadratic form = 585.74750780. SOURCE 렌즈 편향 RMS = 0.00955659 초각. 새 수치 검사 15/15, 상류 재현 검사 28/28 통과. 이 숫자를 전체 이론의 확증이나 SOURCE 검출로 해석하지 않는다.

### 반증조건

교차 검증 오차, 사건·단위 의미의 불일치, 장부·확률 보존 파괴, 실제 물리 모듈과의 연결 실패, 수치 비수렴을 각각 해당 연결의 수정 대상으로 삼는다.

> 현재 판정: 평균 응력에 반응하는 조건부 모형의 시간/운반/공급/CMB 경로가 실행됐다. 유일한 보편 셔터, 기초 동역학의 전체 도출, 개별 실행과 평균 중력의 연결은 남아 있다.

## 1. 시간·위상·붕괴 사건의 교차 연결

### 중성미자 - 하나의 질량 눈금으로 재보정

고정 정수 모드 (0,5,29), 정상 질량 순서와 m1=0을 유지했다. 태양+KamLAND 및 Daya Bay 오차 요약을 사용해 공통 q를 보정했다. 진공의 상대 위상 진화를 실제 계산했다.

| 항목 | 산출값 / 의미 |
| --- | --- |
| q | 1.735336790803 meV |
| (m1,m2,m3) | (0, 8.676683954, 50.324766933) meV |
| 질량 합 | 0.059001450887 eV |
| 중심 분할값 잔차 | 태양 +0.37979%, 대기 -0.35291% |
| 1 MeV 첫 Pee 최소 | 1.662008688 마이크로초; 계산된 진공 시간 표지 |

두 분할값은 요약 오차 범위와 양립한다. 공통 q로 두 중심값을 정확히 동시에 맞출 수는 없다. 동일 실험을 공유하는 PDG 적합들은 독립 반복 검증으로 세지 않는다.

### 수소 및 중성미자-수소 공동 보정

1/n² → Coulomb/Dirac → S상태 잔차 → 고정 선도 자기 에너지 보정으로 진행했다. 실제 계산한 채택 원자물리 모듈을 통해 2S-8D5/2 홀드아웃 잔차가 7.880336 MHz에서 0.414264 MHz로 약 19배 줄었다. 실험 요약 정밀도에는 아직 미달하며 전체 QED의 반증으로 해석하지 않는다.

q,A,L과 공통 위상 속도 G를 모두 자유롭게 두면 재척도 퇴화가 있다. 기존 q0 및 전자 기반 에너지 눈금을 고정한 공동 시험에서는 G=0.999999994790629. 수소가 G 정밀도를 지배하며 자료 결합만으로 유일한 보편 시계를 정하지 못한다.

### 뮤온-타우 붕괴 연결

뮤온 평균 수명으로 약한 붕괴율 눈금을 보정하고 실제 유한 양수 사건 장부를 실행했다. 채택한 m^5 법칙·질량 위상 공간·선도 W 보정을 통한 타우 전자/뮤온 부분율 잔차는 -0.362612% / -0.418263%. 전체 타우 수명에는 측정된 기타 채널율을 사용했다.

> 위상 주기, 맛 진동의 최소 시점, 평균 수명과 부분율의 역수는 서로 다른 관측량이다. 숫자를 같은 단위로 옮기는 것과 같은 물리 사건임을 입증하는 것은 구분한다.

## 2. 광속·셔터와 SOURCE 공간·공급 연결

### 15채널 공통 운반자의 조건부 셔터

기존 모드 에너지 22217.345682174 eV와 위상 해상도 epsilon=0.05로 dt=epsilon*hbar/E를 정하고, 알려진 c를 사용해 dx=c*dt를 정했다. 유한 512셀 링에서 이동 연산과 15개 내부 채널의 항등 운반을 실행했다.

| 항목 | 결과 |
| --- | --- |
| dt | 1.481301966415863e-21 s |
| dx | 0.444083157552045 pm |
| 64회 운반 속도/c | 최대 상대 차이 6.23945e-14 |
| 확률·채널·에너지 | 부동소수점 정밀도에서 보존 |

c는 고정 입력이다. 셀 링은 계산 경계이며 우주 크기가 아니다. 더 높은 광자 에너지의 위상 앨리어싱을 판별하고 시간·공간을 함께 세분화했다. 수소의 기존 오차는 셔터 환산으로 사라지지 않는다.

### SOURCE 주소와의 첫 기하학 연결

실제 1,015,000 주소 및 500×29×70 유한 인덱스를 새로 선언한 주기 그래프로 판독했다. 주소 전단사와 dx 간격을 실행했으며 1024점 프로파일의 조건부 주기는 0.454741153333 nm이다. 독립적으로 도출된 SOURCE 미터 눈금과의 일치는 아직 확정하지 않았다.

### 잔여 소유권을 복원한 공급 연결 v0.2

총 슬롯 공통 커널만 쓰던 첫 시도는 국소 P/D/R 배분을 재현하지 못했다. 기존 코드에 있던 소수 2,3,5의 잔여 소유 커널을 복원하자 실제 주소 재합산과 국소 프로파일이 일치했다. 직접 정보 모양을 밀도에 대입한 음성 대조는 보존했다.

p_r(X)=0.5+1e-8[K_r(X/L)-1] → 실제 공급 간격 → 에너지·압력 변조로 7개 조화모드를 구성했다. 공급은 교환 전에 장부에 포함된다. 28개 실수 성분을 GR 하위계에서 진화시켰다.

> 3차원 스펙트럼 운반 H=hbar*c*|k|도 실행했지만 위치에서 비국소적이다. 엄격한 미시 인과 지지, Maxwell 편광·게이지 및 Lorentz 완성은 주장하지 않는다. 거시 첫 파수 0.05 Mpc^-1는 보정된 입력이다.

## 3. SOURCE 모드의 실제 CMB 진화와 원인 진단

### Boltzmann 실행으로 확장

패치 CAMB 2.0.4 안에서 기존 7개 SOURCE 모드를 광자·중성미자·재결합 계산까지 진화시켰다. 정규 복사시대/CDM 등곡률 확장과 일정한 delta_R를 채택했다. 이는 이전 후기 우주 초기값의 단순 역진화가 아니다.

geodesic synchronous 게이지에서 delta_R'=0, delta_D'=-k(z+v_D), v_D'=-H_conformal*v_D-k(rho_R/rho_D)delta_R. 진공 압력 변조와 암흑 운동량을 함께 metric에 넣었다. SOURCE 계산에서는 후기 복사 근사를 끄고 후기 ISW를 유지했다.

### 첫 공개 공분산 평가

| 고정 배경 분기 | 고다중극 quadratic form |
| --- | --- |
| 가중치 분기 | 591.57034 |
| 비가중치 분기 | 1217.75123 |
| 구간·보정 | TT/TE/EE 613구간, A_planck=1 |

SOURCE 추가 TT는 약 1.5e-5 microK²로 작았다. 표준 배경의 정합성이 새 SOURCE 기여의 검출을 뜻하지 않는다. 기존 보정 배경과 새 모드를 명확히 구분했다.

SI 단위 환산, 실제 solver 진폭 변경·선형 중첩 및 운동량 보존을 점검했다. 28개 실수 궤적은 유한했다. 밀도 0 교차 부근의 로그 성장률은 OPEN으로 표시했다. 장부 교환은 원인 진단이며 새로운 상류 도출 분기로 표현하지 않았다.

> 판정: 이 구성에서는 암흑 배경 장부가 불일치의 더 강한 수정 지점이다. 초기 우주 확장은 이미 실행됐으며, 상류 준비의 생성 정당화는 별도 문제로 남았다.

## 4. 진단을 주소 단계의 보정으로 구현

### 실제 주소부터 다시 계산

상속한 가중치 가족 e_s(n)w_n[1+lambda_s ln(n)/ln(N_U)] 안에서 lambda=(0,0.25,0)을 관측 진단 후 선택했다. 밀도 판독 뒤 교환하지 않고 슬롯·잔여·공급·에너지부터 다시 합산해 CMB까지 실행했다.

| 항목 | 산출값 |
| --- | --- |
| 암흑 평균 부하 | 0.268 → 0.278925610976744 |
| 추가 암흑 에너지 | 7.960139394787e-12 J/m³ |
| 주소 100 미만의 증가분 | 전체 증가분의 약 88.8% |
| H0 | 67.2568374662005 km/s/Mpc |
| ombh2 / omch2 | 0.022395806793 / 0.120378061774 |
| 당시 CMB + SOURCE | 585.9139188511556 |
| 당시 수치 검사 | 41개 통과 |

이 보정은 기존 가족 안에서 정합성을 개선한 실제 상류 변환이다. 관측 입력을 반영한 정당한 모형 구성으로 평가한다. 동시에 관측을 보기 전의 원래 고정 분기 결과와 구분한다. 각 단계마다 새 진폭 최적화를 수행한 것은 아니다.

### 무엇이 설명됐는가

배경 밀도 조정이 어떤 주소·잔여·슬롯에 의해 실현되는지 추적 가능해졌다. 증분 대부분이 낮은 주소에 집중되어 수정 위치가 구체화됐다. 가중치의 물리 해석·적용 범위가 추가 연구 대상임을 유지했다.

### 반증조건

주소/슬롯 합산 불일치, 공급·에너지·압력 비보존, 선형 구간 이탈, 해상도 변화에서 결과 붕괴 또는 실제 관측과의 불일치가 발생하면 해당 연결을 수정한다.

> 585.91이라는 값은 관측 진단을 반영한 새 주소 보정 후보의 결과다. 원래 비가중치 분기가 추가 조정 없이 같은 정합성을 얻었다는 뜻은 아니다.

## 5. 유한 초기 평균 준비·렌즈·확장 관측 평가

### 128개 위상 상태의 초기 평균 준비

SOURCE 모드 |8>과 구분되는 rho_phase=I/128 제어 레지스터를 추가했다. 조건부 공급 상태의 평균 에너지 및 각 모드 공분산을 구성하고 실제 CAMB 초기 콜백과 비교했다. 이산 평균/Fourier 공분산의 상대 차이는 1.94218576587e-9이다.

제어 메모리의 초기 엔트로피 ln(128)를 명시했다. 근복사시대 배경에서 정규 지연 속도 해를 점검했으며 초기 콜백은 선도 정규 항을 쓴다. 준비의 자연적 생성이나 반복 재설정의 무비용을 증명하지 않았다.

### 실제 SOURCE 공분산 렌즈

ell=2..6000, 7개 실제 파수에서 T,E,phi를 계산하고 phi 정규화를 직접 확인했다. SOURCE에는 연속 파수 Limber 채움을 쓰지 않았다. 채택한 공분산 재매핑 커널에 SOURCE phi를 넣었다. int32 제곱 오버플로를 양수성 검사에서 발견해 float64로 수정하고 영향을 받은 결과를 재계산했다.

| 최신 산출값 | 결과 |
| --- | --- |
| SOURCE 편향 RMS | 0.009556588544 초각 |
| 표준 성분 편향 RMS | 146.804724052 초각 |
| SOURCE/표준 편향 분산 | 4.23765614476e-9 |
| 고다중극 quadratic form | 585.747507795326 |
| 저다중극 TT / EE -2lnL | 23.425650359 / 396.117345700 |
| CMB 주변화 렌즈 -2lnL | 9.066339240 |
| SOURCE에 따른 합산 변화 | -8.07531250757e-7 |

공개 Planck 자료와 Cobaya 네이티브 TT/EE·CMBlikes 및 Gaussian Plik-lite를 실제 실행했다. 공식 clik와 비주변화 전체 전경 분석은 실행하지 않았다. 블록별 정규화 상수가 달라 합계 약 1014.36은 단순 자유도의 chi²가 아니다.

> 새 검사 15/15 및 상류 재현 28/28 통과. 585.91 → 585.75의 차이는 주로 기준 렌즈 계산 확장에 따른 것이다. SOURCE 효과는 매우 작으며 정확한 비가우시안 재매핑은 아직 남아 있다.

## 6. 현재 답변 범위와 남은 물리 연결

### 검증 입력 → 변환 → 산출값 → 반증조건

보정된 유한 공급/상태 → 실행된 운반·응력·CAMB·렌즈 → 조건부 CMB 정합성 → 상태·단위·보존·수렴·관측 비교라는 판정 경로가 마련됐다. 숫자의 새로움만으로 성과를 판정하지 않는다.

| 초기 공간 준비·스펙트럼 생성 | 평균 준비 구성; 생성 동역학 남음 |
| 추가 조정 없는 원래 분기 시험 | 불일치 기록; 보정 후보와 구분 |
| BAO 관측 우도·별도 핵합성 검증 | 표준 배경 거리·PRIMAT 보간값은 존재; 추가 검증 남음 |

기존 표준 배경에서 BAO 거리와 PRIMAT 보간을 계산했다. D/H=2.44177424096e-5, 헬륨 질량분율=0.24566720619는 채택 모듈의 출력이며 새 핵반응망 실행은 아니다. Afshordi 박사와의 기술적 논의는 연구 맥락으로만 표시한다. 사적 메일 원문이나 검토 승인·공동연구 주장은 수록하지 않는다.

### 다음 핵심: 평균과 개별 실행

독립 주소 공급 비트라는 한 준비 예에서는 고유 상대 RMS가 D=0.34514, R=0.49415로 평균 위상 신호 1.21074e-8 / 9.48940e-9보다 크다. 현재 중력 판독은 앙상블 평균 응력이다. 다른 상관 준비는 분산을 바꿀 수 있으며 이 결과가 모든 준비의 불가능성을 뜻하지 않는다.

공급 상관 구조 또는 유한 평균화의 독립성·새 자원·기록·재설정 비용을 구성해야 개별 실행과 평균 응력 사이를 닫을 수 있다. 독립 프레임 평균화 진단의 약 8.13e14 / 2.71e15 표본수는 아직 구현된 평균화 과정이 아니다.

> 최종 판정: 시간부터 관측까지 계산되는 조건부 통합 연구 기록이다. 수소 정밀 홀드아웃, 유일한 시계/미터 눈금, 초기 생성·개별 실행 중력·정확 비가우시안 렌즈는 구체적 후속 과제다.

## 재현 방법·자료 출처

전체 입력과 결과는 원래 단계 이름 아래 보존한다. 큰 동일 파일은 SHA256 객체 저장소에 한 번 보관하고 prepare_workspace.py가 정확한 원래 경로를 복원한다. 새 관측 수치 최적화나 재계산을 이 통합 정리 작업에서 추가하지 않았다.

```text
python prepare_workspace.py --verify-only
python prepare_workspace.py
pip install -r requirements.txt
python stages/neutrino_sync_v01/reproduce.py
python stages/cmb_preparation_lensing_v01/reproduce.py --verify-only
```

그 밖의 각 단계에도 reproduce.py가 있다. CMB 전체 재실행은 Linux용 번들 패치 런타임 또는 gfortran/make 재빌드를 사용하며 무거운 계산은 직렬로 진행한다. 완전한 재현 경로와 초기 가정은 각 단계의 README와 입력 JSON에 있다.
