SOURCE 국소 부문·공급 프레임·셔터 연결 계산 v0.2
최원식·최정인 공동연구 맥락. 2026-10-14.
실행: python reproduce.py. 필요: numpy, scipy, matplotlib.
실제 주소 자료, 원래 판독 코드와 GR 적분 코드를 포함하므로 인터넷 없이 재현한다.

1. 검증 입력
기존 v0.15의 1,015,000 주소·가중치·부문 함수·128 슬롯, 그리고 원래 2·3·5
전송 탭을 모두 사용하는 잔여별 공간 kernel을 사용했다. n=1 비활성 주소는 그대로 둔다.
v0.29.1의 실제 보존 프레임, eta 계수, 공급 준비 p=1/2, epsilon=1e-8,
진공 운동량 전달을 포함하는 표준 GR 부분계도 이어받았다.
한 셔터 dt=1.481301966415863e-21 s, 한 광행 간격 dx=c*dt=0.444083157552045 pm.
거시 파수 k1=.05 Mpc^-1는 이전 단일 모드의 시험 입력을 첫 조화 모드와 대응시킨
명시적 보정이다. 원전 공개 DOI 10.5281/zenodo.23329214.

2. WRRA 고유 변환
원본 주소별 입력을 다시 합산해 부문 s·잔여 r=n mod30·슬롯 j의 B_s,r,j를 계산했다.
원래 전송 kernel:
  K_r(x) = normalized product_(p=2,3,5) |1-D_p((r mod p)/p-x)|^2,
  mean_x K_r(x)=1.
국소 부문은 S_s(x)=sum_(r,j) B_s,r,j K_r(x)로 계산한다.
앞선 v0.1에서 각 부문에 총 슬롯의 kernel을 공통 적용했던 연결은 잔여/부문 소유권을
잃었다. 필요한 규칙은 기존 v0.15에 이미 있었다. 이번에 그 규칙을 복원했다.
슬롯별 kernel을 쓸 때도 각 부문의 실제 조건부 잔여 가중치로 K_s,j(x)를 계산해야 한다.

정보 프로파일과 물리적 밀도는 다른 판독이다.
직접 eta*S_s(x)를 밀도로 치환하는 후보는 큰 상대변동을 주므로 음성 대조로 남겼다.
실행한 수정 경로는 기존 유한 공급 프레임을 거친다.
  p_r(X)=1/2+epsilon*[K_r(X/L)-1], 원래 n mod3 !=0 제어 주소에만 적용.
  DeltaA=A72-A8=2cos(pi/8).
  delta u_s(X)=eta_s*DeltaA*epsilon*sum_controlled B_s,r,j*[K_r(X/L)-1], s=D,R.
  delta u_P=0, delta p=-delta u_R.
모입력에 없던 감쇠 배율이나 관측 최적화는 추가하지 않았다. epsilon=1e-8은 원전의
지정 시험 입력이며 관측에서 결정된 보편상수로 바꾸지 않는다.
공간 kernel을 각 공급 확률의 준비 패턴으로 사용한다는 연결은 이번의 명시적 가정이다.
교환 이전의 source+supplier와 이후 source 에너지를 위치별로 모두 계산한다.
소스의 증가를 전체 에너지 생성으로 세지 않는다. 비활성/균등 주소 그룹도 보존한다.

3. 산출값
원본 주소 payload와 국소 부문 프로파일: 저장 배열과 차이 0(동일 계산의 배열 비교).
별도의 직접 주소 합산 대 슬롯 경유 계산 차이: 최대 약6.99e-15.
부문 소유 kernel로 재구성한 차이: 최대 약3.77e-15.
이 숫자는 실행 비교 오차이며 관측 sigma가 아니다.

직접 정보→밀도 대조: 최대 상대변동 0.946/0.942로 선형 0.1 허용 문턱에 실패한다.
기존 공급 프레임을 거친 올바른 형식의 밀도 판독:
  미가중: 상대 RMS 7.5120923e-9, 최대 2.1438452e-8.
  가중: 상대 RMS 7.4694725e-9, 최대 2.1319120e-8.
평균 밀도 이동은 약1.5e-33 J/m^3 이하의 계산 오차이다.
공급 확률은 약0.49999999~0.500000038543로 유효하다.
두 분기의 배경 평균은 원래 eta*총량을 유지하며 기존 공급 ε는 그대로이다.
이 상대변동을 관측된 원초 곡률 진폭 A_s 또는 CMB 검증 성적으로 읽지 않는다.

첫 파수 보정 뒤 원래 탭에서 나오는 7개 조화 모드를 계산했다.
  k=(.05,.10,.15,.20,.25,.30,.35) Mpc^-1.
밀도·압력의 실제 Fourier 진폭과 위상은 SOURCE와 공급 에너지식으로 산출했다.
첫 파수는 입력, 나머지 위치 및 입력 확정 뒤의 진폭은 조건부 모델 산출값이다.
거시 파수의 기원 또는 미시 길이에서 거시 길이를 고르는 법칙을 새로 유도한 것은 아니다.
마이크로 프로파일 주기는 0.454741153333 nm, 보정한 거시 주기는 약125.664 Mpc이며,
그 비율은 약8.52699778655e33이다. 이 보정 관계의 정수 셔터 수도 계산했다.
거대한 유한 셔터 수를 매번 순회하지 않고 Fourier 위상·정수 카운터로 계산한다.
표의 빛 위상 주기는 a=1 순간의 경로 환산이며 실제 팽창 역사를 적분한 여행시간이 아니다.

가중/미가중 ×7 모드 ×cos/sin =28개 실제 SOURCE 성분을 기존 GR 부분계에 넣었다.
필요한 진공 운동량 전달 포함 시 공통 진공 원천으로 정규화한 최대 잔차:
  기존 허용오차: 약5.52e-7.
  더 엄격한 허용오차: 약6.90e-8.
전달 누락 대조군: 약0.999992. 두 계산의 해 차이는 최대약2.25e-12이다.
이는 기존 한 임의 cosine 시험에서 실제 SOURCE의 조화 성분으로 확장한 계산이다.
각 공간 모드의 선형성 및 source/공급 유한 교환 조건 아래 해석한다.
광자·중성미자·재결합을 포함한 전체 Einstein–Boltzmann/CAMB 또는 Planck 우도 계산은 아니다.

3차원 운반 대조
기존 500×29×70 유한 인덱스에 보정한 거리 계량을 두고 H=hbar*c*|k|를 채택했다.
U=exp(-iH*dt/hbar) tensor I15를 실제 FFT로 실행했다. 7방향, 64셔터 시험에서:
  위상속도와 c의 최대 상대차 약2.80e-13.
  확률 norm 최대오차 약6.66e-16.
  에너지 보존 및 수치적 위상 기울기 속도 검사 통과.
한 공간 상태와 15채널 내부 상태를 인수분해하여 중복 계산을 줄였다.
이것은 질량0 표준 스펙트럼 동역학을 WRRA 운반 모듈에 채택한 시험이다.
공간에서는 비국소 연산자이며 엄격한 미시적 광원뿔 지지, Maxwell 편광/gauge,
완전한 Lorentz 공변성 또는 SOURCE에서 광자가 생성되는 법칙을 증명하지 않았다.

4. 반증조건
주소·부문 소유권 누락, 직접 합산과 슬롯 판독 불일치, 양성/보존 실패,
공급 누락·중복, 위상 alias 통과, 방향별 속도 불일치, 필요한 전달을 포함해도
GR 제약이 깨지는 경우 또는 관측과의 적절한 후속 비교 실패가 수정 기준이다.

결론
앞서 막혔다고 보고한 국소 분포 연결은 원래 잔여 kernel을 복원하여 재현했다.
실제 SOURCE 모양→기존 공급 확률→같은 에너지/압력 판독→7개 거시 모드의 조건부
GR 보존 연결을 계산했다. 새 숫자를 요구하지 않고 구조·변환·실행 재현으로 판정했다.
미시 셔터와 거시 길이 사이의 대응은 아직 보정된 관계이다. 이것만으로 우주 크기나
원초 공간 배치가 산술에서 자동 결정됐다고 하지 않는다. 전체 CMB 검증도 남아 있다.

기록 정정
v0.1의 단순 부문 kernel 시험은 유효한 음성 대조이다. 그 실패를 원래 WRRA의
국소 공간 규칙 부재로 해석하는 부분은 이번 v0.2가 대체한다.
