SOURCE 주소·프로파일과 빛/셔터 척도의 연결 시험 v0.1
연구 맥락: 최원식·최정인. 2026-10-14.
실행: python reproduce.py (numpy 필요). 인터넷 없이 재현 가능.

1. 검증 입력
Afshordi 박사에게 2026-10-13 10:44 KST 발송한 v0.29.1 원전 ZIP을 내려받았다.
공개 원전 DOI: 10.5281/zenodo.23329214.
최신 3.0 한글 원고 v0.13, 파일 버전 11의 101–106장도 확인했다.
개인 서신은 패키지에 포함하지 않는다. 회신/검토 사실은 승인이나 공동연구를 뜻하지 않는다.

원전의 N_U=1,015,000, 128 내부 슬롯, 1024점 정보 프로파일,
실제 부문·주소잔여·슬롯 payload, 양의 슬롯 kernel, eta 계수를 그대로 이어받았다.
existing_local_operator.py의 기존 finite index 500×29×70도 확인했다.
원전은 그 인덱스를 합성 공간 대조 시험에 사용했으며 물리적 주소 배치의 유도는 주장하지 않았다.
이번 셔터 입력은 dt=1.481301966415863e-21 s, c=299792458 m/s이다.

2. WRRA 고유 변환과 새 구성 가정
두 연결을 구분해서 실행한다.

(가) 주소 인덱스의 조건부 거리 Renderer
  n-1 = i + 500(j+29k), 0<=i<500, 0<=j<29, 0<=k<70.
이 인덱스를 주기 이웃 그래프로 읽고, 각 축 한 이웃 간격에 d=c*dt를 부여한다.
정수 인덱스 분해는 기존 자료에서 이어받았지만 이웃의 물리적 거리·주기 경계는
이번에 추가한 명시적 구성 가정이다. SOURCE 내부 표지가 원래 공간이었다고 하지 않는다.
전체 주소의 좌표 및 역변환을 실제 배열로 검사했다.
이 그래프는 국소 표현 후보이며 우주 전체의 물리적 부피·크기로 읽지 않는다.
주소 1의 비활성 역할은 원래 부문 장부에 남고, 기하 표지에서 임의 삭제하지 않는다.

(나) 실제 SOURCE payload에서 정보 프로파일을 다시 구성
원본 W_s와 K_s(x)를 읽어 I(x)=sum_s W_s K_s(x)를 재계산했다.
기존 v0.20의 길이 판독 X=Lx, I_L(X)=I(x)/L를 사용했다.
정보 격자의 간격 1/1024를 한 셔터 광행 거리와 대응시키면 L=1024*d이다.
적분 총량과 상대변동을 보존하는지 가중·미가중 두 분기에서 검사했다.
서로 다른 공간량이다: 128은 내부 슬롯 수, 1024는 이 프로파일의 표본 수,
1,015,000은 주소 수이다. 이를 같은 물리 셀 개수로 취급하지 않는다.

3. 산출값
d=0.444083157552045 pm.
조건부 주소 그래프의 축별 주기 길이:
  500 d = 222.041578776 pm,
   29 d =  12.878411569 pm,
   70 d =  31.085821029 pm.
위 값은 이번 거리 판독을 적용한 출력이며 실제 우주 크기의 관측값이 아니다.
정보 프로파일의 주기 길이 L=454.741153333 pm =0.454741153333 nm.
전체 주소 1,015,000개의 좌표 역변환, 이웃, 한 축의 d/dt=c 대응을 통과했다.
원본 총 정보 프로파일은 W와 kernel 곱으로 정확히 재현했다.
상대 정보 RMS는 가중 약0.413291909, 미가중 약0.415389786이며 길이를 바꿔도 같다.

국소 부문 분담에 대한 실패한 단순 연결도 기록했다.
주소잔여 축을 먼저 합하고 부문별 슬롯 가중치에 공통 K_s만 곱하면,
P/D/R 전체 합과 각 부문의 적분 총량은 원본과 같지만 국소 부문 프로파일은 다르다.
가중 분기의 최대 국소 차이는 P 약0.04180, D 약0.10694, R 약0.09798이다.
이 수치는 무차원 정보/부하 판독 차이이며 관측 밀도나 sigma가 아니다.
단순 슬롯 연결은 원본의 공간 부문 분담을 재현하지 못했으므로 그 지점을 PASS로 세지 않는다.
원본 자료가 틀렸다고 결론내린 것도 아니다. 주소잔여·부문별 공간 kernel 사상 또는
그 준비 규칙을 추가로 넘겨야 한다는 구체적인 수정 지점이다.

기존 단일 우주론 모드 k=0.05 Mpc^-1를 기본 파수로 읽으면 주기는 약125.664 Mpc이다.
이를 위 1024점 프로파일의 주기로 채택하는 별도 대조에서는 미시 프로파일 대비
길이 배율 약8.52699778655e33이 필요하다. 이 주기와 진폭은 원전에서도 입력이다.
N_U를 공간 셀 수라고 선언하는 것만으로 이 배율이나 우주론 파수가 유도되지는 않는다.
프로파일의 공간 단위 변환만으로 상대 정보 변동이 관측 섭동 수준으로 작아지지도 않는다.

원본 v0.29.1 single_mode.py와 review.py를 실제 재실행했다.
기존 26/26, 28/28 검사를 다시 통과했다. 운동량 전달 포함/누락 차이는 유지됐다.
새 거리 Renderer를 CAMB에 넣은 계산, 새로운 Planck 우도 검증 또는 3D 기원 증명이 아니다.

3차원 전파의 음성 대조
세 축 방향의 동일 틱 이웃 이동만으로 모든 방향의 같은 광속을 얻지는 않는다.
축을 번갈아 진행하는 대각선 경로의 유효 속도는 c/sqrt(3)이다.
또 별도의 3차원 중앙차분 파동 기법에는 c*dt/d<=1/sqrt(3)의 안정조건이 있다.
현재 d=c*dt를 그 기법에 그대로 적용하면 실패한다. 이는 특정 확장의 검사이며,
앞서 실행한 1차원 massless shift의 실패나 모든 3차원 구현의 불가능성 증명이 아니다.
공통운반자의 3차원 전파/등방성은 별도 동역학으로 완성해야 한다.

4. 반증조건
주소 누락·중복, 음의 정보량, 총량 또는 원본 프로파일 재구성 실패,
거리/셔터 불일치, 부문 공간분담의 미재현, 새 SOURCE 계량과의 충돌,
주장한 3차원 전파의 방향 의존성 또는 불안정이 해당 연결의 반증조건이다.
c와 셔터로 한 거리 척도를 보정하는 구성은 정당한 모형 수정이다.
다만 이 구성 결과와 기존 SOURCE에서 따로 도출된 거리의 일치 검증은 다른 판정이다.

결론
Afshordi 발송본의 실제 자료를 사용해 주소 인덱스·정보 프로파일을 셔터 거리와
연결하는 보정적 Renderer 후보를 구성하고 실행했다. 기존 보존 연결을 활용할 수 있다.
그러나 한 숫자만 맞추면 상·하류가 모두 밀봉된다는 결론은 아직 성립하지 않는다.
남은 구체적 연결은 국소 부문 소유권을 보존하는 공간 사상, 거시 길이/배율의 규칙,
그리고 3차원 전파 동역학이다. 숫자의 새로움이 아니라 이 변환·연결의 실행 여부로 판정했다.
