작성: 2026-10-14. 연구 맥락: 최원식·최정인 공동연구.
코드와 계산 결과를 포함하는 연구용 감사 패키지. 출판·외부 검증 완료를 뜻하지 않는다.

실행
  python reproduce.py
의존성: Python 3, numpy, matplotlib. 입력은 frozen_inputs.json에 고정되어 있다.
코드는 실행 폴더에 CSV, JSON, PNG, SHA256SUMS.txt를 재생성한다.

1. 검증 입력
시간 기준은 뮤온 평균수명 2.1969811 ± 0.0000022 마이크로초이다.
뮤온·전자·타우의 질량, W 질량은 외부 측정 입력이다.
대조값은 타우 평균수명 290.3 ± 0.5 fs와 다음 분기비이다.
  PDG 2026/HFLAV: 전자 17.85 ± 0.04%, 뮤온 17.37 ± 0.04%.
  PDG 직접 평균: 전자 17.82 ± 0.05%, 뮤온 17.33 ± 0.05%.
  ALEPH 2005, L3 2001: 각각의 발표 분기비 및 공개된 상관계수도 입력.
타우의 부분 붕괴율 대조값은 분기비 / 전체수명이다.
타우 분기비와 수명은 주 계산의 약한 상호작용 정규화에 사용하지 않았다.
GF를 별도로 넣지 않았다. 뮤온 수명에서 추출한 GF를 또 독립 검증으로 셀 수 없다.

2. 고유 실행 구조와 채택 물리 모듈의 경계
MCC/WRRA 책에 있는 유한 붕괴 전이·딸 입자 코호트·장부 구조를 시험용으로 구현했다.
해당 구조 자체가 아래 약한 상호작용 공식을 새롭게 유도했다는 주장은 하지 않는다.
채택한 외부 물리 모듈은 렙톤 보편성 하의 m^5 법칙, 최종상태 질량 위상공간,
선도 W 전파자 보정이다. Pich 1310.7922 식 (2)~(4)를 사용했다.

  f(x) = 1 - 8x + 8x^3 - x^4 - 12x^2 ln(x)
  w(M,m) = 1 + (3 M^2 + 9 m^2)/(5 M_W^2)
  Gamma(tau -> l) = [1/t_mu] (m_tau/m_mu)^5
                   * f((m_l/m_tau)^2)/f((m_e/m_mu)^2)
                   * w(m_tau,m_l)/w(m_mu,m_e)

동일한 고정 alpha에서 최종상태 질량을 무시한 일차 QED 보정은 이 비율에서 상쇄된다.
채널별 유한질량 QED, 고차·running QED, 완전한 전기약 보정은 구현하지 않았다.
따라서 완전한 정밀 표준모형 계산이 아니라 잘 정의된 절단 근사이다.

유한 사건 인덱스는 선택한 해상도 N_mu=2^k와 dt=t_mu/N_mu로 SI 시간에 연결된다.
N_mu는 계산상의 선택이며 수론적으로 유도된 근본 틱이 아니다.
한 틱의 다중 채널 전이 확률:
  p_i = (Gamma_i/Gamma_total) * [1-exp(-Gamma_total*dt)]
  p_stay = exp(-Gamma_total*dt)
한 모입자는 틱마다 한 번만 제거되고 해당 딸 입자 코호트에 기록된다.
기대값 장부와 고정 난수 seed의 정수 코호트 장부를 모두 구현했다.
렙톤 코호트에는 하전 딸입자 1개와 중성미자 2개를 계수한다.
에너지는 모입자 정지계의 총 예산을 완전한 딸 코호트에 이월한다.
이것은 총에너지 회계 점검이며 개별 입자의 에너지 스펙트럼·운동량 생성은 아니다.
보존되는 코호트 식별자 수와 실제 입자 수는 다르다.

3. 산출값
뮤온만을 정규화 기준으로 사용하는 주 계산:
  타우 -> 전자: 6.1265152383e11 /s; 관측 6.1488115742e11 /s.
                 상대차 -0.362612%; 개별 잔차 -1.27790 sigma.
  타우 -> 뮤온: 5.9584387804e11 /s; 관측 5.9834653806e11 /s.
                 상대차 -0.418263%; 개별 잔차 -1.44880 sigma.
위 sigma는 입력·측정 요약오차 전파이며 이론 절단오차를 포함하지 않는다.
HFLAV 두 분기비의 공분산을 가져오지 않았으므로 합산 유의도는 제시하지 않았다.
채널별로 전체수명 오차를 포함했고, ALEPH/L3는 알려진 분기비 공분산을 사용했다.
수명과 분기비, 외부 질량 요약값들 사이의 상관은 0으로 근사했다.
타우 질량 오차가 예측 오차의 대부분을 차지한다.

부분 붕괴율의 역수는 전자 1.632249 ps, 뮤온 1.678292 ps이다.
이 값은 실제 타우 전체수명 0.2903 ps가 아니다.
두 채널의 합은 전체의 약 35.08%이다. 강입자 등 나머지 붕괴율을 예측하지 않았다.
전체 장부 시뮬레이션에서 나머지 비율은 측정 전체수명으로 닫았다.
따라서 전체 타우 생존곡선 재현은 조건부 계산이며 전체수명의 새 예측으로 세지 않는다.

별도 추가 튜닝:
타우 전자 채널로 추가 정규화하면 공통 배율 1.0036393178이 필요하다.
그때 남겨 둔 타우 뮤온 채널의 분기비 계산값은 17.3602983%이다.
관측 17.37% 대비 -0.0558531% 차이이다. 이것은 별도의 2기준 계산이다.
전자 채널은 이 단계의 검증 대상에서 제외한다.
ALEPH/L3는 PDG/HFLAV의 입력 자료에도 들어간다. 네 데이터셋을 독립 검증 네 건으로
합산할 수 없고, 자료 선택에 대한 민감도 시험으로 해석한다.

장부 결과:
  k=24,28,32에서 비음수 확률·확률합·정수 코호트 합·총에너지 회계를 점검했다.
  지수 전이 장부와 해석적 생존확률의 최대 차이 약 3.2e-15.
  일차 Euler 생존오차는 해상도 증가에 따라 약 0.1044 -> 0.005248 -> 0.0003243으로 감소.
  서로 다른 해상도는 가장 가까운 정수 틱의 시각에서 비교하므로 시간 반올림도 기록했다.

중성미자·수소와의 연결:
이전 공동 계산의 G=0.9999999947906286과 두 시간 관측값을 prior_time_anchor.json에 고정했다.
원자 위상 주기, 중성미자 맛 진동의 첫 극소, 붕괴 평균수명은 서로 다른 시간 관측량이다.
공통 계수 G를 붕괴율에도 곱한다는 가정 아래, 뮤온에서 다시 정규화하면 G는 비율에서
상쇄된다. G=.5,1,2 및 이전값으로 실제 점검했다. 이번 시험은 G를 독립 결정하지 못한다.
SI 에너지/붕괴 폭 환산에는 알려진 hbar를 사용한다. hbar의 기원도 새로 유도하지 않았다.

4. 반증조건과 수정 방향
고정된 입력으로 타우 부분율이 측정오차 및 명시한 이론절단 범위를 넘어 어긋나거나,
음수 잔여 붕괴율·확률, 중복 모입자 차감, 누락 코호트/에너지, 해상도 수렴 실패가
발생하면 해당 실행/전이 규칙을 수정해야 한다.
두 타우 채널의 작은 공통 결손은 정밀 방사보정, 수명/질량 입력, 약한 상호작용
정규화의 점검 지점이다. 현재 1.3~1.5 sigma로 새 물리의 증거라고 할 수는 없다.
보편적인 수론 시계를 검증하려면 정규화에 흡수되지 않는 추가 관계와 SOURCE에서
약한 상호작용·틱 수를 산출하는 규칙이 필요하다.

결론
측정 뮤온 시간으로 기준을 고정하고 타우의 알려진 부분 붕괴율을 계산하는 운영적
시간/사건 전이는 이 근사 수준에서 잘 맞는다. 유한 실행 장부에서도 보존 검사를 통과했다.
수론 사건과 물리 사건의 동일성이나 보편적 근본 시간의 유도까지 완료된 결과는 아니다.
